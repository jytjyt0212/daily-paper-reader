## 摘要
我们提出感知流匹配（PFM），这是一个简单而有效的框架，用于流匹配模型中的少步生成。PFM并非在传统的VAE潜空间中进行速度回归，而是使用预训练的感知模型在感知特征空间中对流匹配进行监督。这一简单改变显著提升了流匹配模型的少步生成能力，将采样步数从35-50步减少到4-8步，同时保持生成质量。与现有的加速和蒸馏方法不同，PFM既不需要教师模型，也不需要辅助评分网络，并且可以以最少的修改集成到标准流匹配训练流程中。在图像生成、视频生成和图像编辑任务上的大量实验表明，PFM一致地产生高质量结果，同时比现有基于蒸馏的方法产生的伪影更少。我们进一步表明，感知监督将回归最小化器从均值寻找转向模式寻找，使预测偏向于流形上的模式，这些模式在粗粒度的少步积分下仍然准确。我们的结果表明，当在适当的表示空间中进行监督时，标准流匹配训练自然能够产生高质量的少步生成器。我们希望这一见解能激发未来关于表示感知目标的高效生成建模研究。

## Abstract
We propose Perceptual Flow Matching (PFM), a simple yet effective framework for few-step generation in flow-matching models. Rather than performing velocity regression in the conventional VAE latent space, PFM supervises flow matching in a perceptual feature space using pretrained perceptual models. This simple change substantially improves the few-step generation capability of flow-matching models, reducing the number of sampling steps from 35-50 to 4-8 while preserving generation quality. Unlike existing acceleration and distillation approaches, PFM requires neither teacher models nor auxiliary score networks and can be integrated into standard flow-matching training pipelines with minimal modifications. Extensive experiments on image generation, video generation, and image editing tasks demonstrate that PFM consistently produces high-quality results while producing fewer artifacts than existing distillation-based methods. We further show that perceptual supervision shifts the regression minimizer from mean-seeking to mode-seeking, biasing predictions toward on-manifold modes that remain accurate under coarse few-step integration. Our results reveal that standard flow-matching training can naturally yield high-quality few-step generators when supervised in an appropriate representation space. We hope this insight inspires future research into representation-aware objectives for efficient generative modeling.

## 2. 论文提出的方法论：核心思想、关键技术细节、算法流程

**核心思想：**
- 标准流匹配在 VAE 潜空间中对速度场进行 L2 回归，其最优解为后验均值。在高噪声水平下后验分布多模态，均值处于流形外，产生模糊预测，少步采样难以修正。
- 预训练感知模型（如 VGG、DINOv2、ConvNeXt）的特征空间对非流形退化（模糊）赋予更大距离，使回归最小化器从均值寻求（mean-seeking）转向模式寻求（mode-seeking），预测偏向于流形上的有效样本。

**关键技术细节：**
1. **感知流匹配目标：**
   - 给定噪声潜变量 \(x_t = (1-\sigma_t)x_0 + \sigma_t \epsilon\)，模型预测速度 \(v_\theta(x_t, t, c)\)，通过逆公式 \(\hat{x}_0 = x_t - \sigma_t v_\theta\) 恢复干净潜变量。
   - 将 \(\hat{x}_0\) 和真实 \(x_0\) 通过 VAE 解码器 \(D\) 解码到像素空间，再用预训练感知模型 \(\phi\) 提取特征，计算感知距离损失：
     \[
     L_{\text{PFM}} = \mathbb{E}_{x_0,\epsilon,t} \left[ d(\phi(D(\hat{x}_0)), \phi(D(x_0))) \right]
     \]
   - 在推理时使用标准的少步一致性采样（预测 \(\hat{x}_0\)，再加噪跳到下一步）。

2. **分类器自由引导（CFG）的融合：**
   - 标准 CFG 需要推理时额外一次无条件网络评估。PFM 提供了两种在训练阶段烘焙 CFG 的策略：
     - **预测侧（Prediction-side）：** 将引导嵌入模型预测，用 stop-gradient 处理无条件分支，使梯度仅通过条件分支。
     - **目标侧（Target-side）：** 构造 CFG 增强的目标 \(\hat{x}_{\text{cfg}}\)，用感知损失直接优化模型。
   - 论文发现 PFM 本身已大幅降低对 CFG 的需求，训练时即使不使用 CFG 烘焙也能生成良好结果。

3. **算法流程（伪代码风格）：**
```
# PFM 基本流程
v_pred = model(x_t, t, c)
x0_pred = velocity_to_x0(v_pred, x_t, t)
loss = perceptual_loss(decode(x0_pred), decode(x0))
# PFM with prediction-side CFG baking
v_pred = model(x_t, t, c)
v_uncond = model(x_t, t, null)
v_pred = beta * v_pred + (1 - beta) * stopgrad(v_uncond)
x0_pred = velocity_to_x0(v_pred, x_t, t)
loss = perceptual_loss(decode(x0_pred), decode(x0))
```

**补充分析（Why it works）：**
- 定义了“离流形惩罚” \(R_\phi(a,b) = 2d_\phi(m,a)/d_\phi(b,a)\)（\(m\) 是 \(a,b\) 的欧氏中点），衡量特征空间对模糊平均的惩罚程度。预训练感知模型的 \(R_\phi\) 显著大于 1，而 VAE 潜空间接近 1。
- 在玩具数据（二维螺旋）上验证：感知监督使少步生成样本紧贴真实流形，而潜空间监督导致离流形预测。
