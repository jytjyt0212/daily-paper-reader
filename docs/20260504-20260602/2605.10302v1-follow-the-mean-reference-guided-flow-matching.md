## 摘要
现有的可控生成方法通常依赖于微调、辅助网络或测试时搜索。我们证明流匹配提供了一种不同的控制接口：通过示例进行适应。对于确定性插值，速度场仅由条件端点均值决定；移动该均值会改变流本身。这为可控生成提供了一个简单原则：通过改变预训练模型所遵循的参考集来引导它。我们以两种形式实现这一思想。参考均值引导无需训练：它从参考库计算封闭形式的端点均值校正，并将其应用于冻结的FLUX.2-klein（4B）模型，从而在保持提示、种子和权重不变的情况下控制颜色、身份、风格和结构。半参数引导通过显式均值锚点和学习的残差精炼器将相同思想具体化，在AFHQv2上匹配无条件的DiT-B/4质量，同时允许在推理时交换参考集。这些结果指向一个更广泛的方向：通过数据而非参数更新来适应的生成模型。

## Abstract
Existing approaches to controllable generation typically rely on fine-tuning, auxiliary networks, or test-time search. We show that flow matching admits a different control interface: adaptation through examples. For deterministic interpolants, the velocity field is solely governed by a conditional endpoint mean; shifting this mean shifts the flow itself. This yields a simple principle for controllable generation: steer a pretrained model by changing the reference set it follows. We instantiate this idea in two forms. Reference-Mean Guidance is training-free: it computes a closed-form endpoint-mean correction from a reference bank and applies it to a frozen FLUX.2-klein (4B) model, enabling control of color, identity, style, and structure while keeping the prompt, seed, and weights fixed. Semi-Parametric Guidance amortizes the same idea through an explicit mean anchor and learned residual refiner, matching unconditional DiT-B/4 quality on AFHQv2 while allowing the reference set to be swapped at inference time. These results point to a broader direction: generative models that adapt through data, not parameter updates.

- **整体含义**：作者发现流匹配（Flow Matching）的确定性插值器中，速度场唯一由**条件端点均值（endpoint mean）** 决定。因此，**通过改变参考集分布来移动该均值**，即可隐式地重新定向生成流。这开辟了“通过数据适应而非参数更新”的可控生成新范式。

### 2. 论文提出的方法论：核心思想、关键技术细节

#### 核心思想
- **关键观察**：对于线性插值 \( x_t = (1-t)x_0 + t x_1 \)，最优速度场满足  
  \[
  u_t(x) = \frac{\mu_t(x) - x}{1-t}, \quad \mu_t(x) = \mathbb{E}[x_1 | x_t = x]
  \]  
  因此，**引导目标分布的变化等价于移动端点均值**：  
  \[
  u^\pi_t(x) - u_t(x) = \frac{\mu^\pi_t(x) - \mu_t(x)}{1-t}.
  \]

#### 技术细节
1. **Reference-Mean Guidance (RMG, 无训练)**  
   - 将参考集 \( R \) 的端点均值 \(\hat{\mu}^\rho_t(x)\) 用封闭形式（softmax加权求和）计算：  
     \[
     \hat{\mu}^\rho_t(x) = \sum_{m} w^{(m)}_t(x) x^{(m)}, \quad w^{(m)}_t(x) \propto \exp\left(-\frac{\|x - t x^{(m)}\|^2}{2(1-t)^2}\right)
     \]  
   - 引导后的速度场为：  
     \[
     u^\pi_t(x) = u^\theta_t(x) + \beta_t \frac{\hat{\mu}^\rho_t(x) - \mu^\theta_t(x)}{1-t}
     \]  
     其中 \(\beta_t\) 为引导调度（常用二次衰减 \(\beta_t = \beta_0(1-t)^2\)），\(\mu^\theta_t(x) = x + (1-t)u^\theta_t(x)\) 由预训练模型输出。  
   - **无需额外训练、梯度计算或辅助模型**，仅需参考集图像经VAE编码后计算加权平均。

2. **Semi-Parametric Guidance (SPG, 可训练)**  
   - 设计可微架构：通过交叉注意力计算锚点 \(\bar{x}\)（类似RMG的加权和，但权重由学习得到），再结合时间门控 \(g_t, \alpha_t\) 和残差精炼器 \(f^\theta\)：  
     \[
     \mu^\theta_t(x_t, R) = (1-g_t)x_t + g_t \bar{x} + \alpha_t f^\theta(\bar{x}, x_t, t)
     \]  
   - 训练时采用留一法（leave-one-out）避免自注意，并利用 stop-gradient 使残差网络专注于更正锚点误差。  
   - 推理时**可自由替换参考集**，无需重新训练。

### 6. 论文的主要结论与发现

1. **端点均值是流匹配控制的唯一接口**：改变参考集即可通过闭环均值校正引导生成，无需修改模型。
2. **RMG实现训练自由控制**：在冻结的FLUX.2模型上，仅靠20张参考图像即可有效改变颜色、风格、物种甚至复杂结构（手势、姿势），且在GenEval上显著优于搜索/梯度基线（+11%平均分），定位性能提升最明显（+28.75）。

4. **生成模型可通过数据适应而非参数更新**：这一范式简化了可控生成过程，扩展了生成模型的适应能力。

### 7. 优点

- **方法简洁**：基于闭环均值移动，数学推导清晰，无需额外模型或梯度。
- **训练自由（RMG）**：可直接应用于任意预训练流匹配模型（线性插值即可），零额外计算开销。
- **可交换参考集**：SPG训练后可在推理时自由替换参考集，无需微调。
- **鲁棒性**：二次衰减调度避免了晚步不稳定；softmax温度 \(\tau=\sqrt{d}\) 防止高维注意力坍塌。
- **实验严谨**：消融覆盖调度、强度、参考集大小、NFE；对比基线使用相同骨干、分辨率、提示、种子，确保公平；定量指标包含多样性（LPIPS）、属性强度（CLIP）、分类准确率（VLM）。
- **应用广泛**：RMG可控制颜色、风格、物种、结构（形状/肢体姿态），SPG可控制类别并抑制背景伪影。

### 8. 不足与局限

- **参考集质量依赖**：RMG引导效果直接受参考集质量影响，噪声或浅层相似但语义无关的参考会导致伪影。
- **计算成本**：RMG在大参考集（如数千张）下计算softmax加权平均会随 \(O(Md)\) 增长，尽管可通过子采样或检索缓解。
- **适用范围**：当前仅针对**线性插值的流匹配模型**（如FLUX、DiT），对于其他桥接形式（如VP-SDE）需重新推导。
- **多样性控制**：RPB在参考集很小时多样性降低（图15），需权衡控制强度与多样性。
- **结构控制仅定性**：手势、体操、钥匙孔等结构控制仅提供视觉示例，缺乏定量评估（如关键点准确率、IoU）。
- **潜在误用风险**：如作者所述，需负责任地管理参考集内容，防止有害或误导性生成。
