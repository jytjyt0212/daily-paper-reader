## 摘要
现有可控生成方法通常依赖于微调、辅助网络或测试时搜索。我们证明流匹配提供了一种不同的控制接口：通过示例进行自适应。对于确定性插值，速度场仅由条件端点均值决定；移动该均值即可移动流本身。这为可控生成提供了一个简单原则：通过改变预训练模型所遵循的参考集来引导模型。我们以两种形式实例化这一思想。参考均值引导无需训练：它从参考库中计算闭合形式的端点均值校正，并将其应用于冻结的FLUX.2-klein（4B）模型，从而在保持提示、种子和权重不变的情况下控制颜色、身份、风格和结构。半参数引导通过显式均值锚点和学习到的残差精化器来摊销相同思想，在AFHQv2上达到无条件DiT-B/4的质量，同时允许在推理时切换参考集。这些结果指向一个更广泛的方向：通过数据而非参数更新进行自适应的生成模型。

## Abstract
Existing approaches to controllable generation typically rely on fine-tuning, auxiliary networks, or test-time search. We show that flow matching admits a different control interface: adaptation through examples. For deterministic interpolants, the velocity field is solely governed by a conditional endpoint mean; shifting this mean shifts the flow itself. This yields a simple principle for controllable generation: steer a pretrained model by changing the reference set it follows. We instantiate this idea in two forms. Reference-Mean Guidance is training-free: it computes a closed-form endpoint-mean correction from a reference bank and applies it to a frozen FLUX.2-klein (4B) model, enabling control of color, identity, style, and structure while keeping the prompt, seed, and weights fixed. Semi-Parametric Guidance amortizes the same idea through an explicit mean anchor and learned residual refiner, matching unconditional DiT-B/4 quality on AFHQv2 while allowing the reference set to be swapped at inference time. These results point to a broader direction: generative models that adapt through data, not parameter updates.

## 一、 论文的核心问题与整体含义（研究动机和背景）

当前可控生成方法通常依赖 **微调模型参数**、**辅助网络**（如分类器、奖励模型）或 **测试时搜索**（如反复采样、评分）。这些方法要么需要额外训练或梯度计算，要么显著增加推理成本。本文基于 **流匹配（Flow Matching）** 的理论性质——**速度场完全由条件端点均值（conditional endpoint mean）决定**——提出一种新的控制范式：**通过改变参考数据集的端点均值，即可直接引导生成分布**。核心思想是：“用示例引导，而非用奖励”。这一思路将可控生成从“参数更新”转换为“数据操作”，开辟了无需修改模型、无需辅助信号、无需搜索的简洁控制路径。

## 二、 论文提出的方法论：核心思想、关键技术细节

### 2.1 核心思想
- 对于确定性线性插值的流匹配，速度场与端点均值满足简单关系：  
  `u_t(x) = (μ_t(x) - x) / (1 - t)`
- 若在测试时希望生成来自不同目标分布 π 的样本，仅需将预训练模型的端点均值 μ_t(x) 替换为指导后的均值 μ_π(x) = (1-β_t)μ_t(x) + β_t μ_ρ(x)，其中 μ_ρ 是基于参考集 R 的端点均值。
- 这种均值偏移可写为速度场修正：  
  `u_π(x) = u_θ(x) + β_t * (μ^ρ_t(x) - μ_θ(x)) / (1 - t)`

### 2.2 两种具体实现

#### 2.2.1 Reference-Mean Guidance (RMG) — 无训练
- 直接从预训练模型中恢复端点均值 μ_θ(x) = x + (1-t) u_θ(x)。
- 利用参考集 R 计算闭合形式的经验端点均值：  
  `μ^ρ_t(x) = Σ w^(m)_t(x) x^(m)`，权重为 softmax 归一化的高斯核（类似交叉注意力）。
- 将修正项 β_t (μ^ρ - μ_θ) 加入原始速度场，在冻结模型上运行标准采样器。
- 无需额外训练、无需分类器、无需搜索。

#### 2.2.2 Semi-Parametric Guidance (SPG) — 可学习残差网络
- 训练时，模型 μ_θ(x_t, R) 通过交叉注意力计算参考锚点 `x̄`，再结合时间依赖门控与残差精炼。
- 损失函数包括：端点预测损失 L_μ（留一法）和正残差精炼损失 L_ref（停止梯度通过锚点）。
- 推理时，更换参考集 R 即可控制生成属性，同时模型可学习抑制参考集中的无关伪影（如共享背景）。

## 六、 论文的主要结论与发现

1. **端点均值控制流**：通过改变参考集的条件端点均值，可直接改变生成分布，无需任何参数更新。
2. **RMG 无需训练即可控制**：在冻结 FLUX.2 模型上，仅交换参考图像即可控制颜色、风格、物种，甚至结构姿态；在 GenEval 上，RMG 在位置（+94.00 vs 65.25）、总体平均分（91.17 vs 80.10）上大幅超越基线，且推理时间仅略高于基线（1.02×），远低于搜索/梯度方法。
3. **SPG 保持生成质量并实现推理时控制**：在 AFHQv2 上 FID (23.26 vs 23.11) 与无条件 DiT-B/4 相当，同时允许通过参考集比例连续控制输出类别。
4. **示例优于奖励**：无需标量奖励、分类器或梯度，即可通过数据直接引导生成。

## 七、 优点

- **无训练、无辅助网络、无梯度、无搜索**：RMG 简洁高效，仅需一次前向传递即可集成参考集信息。
- **控制与提示正交**：提示和参考集可独立调整，实现灵活组合。
- **理论优雅**：基于流匹配的基本性质，推导清晰，闭合形式简单。
- **可扩展**：SPG 将相同原理整合为可学习架构，兼具非参数和参数学习优点，可压制参考集中无关的干扰。
- **公开基准评估公平**：所有对比方法共享相同主干、种子、步数，仅控制接口不同。

## 八、 不足与局限

- **参考集质量敏感**：噪声或错误参考会污染生成结果；伪影传递问题（如白色背景）在 RMG 中明显，需借助 SPG 或进一步设计缓解。
- **计算成本**：计算闭合形式权重需对所有参考点计算距离，当参考集极大时成本高；虽可通过子采样缓解，但非完全可伸缩。
- **模态依赖**：理论基于高斯桥假设，扩展到其他模态（如文本、音频）需调整桥结构和后验形式。
- **安全问题**：如论文所述，若参考集合被恶意构造，可能生成有害或误导性内容，需审慎管理。
- **实验覆盖局限**：GenEval 对比中，搜索/梯度方法未获得视觉参考库，但论文明确说明这是在不同控制接口间的比较；更公平的做法可能是让所有方法都使用相同参考信息，但当前设计已足够说明 RMG 的效率优势。
