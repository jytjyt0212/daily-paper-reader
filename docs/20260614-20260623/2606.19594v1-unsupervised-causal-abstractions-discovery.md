## 摘要
因果抽象形式化了高层次结构因果模型（SCM）何时能够捕捉低层次SCM的干预行为。该概念的现有应用主要遵循假设检验范式：专家提出候选的高层次模型，然后评估低层次系统是否实现了它。我们研究直接根据低层次测量学习高层次模型的互补问题。我们的贡献利用了低秩因果发现的假设，可总结如下：(1) 我们证明了低秩图生成的观测会诱导形成因果抽象的潜变量，(2) 我们提供了关于这些潜变量的可辨识性结果，(3) 我们提出了一个实用的目标函数来学习这个高层次SCM。

## Abstract
Causal abstractions formalize when a high-level structural causal model (SCM) captures the interventional behavior of a lower-level SCM. Existing applications of this notion largely follow a hypothesis-testing paradigm: an expert proposes a candidate high-level model and then evaluates if the low-level system implements it. We study the complementary problem of learning a high-level model directly from low-level measurements. Our contributions leverage hypotheses from low-rank causal discovery, and can be summarized as follows: (1) we show that observations generated by a low-rank graph induce latents that form a causal abstraction, (2) we provide identifiability results about these latents, and (3) we propose a practical objective to learn this high-level SCM.

- **核心问题**：现有因果抽象研究主要依赖专家提出候选高层次模型，然后通过假设检验验证低层系统是否实现该模型。本文研究互补问题：**直接从低层观测数据无监督地发现高层次的因果抽象**，即自动学习一个高层 SCM，使其能够忠实地反映低层系统的干预行为。

### 论文提出的方法论

- **核心思想**：利用低秩图结构（factor DAGs, f-DAGs）假设，将低层变量间的因果图表示为两个布尔矩阵的酒神乘积 \(A = Q \diamond R^T\)，其中 \(Q\) 表示变量→因子的边，\(R\) 表示因子→变量的边。因子（latent factors）自然构成高层次的因果变量。
- **关键技术细节**：
  1. **因子 SCM 构造**：定义 f-SCM，其因果图为二分有向无环图，变量 \(X\) 和因子 \(Z\) 之间仅存在 \(X \to Z\) 或 \(Z \to X\) 的边。通过将因子机制 \(F_Z\) 和变量机制 \(F_X\) 组合，可得低层模型 \(L\)（仅含 \(X\)）和高层模型 \(H\)（仅含 \(Z\)）。
  2. **理论证明**：定理1证明，对于任意 f-SCM，所构造的 \(H\) 是 \(L\) 的 **均匀变换**（uniform (\(\tau-\omega\))-transformation），即存在状态映射 \(\tau\) 和干预映射 \(\omega\) 使得因果图交换。
  3. **可辨识性**：
     - 引入 **anchor 假设**：每个因子至少有一个 in-anchor（唯一父节点为该因子的变量）和一个 out-anchor（唯一子节点为该因子的变量）。
     - 定理2证明，在 anchor 假设下，布尔矩阵分解 \(A = Q \diamond R^T\) 在因子置换下唯一，从而 **f-DAG 可辨识**。
     - 定理3证明，若父机制 \(F_Z\) 是仿射的，则因子机制可恢复至仿射变换；若子机制 \(F_X\) 是仿射的，同样可恢复至仿射变换。
  4. **实际算法 UCAD**：
     - 将图结构参数化为可微的 Gumbel-softmax 分布，每个变量-因子对有三个可能：parent、child、无连接。
     - 优化目标：最大化条件对数似然（NLL），约束包括无环性（针对 f-DAG 的谱半径约束或分层约束）、anchor 约束（每个因子至少有一个 in-anchor 和一个 out-anchor）、稀疏约束（L1 范数）。
     - 采用增广拉格朗日方法（Cooper 库）求解约束优化。
