## 摘要
用于世界建模的联合嵌入预测架构（JEPA）通常采用固定规模的视觉 Transformer 编码器，这类编码器对简单任务过度配置，对复杂任务配置不足，并且注意力头之间存在显著冗余。我们提出逐次容量增长（SCG），一种从最小编码器（1 个注意力头、2 层、283K 参数）开始的方法，并以宽度（添加注意力头以增强低层语义容量）或深度（添加 Transformer 块以实现更高阶语义抽象）的方式增量增长，由任务无关的测试-验证机制驱动。该机制利用保函数扩展来安全地尝试架构变更，并在其未能改善预测损失时回滚。草图化各向同性高斯正则化器（SIGReg）确保所有学习到的语义维度保持统计独立，并与预测目标对齐，从而在架构增长时防止坍缩。在一个 60 维多物体动力学任务上，SCG 自然触发深度扩展，相较固定小基线将预测损失改善 20.3%，且参数效率是扩展至固定大模型的 56 倍；在一个 2D 导航任务上，单次宽度扩展相较固定大模型甚至带来 23% 的提升。在所有三个复杂度递增的测试环境中，自适应编码器达到或超过固定小基线，且零假阳性扩展，并保持比特级精确的函数保持（比值 = 1.0，绝对差 = 0.0）。结论是，JEPA 世界模型编码器无需预先按最大容量分配——它们可以随任务需求逐次增长，在保持表示质量的同时实现显著的计算与数据效率。

## Abstract
Joint-Embedding Predictive Architectures (JEPAs) for world modeling typically employ fixed-size Vision Transformer encoders that are over-provisioned for simple tasks and under-provisioned for complex ones, with significant redundancy across attention heads. We propose Successive Capacity Growth (SCG), a method that starts from a minimal encoder (1 head, 2 layers, 283K parameters) and grows incrementally in width (adding attention heads for low-level semantic capacity) or depth (adding transformer blocks for higher-order semantic abstraction), driven by a task-agnostic test-and-verify mechanism that exploits function-preserving expansion to safely trial architectural changes and roll back if they do not improve prediction loss. The Sketched Isotropic Gaussian Regularizer (SIGReg) ensures that all learned semantic dimensions remain statistically independent and aligned with the predictive objective, preventing collapse even as the architecture grows. On a 60-dimensional multi-object dynamics task, SCG naturally triggers depth expansion, improving prediction loss by 20.3% over the fixed small baseline with 56 times greater parameter efficiency than scaling to the fixed large model; on a 2D navigation task, a single width expansion yields even an 23% improvement over the fixed large model. Across all three tested environments of increasing complexity, the adaptive encoder matches or exceeds the fixed small baseline, with zero false-positive expansions and bit-exact function preservation (ratio = 1.0, absolute difference = 0.0). The take-away is that JEPA world model encoders need not be pre-allocated at maximum capacity - they can grow successively as the task demands, achieving significant compute and data efficiency while maintaining representation quality.

## 1. 核心问题与研究动机

- **背景**：JEPA（联合嵌入预测架构）世界模型（如 LeWM）通常使用**固定尺寸**的 ViT 编码器（ViT-Tiny：12 层、3 头、192 维、约 5M 参数）。
- **核心矛盾**：
  - 简单任务（如 2D 导航）被**过度配置**，浪费算力；
  - 复杂任务（如 60 维状态动力学）可能**容量不足**；
  - 固定大模型存在**结构性冗余**：3 个注意力头注意力图余弦相似度约 0.0001（作者称之为近似冗余），第 3–12 层残差比从 0.9 降至 0.15、层间余弦相似度达 0.99，说明大量深度层接近恒等变换。
- **研究缺口**：现有工作（Progressive Growing、bert2BERT、LiGO、递归 ViT 等）要么使用预定义增长计划，要么需要单独的增长训练阶段，**缺乏一个由任务预测能力在线驱动、无需按数据集调参的扩展触发机制**。
- **整体含义**：编码器容量不必预先按最大配置分配，可以随任务需求**逐次生长**，在保持表示质量的同时提升计算与数据效率。

## 2. 方法论：SCG

### 2.1 核心思想
- 从**最小编码器**起步：1 个注意力头、2 层、d_model=64、283K 参数。
- 通过**任务无关的测试-验证（test-and-verify）机制**，在训练过程中检测预测损失平台期，尝试**保函数扩展**：
  - **宽度扩展**：增加 1 个注意力头（d_model +64），提供低层语义容量（更多独立表示维度）；
  - **深度扩展**：增加 1 个恒等初始化的 Transformer 块，提供高阶语义抽象（层次化组合能力）。
- 每次扩展先试宽度、再试深度，失败则**完整回滚**（模型参数 + 优化器状态），若两者都无效则标记为已收敛。

### 2.2 关键算法流程
1. 每个有效 epoch 结束时，若未收敛且处于冷却期外，检查 `Lpred` 是否平台化：最近 2 个 epoch 的中位损失相对前 2 个 epoch 的中位损失改善 ≤ 2%。
2. 平台化后保存模型与优化器状态，记录 `ℓpre`。
3. 尝试**宽度扩展**（保函数），训练 2 个 epoch，得到 `ℓpost`；若 `ℓpost < 0.98·ℓpre`（改善 >2%），保留扩展并设置 2 epoch 冷却；否则回滚。
4. 回滚后尝试**深度扩展**，同样训练 2 epoch 并验证；成功则保留，失败则回滚并标记收敛。
5. 测试 epoch **不计入**有效 epoch 预算，保证与固定配置的公平比较。

### 2.3 保函数扩展的技术细节
- **宽度扩展（Net2Net 式复制）**：
  - patch embedding、CLS token、位置嵌入：复制前 64 维；
  - QKV 投影：新头的 QKV = 头 0 的副本；
  - **输出投影：新头对应行置零**（初始贡献为零，但 QKV 有有意义初始化）；
  - MLP：复制前 64 维；Projector：输入权重零填充。
- **深度扩展（恒等块）**：
  - 注意力输出投影权重与偏置 = 0；
  - MLP 第二层权重与偏置 = 0；
  - LayerNorm 权重 = 1、偏置 = 0；
  - 使新块满足 g(y)=y，从而 f∘g∘h = f∘h。
- **理论保证**：
  - 结构不变性使扩展前后映射完全相同（f_W′(x)=f_W(x)）；
  - 由于函数保持，试错不扰动损失景观；回滚恢复精确参数与 Adam 动量，优化轨迹连续、无灾难性遗忘。
- **损失函数**（沿用 LeWM，无 stop-gradient）：
  - L_total = (1/3)Σ_{i=0}^{2} MSE(ẑ_{i+1}, z_{i+1}) + λ·L_SIGReg(Z)，λ=0.1；
  - SIGReg 通过特征函数匹配的 Epps-Pulley 正态性检验，确保新增语义维度统计独立、与预测目标对齐，防止表征坍缩。
- **瓶颈分解理论**：
  - **表示瓶颈**（任务内在维度 > d_model）→ 只能靠宽度扩展解决；
  - **计算瓶颈**（需要高阶非线性交互但深度不足）→ 只能靠深度扩展解决；
  - 触发机制无需显式诊断，只需依次检验两个假设。
