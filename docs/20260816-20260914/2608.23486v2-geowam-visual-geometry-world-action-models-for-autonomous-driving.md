## 摘要
世界动作模型（WAMs）近来作为在自动驾驶中联合建模场景演化与自车动作的框架而受到越来越多的关注。大多数现有 WAM 通过将用于未来观测预测的视频生成主干网络与用于自车轨迹预测的动作头相结合，在像素空间中学习场景动力学。然而，像素仅提供这些动力学的间接表示：它们将几何与运动同外观、纹理和光照纠缠在一起，迫使模型从二维观测中推断三维变换。我们认为，以点云表示的几何为驾驶提供了更自然的状态空间，因为它显式地捕捉空间结构以及支配场景演化的刚性与非刚性变换，同时与执行驾驶动作所在的空间直接对齐。基于这一见解，我们提出 GeoWAM，一种面向自动驾驶的视觉几何世界动作模型。GeoWAM 并非预测未来图像，而是经过预训练来预测未来场景几何，从而产生联合编码空间结构与时间演化的表示。随后，一个以几何为条件的动作头利用这些学习到的几何动力学来预测未来的自车轨迹。大量开环和闭环评估表明，视觉几何世界建模产生的驾驶策略显著强于基于图像的替代方案，从而确立未来几何预测作为自动驾驶一种有效的预训练目标。

## Abstract
World action models (WAMs) have recently gained increasing attention as a framework for jointly modeling scene evolution and ego actions in autonomous driving. Most existing WAMs learn scene dynamics in pixel space by combining a video-generation backbone for future-observation prediction with an action head for ego-trajectory prediction. Pixels, however, provide only an indirect representation of these dynamics: they entangle geometry and motion with appearance, texture, and illumination, forcing the model to infer three-dimensional transformations from two-dimensional observations. We argue that geometry, represented by point clouds, offers a more natural state space for driving because it explicitly captures spatial structure and the rigid and non-rigid transformations that govern scene evolution while directly aligning with the space in which driving actions are executed. Building on this insight, we introduce \textbf{GeoWAM}, a visual geometry world action model for autonomous driving. Rather than predicting future images, GeoWAM is pretrained to forecast future scene geometry, yielding representations that jointly encode spatial structure and temporal evolution. A geometry-conditioned action head then leverages these learned geometric dynamics to predict future ego trajectories. Extensive open-loop and closed-loop evaluations show that visual geometry world modeling yields substantially stronger driving policies than image-based alternatives, establishing future-geometry prediction as an effective pretraining objective for autonomous driving.

## 1. 核心问题与研究动机

- **背景定位**：自动驾驶本质是"预测"问题——智能体不仅要理解当前场景，还要预判场景如何演化以及这种演化如何约束自身动作。当前主流路线分两类：VLA（视觉-语言-动作）模型擅长高层语义理解与决策，但其以动作为中心的训练目标不显式监督未来场景演化；世界模型则通过学习环境如何演化来提供互补基础，近期多依赖高容量视频生成主干预测未来观测。
- **WAM 的定位**：世界动作模型（World Action Models, WAMs）把未来状态预测与轨迹生成耦合起来，使同一表示既能刻画世界如何演化，又能刻画自车应如何行动。但**大多数现有 WAM 沿用视觉世界模型的表示设计，以图像/视频作为观测空间**。
- **核心论点**：**像素不是建模驾驶动力学的理想状态表示**。图像虽视觉丰富，却只是间接编码几何与运动，将其与外观、纹理、光照纠缠在一起；视频世界模型被优化的目标是未来视觉观测的分布，并不要求显式恢复生成这些观测的底层物理动力学——模型可通过捕捉视觉时空规律性产生"看起来合理"的未来，而底层三维变换仍是隐式的、难以从生成观测中恢复。
- **几何的优势**：以点云为代表的几何为驾驶提供了**原生状态空间**——显式编码环境三维结构；随时间变化的几何直接揭示物体运动与自车参考系变换，无需光度重建；且场景几何与自车轨迹定义在**同一三维坐标系**中，因此预测未来几何为支撑安全规划与控制的空间结构与场景动力学提供了直接监督。
- **整体含义**：GeoWAM 提出以几何作为世界动作模型的状态空间，把几何演化置于观测与动作之间，确立"未来几何预测"作为自动驾驶的有效预训练目标。

## 2. 方法论

### 2.1 核心思想
- 放弃预测未来图像，改为**预训练预测未来场景几何**，得到联合编码空间结构与时间演化的表示；再用**几何条件动作头**基于学到的几何动力学预测未来自车轨迹。
- 采用**两阶段训练**：阶段一（几何世界模型预训练）预测稠密未来场景几何；阶段二（动作建模）扩展为完整 WAM，联合微调未来几何预测与轨迹规划。
- 动作分支遵循**类逆动力学（inverse-dynamics-like）范式**：先从预测的场景演化推断未来自车运动，再将该运动表示映射为轨迹。

### 2.2 阶段一：视觉几何世界模型
- **多视角几何编码**：输入 K 帧多视角图像历史（V 个相机），采用 DVGT-2 作为几何编码器 E_θ，保留 L 个选定特征层级。每个时刻、每个层级输出两类 token——几何 token X（每视角 P=hw 个，表示各视角观测到的空间结构）与 ego token E（每视角 N_e 个，编码历史自车运动上下文），沿 token 维拼接为 Z=[X;E]，构成完整历史几何记忆 Z_t = E_θ(I_{t-K+1:t})。
- **未来几何解码**：以学习到的几何查询种子 q_geom 为基础，为每个未来步、相机视角、空间位置构造查询：**q_geom + 时间嵌入 + 视角嵌入 + 二维正弦位置嵌入**。解码器每层两步更新：先做**因果时间自注意力**（建模同一空间位置在 F 个未来步上的演化），再**交叉注意力到历史记忆 Z_t** 检索观测场景的上下文。堆叠多层后得到未来几何隐变量 Û_{t+k}；对每个特征层级用输出投影 W_ℓ 映射到几何头所需特征空间，得到多层级未来场景表示 X̂^ℓ。共享几何头 G_ψ 将其解码为**稠密点图 P̂ 与逐像素置信度图 Ĉ**（每像素一个自车坐标系下的三维点）。模型因此**无需重建未来图像外观**即可预测几何场景演化。
- **未来几何监督**：
  - **特征级对齐**：未来图像经同一几何编码器的目标分支得到 patch 特征目标 X̄，目标特征**脱离计算图**（stop-gradient），未来图像**从不提供给预测分支、推理时也不使用**；用余弦距离对齐预测特征与目标特征（L_feat）。
  - **点图监督**：由稠密未来点图目标与有效性掩码监督，目标函数包含**欧氏点回归 + 置信度感知回归 + 多尺度表面法向一致性**（L_future point = L_reg + L_conf + L_normal）。
  - 对编码后的当前帧施加同一点图目标（L_current point）以**锚定几何编码器**，同时让它学习预测。
  - 预训练总损失：**L_pre = L_feat + L_future point + L_current point**。

### 2.3 阶段二：GeoWAM 动作分支
- **未来 ego token 解码**：引入 N_e 个学习到的 ego 查询种子，为每个未来步与视角构造查询（种子 + 时间嵌入 + 视角嵌入）。每层先做**逐视角、逐 ego-token 槽位独立的因果时间自注意力**（跨 F 个未来步），再**同时交叉注意力到历史几何记忆 Z_t 与预测的未来几何 token Û_{t+1:t+F}**，得到与预测场景演化一致的未来 ego token Ê_{t+1:t+F}。
- **stop-gradient 设计**：预测未来几何以 **sg(·)** 形式接入，轨迹损失不反传至预测几何，从而**保持预训练获得的几何预测能力**；这种单向连接也契合逆动力学设计——自车运动由场景演化推断，而轨迹监督不反过来重塑作为其条件信号的几何。
- **轨迹解码**：动作头取最深层历史 ego token E^L_{t-K+1:t} 与预测未来 ego token Ê 拼接，用**因果时间 transformer** 精炼，使每个未来 ego token 融入此前历史与预测的运动上下文；再由**学习到的轨迹查询交叉注意力**到精炼后的特征，回归头输出单一未来轨迹 Â_t = [â_{t+1},...,â_{t+F}]，每个 â=(x, y, θ) 为当前坐标系下的平面位置与航向。动作头**直接回归单条轨迹，不使用轨迹 anchor、模式分类或迭代采样**。
- **规划目标**：微调时保留未来与当前几何目标，轨迹用 ℓ1 回归损失 L_traj，并额外用辅助 ℓ1 损失 L_pose 预测历史帧间相对位姿。总目标 **L_plan = L_pre + λ_traj·L_traj + λ_pose·L_pose**，两个权重均设为 5。

4. **实证充分性**：在 nuScenes 几何预测、NAVSIM v2 navtest 与 navhard（含伪闭环）上均取得领先，并给出定性可视化支撑。

## 7. 局限性与可讨论点

- **算力与效率信息缺失**：未报告 GPU 资源、训练时长、参数量与推理延迟，无法评估几何路线的实际部署成本，也无法与视频世界模型做公平的效率对比。
- **依赖外部几何编码器与重建器**：方法以 DVGT-2 为几何编码器、以 DVGT 重建视频基线输出，性能部分受上游几何模型质量约束；对比中视频世界模型被"生成 + 重建"两段流程拖累，可能低估其直接几何化改造后的潜力。
- **评测范围**：几何预测仅在 nuScenes 验证集评估，规划评测限于 NAVSIM 体系，尚未在真实闭环或更多驾驶数据集（如 Waymo 闭环、CARLA 闭环）上验证泛化性。
- **伪闭环的近似性**：navhard 用 3D Gaussian Splatting 重建近似闭环，与真实闭环仍有差距，对闭环鲁棒性的结论需谨慎外推。
- **单一轨迹回归**：动作头直接回归单条轨迹、不使用 anchor 或多模态采样，在高度多模态的交互场景下可能限制其表达上限，多模态与不确定性建模是潜在改进方向。
- **表征粒度**：几何 token 主要编码静态空间结构与自车运动，对语义（如交通参与者意图、可通行语义）的显式建模较弱，几何与语义的融合值得进一步探索。
