## 摘要
因果表示学习（CRL）旨在从高维观测中恢复潜在因果变量及其结构关系。现有 CRL 方法通常假设所有环境都定义在同一组潜在变量上，或至少共享一个共同的潜在表示空间。我们研究一种碎片化多客户端设定：多个客户端与同一个全局潜在因果系统交互，但每个客户端仅能访问并干预潜在变量的一个子集。在这种情形下，对未使用的潜在变量进行边缘化会引入双向边，因此单个客户端不再能给出节点级潜在因果图，全局潜在因果顺序必须通过组装各客户端特有的结构片段来恢复。我们提出 Jigsaw-CRL，一个从这种碎片化干预中恢复全局潜在因果顺序的框架。在软干预下，不同环境间精度矩阵的差异呈现出由潜在祖先关系支配的低秩结构。这使得能够为每个客户端恢复块划分、相应的块级祖先顺序以及潜在子空间，然后将这些片段组装成全局节点级潜在因果顺序。我们建立了可识别性保证，开发了实用算法，并在合成数据上验证了该框架。我们的代码可在 https://anonymous.4open.science/r/code-for-Jigsaw-CRL-7B26 获取。

## Abstract
Causal representation learning (CRL) aims to recover latent causal variables and their structural relations from high-dimensional observations. Existing CRL methods typically assume that all environments are defined over the same latent variables, or at least share a common latent representation space. We study a fragmented multi-client setting, where multiple clients interact with the same global latent causal system but each client only accesses and intervenes on a subset of the latent variables. In this regime, marginalizing unused latent variables induces bidirected edges, so a single client no longer admits a node-wise latent causal graph, and the global latent causal order must be recovered by assembling client-specific structural fragments. We propose \textbf{Jigsaw-CRL}, a framework for recovering global latent causal order from such fragmented interventions. Under soft interventions, differences between precision matrices across environments exhibit a low-rank structure governed by latent ancestor relations. This enables recovery, for each client, of a block partition, the corresponding block-level ancestral order, and latent subspaces, and then assembly of these fragments into the global node-level latent causal order. We establish identifiability guarantees, develop practical algorithms, and validate the framework on synthetic data. ## 1. 核心问题与整体含义

- **研究背景**：因果表征学习（CRL）通常假设所有环境共享同一组潜在变量或同一潜在表示空间，目标是恢复节点级潜在因果结构。
- **核心问题**：论文研究“碎片化多客户端”设定：多个客户端共享同一个全局潜在因果系统，但每个客户端只能访问并干预潜在变量的一个子集。
- **关键困难**：客户端未使用的潜在变量被边缘化后，会引入：
  - 有向捷径边；
  - 由共同未观测变量导致的双向边。
  因此，单个客户端面对的局部因果对象不再是普通 DAG，而是**块结构混合图**，节点级因果恢复一般不可行。
- **整体含义**：论文提出两层次可识别性框架：
  - 单客户端只能恢复“块级因果片段”；
  - 多客户端互补片段可拼装出“全局节点级潜在因果序”。
- **目标**：从多个碎片化客户端的软干预数据中，恢复全局潜在祖先关系/因果顺序。

## 2. 方法论

### 2.1 问题建模

- 全局潜在变量满足线性结构方程：
  - \(Z = AZ + E\)，\(A\) 在拓扑序下严格上三角；
  - 噪声协方差归一化为 \(\Sigma = I\)。
- 客户端 \(k\) 只使用潜在变量子集 \(O_k\)，观测为：
  - \(X_k = G_k Z_k\)，\(G_k\) 列满秩，\(H_k = G_k^\dagger\)。
- 软干预只作用于单个潜在节点，改变该节点的父系数和噪声方差。
- 使用二阶信息：
  - \(\Theta_k^{(j)} = \mathbb{E}(X_k^{(j)} X_k^{(j)\top})^\dagger\)；
  - 并满足：
    \[
    \Theta_k^{(j)} = H_k^\top (I - A_k^{(j)})\Sigma_k^{(j)-1}(I - A_k^{(j)})^\top H_k.
    \]

### 2.2 客户端局部对象：块结构混合图

- 边缘化未使用变量后，客户端局部图包含：
  - 有向边 \(E_k\)；
  - 双向边 \(D_k\)。
- 定义“互达”关系：节点间通过有向祖先路径或双向边路径互相可达。
- **块**：互达等价类，块内节点在单客户端视角下结构纠缠。
- **块级祖先序**：块之间仍保留可识别的祖先关系。
- 命题 2 说明：
  - 非祖先块之间不存在节点级祖先关系；
  - 块级父关系对应真实的节点级父子关系。

### 2.3 核心技术：低秩精度扰动 + 块 RQ 分解

- 引入块 RQ 分解：
  - \(H_k = R_k Q_k\)；
  - \(R_k\) 关于块结构上三角；
  - \(Q_k\) 行正交于严格块祖先方向。
- **Lemma 1**：单节点软干预引起的精度矩阵扰动 \(\Theta_k^{(j)} - \Theta_k^{(0)}\) 的秩最多为 2。
- **Lemma 2**：若干预目标在块 \(C_{k,a}\)，则扰动行空间包含于该块及其块祖先对应的 \(Q_k\) 行空间中。
- 由此可通过“投影后秩”判断干预标签对应的块及其祖先关系。

### 2.4 算法流程

- **Algorithm 1：ID-Block-Ancestor**
  - 给定候选干预标签集与已恢复祖先子空间；
  - 逐个移除已恢复块，检查投影后秩是否仍等于候选集大小；
  - 判断哪些已恢复块是当前新块的块级祖先。
- **Algorithm 2：ID-Block-Causal-Order**
  - 迭代寻找最小标签子集 \(\hat C\)，使投影后扰动行空间维度等于 \(|\hat C|\)；
  - 恢复一个完整块；
  - 调用 Algorithm 1 确定其块祖先；
  - 更新块划分、块级祖先序和 \(\hat Q_k\)。
- **Algorithm 3：ID-Global-Causal-Order**
  - 收集所有客户端中“单例块之间的块级父关系”；
  - 构造有向关系 \(\tilde\prec\)；
  - 取传递闭包得到全局潜在祖先序 \(\hat\prec\)。

### 2.5 理论保证

- **Theorem 1**：在 Assumption 1–2 下，单客户端可恢复：
  - 块划分；
  - 块级祖先序；
  - 块关联行子空间；
  - \(\hat Q_k = S_k P_{\sigma,k} Q_k\)，其中 \(S_k\) 为块对角可逆矩阵，\(P_{\sigma,k}\) 为保块序的行置换。
- **Corollary 1**：恢复的潜在变量 \(\hat Z_k = \hat Q_k X_k\) 可识别到“块级祖先混合”程度。
- **Theorem 2**：在 Assumption 1–3 下，多客户端片段拼装后可恢复全局节点级潜在祖先关系。
