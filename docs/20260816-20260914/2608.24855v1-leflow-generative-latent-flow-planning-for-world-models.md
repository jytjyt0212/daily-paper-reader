## 摘要
潜在世界模型本质上是强大的编码器，可将图像像素转换为潜在嵌入，然而现有世界模型仍依赖在线轨迹优化进行动作规划：对于每个状态-目标对，都从头运行迭代优化器以搜索最优动作序列，将世界模型视为黑箱模拟器。这种做法在每次重新规划步骤中都要重新付出完整的迭代优化代价，并且不在不同查询之间复用任何规划经验。在这项工作中，我们探讨一旦潜在世界模型学习完成后，规划本身能否被摊销。我们提出 LeFlow，它学习一个可复用的潜在轨迹先验，直接在世界模型的潜在动力学空间中运行。LeFlow 将规划重塑为条件潜在轨迹生成：一个整流流模型想象当前嵌入与目标嵌入之间的未来潜在路径，一个逆动力学解码器将潜在转移转换为动作块，而冻结的世界模型通过自回归推演验证每个候选。在四个主要的目标条件像素控制基准上，LeFlow 用摊销式潜在规划与固定预算的推演选择取代迭代动作空间优化，在规划时间减少一个数量级的同时取得了一致的成功率提升。我们的结果表明，潜在世界模型不仅应支持预测，还应支持可复用的规划先验。我们的代码见 https://github.com/hsiangwei0903/LeFlow。

## Abstract
Latent world models are inherently strong encoders that transform image pixel to latent embedding, yet existing world models still rely on online trajectory optimization for action planning: for every state-goal pair, an iterative optimizer is run from scratch to search for optimal action sequences, treating the world model as a black-box simulator. This approach pays the full iterative optimization cost anew at every replanning step and reuses no planning experience across queries. In this work, we ask whether planning itself can be amortized once a latent world model has been learned. We present LeFlow, which learns a reusable latent trajectory prior operating directly in the latent dynamics space from the world model. LeFlow recasts planning as conditional latent trajectory generation: a rectified-flow model imagines a future latent path between the current and goal embeddings, an inverse dynamics decoder turns latent transitions into action chunks, and the frozen world model verifies each candidate by autoregressive rollout. Across four major goal-conditioned pixel-control benchmarks, LeFlow replaces iterative action-space optimization with amortized latent planning and fixed-budget rollout selection, achieving consistent success-rate gains with an order-of-magnitude reduction in planning time. Our results argue that latent world models should support not only prediction but reusable planning priors. Our code is available at https://github.com/hsiangwei0903/LeFlow.

## 1. 核心问题与整体含义（研究动机与背景）

- **背景**：世界模型让智能体通过模拟动作后果来规划；JEPA 类模型（如 LeWM）在紧凑潜在空间中建模动力学，已成为**强大的预测器**。LeWM 可从原始像素端到端稳定训练，在 2D/3D 控制任务上具竞争力。
- **核心问题**：规划环节没有跟上。现有做法仍把世界模型当作**黑箱模拟器**，对每个状态–目标对用 CEM 等在线优化器从头搜索动作序列：
  - 每次重规划都要重新付出完整的迭代优化代价（每步查询世界模型数千次）；
  - 不同查询之间**不复用任何规划经验**；
  - 世界模型虽蕴含"哪些轨迹值得考虑"的结构知识，却从未被用于提供先验。
- **整体含义/主张**：规划本身可以被**摊销（amortize）**——一旦世界模型学好，就应离线学习一个**可复用的潜在轨迹先验**。作者据此提出 LeFlow，并主张：潜在世界模型不仅应支持预测，还应支持可复用的规划先验。

## 2. 方法论

### 2.1 核心思想
- **规划空间的选择是关键设计问题**：不在动作空间规划，而在**潜在状态空间**规划。
  - 动作序列维度高、多模态强（多条动作序列实现同一状态轨迹），且与世界模型内部几何解耦；
  - 潜在状态轨迹更低维、更平滑、已按预测器动力学组织，且**动作无关**（planner 只决定"该在哪"，"怎么去"交给解码器）。
- 将规划重塑为**条件潜在轨迹生成**：生成一条潜在路径 → 逆动力学解码为动作 → 用冻结世界模型推演验证。

### 2.2 三大模块（在冻结 LeWM 之上，仅训练两个模块）
- **潜在流规划器（Latent Flow Planner）**：
  - 起点/终点由构造**夹紧**：z₀ = enc(当前观测)，z_H = enc(目标观测)，模型只生成 H−1 个内部潜在状态；
  - 用**条件整流流（rectified flow）**建模内部路径，学习速度场 v_ψ 把高斯噪声沿直线插值输运到数据样本；
  - 训练目标（式 2）：`L_flow = E‖v_ψ(u_τ, τ | z_start, z_goal) − (u₁ − u₀)‖²`；
  - 选整流流而非扩散的理由：直线输运可用**极少 Euler 步（16 步）**积分，与候选数 N 无关，适合每步重规划生成 N 条路径。
- **逆动力学解码器（Inverse Dynamics Decoder）**：
  - 逐转移局部解码：`a_t = g_ω([z_t, z_{t+1}, z_{t+1} − z_t])`，显式加入**位移特征**提供方向信息、改善回归条件数；
  - 损失（式 4）：`L_inv = E‖g_ω(·) − a_t‖²`（对归一化动作块）；
  - 潜在空间的逆动力学歧义远小于像素空间（编码器已把多种观测折叠为同一潜在）。
- **Rollout 重排序（Rollout Reranking）**：
  - 动机：生成模型不保证动态可实现，可能穿过"**可控潜在流形**"之外的区域；
  - 做法：采样 N 条候选 → 解码动作 → 经冻结预测器自回归推演得到真实终端潜在 ẑ_H^(i) → 按 `score(i) = ‖ẑ_H^(i) − z_goal‖²` 排序，取最小者执行；
  - 这是**推理期、仅选择**的操作，不改变流模型分布。

### 2.3 训练与推理
- 总目标（式 6）：`L = L_flow + L_inv + λ_cons · L_cons`，默认 λ_cons = 0.1。
- **一致性损失 L_cons**（式 7）：对生成转移解码出动作后，单步过冻结预测器，惩罚 `‖pred_ϕ(z_t, â_t) − z_{t+1}‖²`，把预测器动力学蒸馏进规划器，减少被重排序丢弃的比例。
- 设计权衡：λ_cons 过大会把流模型分布塌缩到预测器的**近视单步推演**，丧失多步规划多样性。
- **推理流程**：编码当前/目标 → 并行采样 N 条潜在路径（16 Euler 步）→ 解码动作 → 冻结 LeWM 推演重排序 → 执行最优动作块；运行在**滚动时域 MPC 循环**中。**完全无在线优化循环**，计算主要来自 N 条可并行的 GPU rollout。
- **架构细节**：流速度模型为 4 层 Transformer 编码器（d=512，8 头，FFN=2048，正弦时间嵌入 64 维经两层 SiLU）；解码器为 3 层 MLP（隐藏 512，LayerNorm+GELU）；AdamW（lr=1e-4，wd=1e-4），10 epoch，batch 128，余弦退火，梯度裁剪 1.0；推理 N=64，16 步 Euler。

- **问题重构有洞察力**：把"在线优化"转为"离线摊销的生成式先验"，并给出"为什么在潜在空间而非动作空间规划"的清晰论证（多模态折叠、更低维、贴合预测器几何、动作无关）。

**理论刻画不足**：对"为什么潜在空间规划更易学"只有直觉论证（多模态折叠、维度更低），没有形式化刻画，例如未给出潜在逆动力学的可辨识性条件、也未分析流模型误差与最终任务成功率之间的传播界；重排序为何有效、在什么条件下有效，同样缺少理论或定量诊断（如被丢弃候选的比例、其终端误差分布）。这使得若干设计选择（N、λ_cons、Euler 步数）更多依赖经验调参而非可预期原理。

## 9. 总体评价与启示

- **定位与贡献层级**：LeFlow 的核心贡献不是新世界模型，也不是新生成模型架构，而是**规划范式的重定位**——把"世界模型 + 在线优化器"的推理时搜索，改写为"世界模型 + 离线摊销的潜在轨迹先验 + 推理期选择"。在这个意义上，它与"用生成模型做决策"（diffusion policy、decision transformer 等）同属一条脉络，但明确把生成对象从动作序列搬到**潜在状态轨迹**，并让冻结的预测器充当验证器，这一组合是其最可辨识的贡献点。
- **方法上的"最小充分"取向**：整流流（16 步）、4 层 Transformer、3 层 MLP 解码器、单一一致性正则——组件都偏轻量，说明收益主要来自**问题表述**而非模型容量。这既提升了可复现性，也让"骨干冻结、增益可归因于规划器"的因果叙事更可信。
- **实验叙事的强项与弱项**：强项是变量控制干净（同一冻结骨干、同一协议下与 CEM/iCEM/MPPI 对比）、消融逐项隔离、主动排除饱和基准、并额外提供留出泛化与跨骨干迁移；弱项是任务集全部来自单一官方套件、地平线固定在 H=5、跨骨干仅单任务，因此结论的**外部有效性**仍属"该基准族内成立"。
- **效率主张的边界**：14.4×/11.4×/11.7×/4.5× 的端到端加速是可信且显著的，但论文自己也承认端到端时间被环境步进与渲染稀释，规划器侧加速实际更大。反过来，离线训练成本未披露，"摊销"的净收益因此**无法闭环核算**——这是一个可修复、但确实存在的论证缺口。
- **最值得追问的一点**：既然重排序可以靠 rollout 把候选拉回可控流形，那流模型本身的"覆盖质量"在多大程度上仍是瓶颈？H=20 时 6% 的成功率提示，短地平线下重排序足以兜底，长地平线下生成误差与预测器误差会相互放大，二者的**误差归因尚未被分离测量**。这既是该工作最清晰的可扩展性瓶颈，也是后续工作（分层规划、带不确定性的重排序、联合微调预测器）最自然的切入点。

## 10. 一句话概括

LeFlow 论证并验证了：世界模型一旦学好，规划就不必每次从零搜索——把规划摊销为一个在潜在状态空间上的条件生成先验，再用冻结预测器做 rollout 选择，即可在短地平线目标条件控制任务上同时获得更高的成功率与一个数量级的推理加速；其主要未解问题是长地平线、复杂环境与离线训练成本的核算。
