## 摘要
视频联合嵌入预测架构（V-JEPA）通过自监督潜在特征预测从视频中学习强大的时空表征。然而，V-JEPA 围绕随机掩码补全和确定性回归构建，使其从根本上不适合自动驾驶规划，因为后者要求与动作紧密耦合的未来导向预测。为此，我们重新思考 V-JEPA 范式，并提出 WA-JEPA，一种专为自动驾驶规划设计的 V-JEPA 原生世界-动作模型。WA-JEPA 不采用随机时空掩码，而是采用混合未来掩码预训练，模型从观测上下文中推断未来潜在表示。不同于确定性回归，我们将未来预测重新表述为潜在未来上的条件流匹配，这显著提升了模型为下游规划生成合理未来潜在表示的能力。最后，我们提出联合未来-动作预测器，在统一的时空潜在空间中对未来场景 token 和自车轨迹一起去噪，使动作监督能够直接塑造与规划相关的世界表征。在 nuPlan 视频上预训练并在 NAVSIM 上微调后，WA-JEPA 在 NAVSIM-v2 上达到 91.7 EPDMS，超过最强的端到端和世界-动作基线 1.6 和 1.3 EPDMS；并且，在相同评估协议下，无需针对 HUGSIM 的特定微调，就在闭环 HUGSIM 基准上取得最佳 HD-Score 0.4462。这些结果验证了 V-JEPA 原生世界-动作建模是一种强大且可扩展的自动驾驶规划范式。代码见 https://github.com/AFARI-Research/WA-JEPA。

## Abstract
Video Joint Embedding Predictive Architecture (V-JEPA) learns powerful spatiotemporal representations from video through self-supervised latent feature prediction. However, V-JEPA is built around random-mask completion and deterministic regression, making it fundamentally ill-suited for autonomous driving planning that demands future-directed prediction tightly coupled with action. To address this, we rethink the V-JEPA paradigm and present WA-JEPA, a V-JEPA-native world-action model designed for autonomous driving planning. Instead of random spatiotemporal masking, WA-JEPA employs hybrid future-masked pre-training, where the model infers future latents from observed context. Departing from deterministic regression, we recast future prediction as conditional flow matching over latent futures, which substantially improves the model's ability to generate plausible future latents for downstream planning. Finally, a joint future-action predictor is proposed to denoise future scene tokens and ego trajectories together in a unified spatiotemporal latent space, allowing action supervision to directly shape planning-relevant world representations. Pre-trained on nuPlan videos and fine-tuned on NAVSIM, WA-JEPA reaches 91.7 EPDMS on NAVSIM-v2, surpassing the strongest end-to-end and world-action baselines by 1.6 and 1.3 EPDMS, and, without HUGSIM-specific fine-tuning, attains the best HD-Score of 0.4462 on the closed-loop HUGSIM benchmark under the same evaluation protocol. These results validate V-JEPA-native world-action modeling as a powerful and scalable paradigm for autonomous driving planning. Code is available at https://github.com/AFARI-Research/WA-JEPA.

## 1. 核心问题与研究背景

- **端到端自动驾驶的困境**：E2E 方法直接将原始传感器观测映射为驾驶动作，避免模块化流水线的误差累积与计算冗余；但传统 E2E（如 SparseDrive、VAD）依赖检测、分割、占据预测等**领域专用感知监督**，缺乏显式推理能力，在稀有与长尾场景中鲁棒性受限。
- **两条新兴推理路线**：
  - **VLA 范式**：借助 VLM 的语言理解能力做决策，但多数方法只是"稠密视觉→稀疏动作"的直接映射，存在严重的**监督赤字**（supervision deficit），信息瓶颈大、约束弱。
  - **世界-动作模型（WAM）**：用视频生成模型的像素级未来预测提供稠密自监督，无需昂贵的感知标注，且不依赖语言推理，更贴合驾驶中的视觉前瞻。但多数视频生成式 WAM 在 **VAE 压缩潜空间**中做世界建模，表征的时空语义贫乏，可能限制对驾驶世界的理解与推理。
- **V-JEPA 的潜力与错配**：V-JEPA 系列通过特征级掩码建模，从海量视频中自监督学习时空表征，语义丰富、迁移性强。但论文指出其**三大架构性缺陷**，使其不适合规划：
  1. **随机时空掩码**本质是"补全"目标，缺少规划所需的前向（future-directed）预测能力；
  2. **确定性回归**适合填补已观测上下文中的缺失 patch，却不足以生成完全未见过的未来 token（本质需要生成式建模）；
  3. 即便微调为动作条件未来预测，仍需目标图像 + **MPC 多轮优化**才能恢复动作，远达不到交互式在线规划。
- **核心命题**：能否在保留 V-JEPA 表征能力的同时，赋予其因果式未来生成能力并与动作联合建模？作者提出 **WA-JEPA**——V-JEPA 原生的世界-动作模型。

## 2. 方法论

### 2.1 预备与问题形式化

- V-JEPA 2 的原始目标：给定掩码观测 α 与目标观测 β，用潜在预测器 Pψ 从上下文潜变量推断目标潜变量，采用 **L1 损失**，目标编码器由 **EMA** 更新（动量系数 μ）。
- WA-JEPA 将端到端驾驶形式化为**条件未来-动作生成**：输入历史多视角观测 X₁:ₕ、自车状态 s、历史动作 Y₁:ₕ，输出未来 K 步的 (x̂ₖ, ŷₖ, φ̂ₖ)（位置与航向）。

### 2.2 总体架构：两阶段训练

- **Stage 1**：在多视角驾驶数据上适配预训练 V-JEPA 2，采用混合掩码预测未来表征，**无动作监督**。
- **Stage 2**：加入动作监督，把预测器扩展出动作流，**联合**预测未来场景表征与自车动作。

### 2.3 Stage 1：混合未来掩码预训练

- **骨干与多视角处理**：以预训练 **V-JEPA 2 ViT-L** 为视觉编码器；每个训练样本含 C 个同步相机的历史帧与未来帧，每条相机流被视为独立视频、由共享在线编码器独立处理。**历史 token 始终可见，仅对未来 token 施加掩码**。
- **混合掩码策略**：
  - *Full-mask*：所有未来 token 均为预测目标，只能从历史上下文预测，强制严格的因果"过去→未来"动态；
  - *Patch-mask*：保留部分未来 token 作为可见条件，预测其余被掩码 token，降低学习难度并保留 V-JEPA 2 的部分掩码范式；
  - 二者提供**互补训练信号**。
- **上下文与条件 token**：历史帧输出为上下文场景 token Z_ctx = Eθ(X₁:ₕ)；未来帧先按掩码模式 M^(m) 送入在线编码器，再用掩码感知的 fill-and-scatter 算子 Φ^(m) 把编码后的可见 token 散射回原位、其余位置填可学习 mask token，得到 Z_cond^(m)（Full-mask 下全部为 mask token）。
- **目标表征**：EMA 目标编码器给出无掩码的未来场景目标 Z*_future = Ēθ(X_{H+1:H+K})，仅用于提供潜在监督。

### 2.4 基于流匹配的潜在未来预测

- 将未来预测从回归改为**条件流匹配**，采用 **clean-latent（x-prediction）参数化**：采样高斯噪声 ε 与连续流时间 t，通过线性插值构造带噪未来 token **Zₜ = (1−t)ε + t·Z*_future**。
- 未来流预测器接收历史上下文 Z_ctx、未来条件 Z_cond、带噪未来 token Zₜ 与时间条件 t，直接预测**干净的未来场景 token** Ẑ_future。
- 预测器采用 **MMDiT 风格**设计，核心是上下文场景 token 与未来场景 token 之间的联合自注意力。
- **Stage 1 损失**：对未来干净潜变量做 MSE，目标端施加 **stop-gradient**。

### 2.5 Stage 2：联合世界-动作建模

- **仅使用 Full-mask**（与驾驶的因果性一致）；未来图像只用于构造未来场景潜变量的监督信号，**不作为学生预测器输入**。
- **动作 token 构造**：对真值未来动作归一化后按同样流插值构造带噪动作 Ỹₜ = (1−t)ε_y + t·Ȳ；动作 token T_act = Concat[Tₙ, T_h, T_s]，其中 Tₙ 为带噪动作的线性投影，T_h 为历史动作的 MLP 编码，T_s 为自车状态的 MLP 编码。
- **联合预测器双输出流**：同一 MMDiT 风格预测器分别输出未来场景流 Ẑ_future 与动作流 Ŷ̄；场景输出流对动作 token 施加 **stop-gradient**（前向可条件化，但场景损失不更新动作流），而动作流可关注可微的历史上下文与未来场景 token——这种**非对称梯度设计**让动作监督反塑场景表征，同时保留未来场景预测能力。
- **Stage 2 损失**：L = λ_future·L_future + λ_act·L_act，L_act 为归一化动作空间上 K 步未来动作的 MSE。
- **规划推理**：仅需历史多视角观测、历史动作与自车状态；未来场景潜变量与归一化动作均从高斯噪声初始化，每步预测干净端点并转换为线性流路径上的速度、迭代积分；采样后反归一化得到最终未来动作。**不需要未来图像或未来动作真值**。
