## 摘要
视觉-语言模型（VLM）提升了自动驾驶中的泛化能力和可解释性，但由于长视觉令牌序列（尤其在标准多视图设置下）而面临效率问题。现有的令牌剪枝方法采用固定剪枝率分配和静态重要性度量，忽略了动态的视图间重要性差异以及推理过程中信息重要性的演化。我们的分析表明，多视图VLM在深层中固有地编码了任务相关的视图先验，并表现出动态的信息需求。基于这些发现，我们提出了MVPruner，一种两阶段自适应令牌剪枝方法，使剪枝行为与模型的动态信息需求对齐。第一阶段根据每个视图的信息多样性分配剪枝预算，并保留在各阶段贡献一致的令牌，确保语义表示能力。第二阶段根据指令文本指导分配预算并选择令牌，以保证任务对齐。在四个基准上的实验结果表明了该方法的优越性能。例如，配备MVPruner的DriveMM在DriveLM基准上实现了87.3%的FLOPs减少、预填充阶段4.97倍加速，同时保留了98.5%的准确率。

## Abstract
Vision-Language Models (VLMs) improve generalization and interpretability in autonomous driving but suffer from efficiency issues due to long visual token sequences, particularly in standard multi-view settings. Existing token pruning methods employ fixed pruning rate allocation and static importance metrics, ignoring dynamic inter-view importance differences and the evolving information importance during inference. Our analysis reveals that multi-view VLMs inherently encode task-related view priors in deeper layers and exhibit dynamic information requirements. Motivated by these findings, we propose MVPruner, a two-stage adaptive token pruning method that aligns pruning behavior with the model's dynamic information requirements. The first stage allocates pruning budgets based on the information diversity of each view, and retains tokens with consistent contribution across stages, ensuring semantic representational capacity. The second stage allocates budgets and selects tokens guided by instruction text to guarantee task alignment. Experimental results on four benchmarks demonstrate the superior performance of our method. For example, DriveMM equipped with MVPruner achieves 87.3% reduction in FLOPs, 4.97* speedup in prefilling phase while retaining 98.5% accuracy on DriveLM benchmark.

## 二、方法论

### 核心思想
- 通过实验发现：多视图VLM在深层能有效识别任务相关视图（注意力分数指示），且跨层注意力模式从广泛全局关注逐渐聚焦到任务局部区域，呈现**动态信息需求**。
- 据此设计两阶段自适应剪枝框架 **MVPruner**，使剪枝行为与模型推理过程中不同阶段的信息需求对齐。

### 关键技术细节

#### 第一阶段（浅层，例如第0层之前）：多样性驱动剪枝
1. **Diversity-aware Ratio Allocation (DRA)**  
   - 计算每个视图内令牌间的余弦距离（1-cos），取每个令牌的最小距离作为其独特性分数，视图的多样性分数为所有令牌独特性均值。
   - 根据归一化多样性分数分配保留预算：信息更丰富的视图获得更大预算。
2. **Cross-stage Contribution-aware Token Selection (CCTS)**  
   - 目标：保留在当前阶段语义独特且对未来任务相关阶段有贡献的令牌。
   - 使用贪婪选择：初始化选中最具任务相关性的令牌（与指令文本的余弦相似度最高）；随后迭代加入候选令牌，选择使 **跨阶段贡献度**（独特性分数 × 任务相关性分数）最大的令牌，直至达到预算。

#### 第二阶段（深层，例如第16层之前）：任务相关性驱动剪枝
1. **Instruction-aware Ratio Allocation (IRA)**  
   - 利用深层跨模态注意力矩阵，计算每个视图所有令牌对指令文本的平均注意力分数作为语义相关性得分。
   - 基于相关性得分相对多样性得分的偏差进行补偿归一化，重新分配保留预算：任务相关视图保留更多令牌。
2. **Instruction-guided Token Selection**  
   - 直接选取得分最高的 $k_{2,p}$ 个令牌（按注意力分数），进一步增强任务对齐能力。

#### 总体流程
输入多视图图像 → 视觉编码器/投影得到初始令牌 → 第一阶段：DRA分配预算 + CCTS选择 → 第二阶段：IRA分配预算 + 指令引导选择 → 进入LLM生成响应。

## 七、优点

1. **创新性**：首次系统分析多视图VLM跨层注意力的演化规律，并以此指导剪枝设计。
2. **动态自适应**：根据场景和指令在线调整各视图剪枝率，避免固定策略的性能损失。
3. **两阶段对齐**：第一阶段保留语义覆盖，第二阶段聚焦任务相关，紧密契合模型推理需求。
4. **高性价比**：在极小性能损失（1.5%~2%）下，实现4~5倍预填充加速和大量FLOPs节省。
5. **普适性**：无需数据集特定的超参调优，在多个基准和模型上表现稳定。
6. **模块化设计**：各组件可独立替换或与其他剪枝方法结合。

## 八、不足与局限

1. **计算开销**：CCTS中逐视图的成对相似度计算（26.48 ms/视图）在视图数更多或令牌数更大时可能成为瓶颈。
2. **模型范围**：仅在7B/8B规模VLM上验证，未测试更大模型（如13B/70B）或不同架构的泛化性。
3. **输入模态**：仅考虑多视图图像，未融合LiDAR、雷达等互补模态（MAPLM虽含点云但作为单独任务输入）。
4. **指令依赖**：第二阶段依赖指令文本的注意力分数，若指令模糊或存在歧义（如无空间参照的问题），可能影响预算分配质量。
5. **实时部署**：剪枝本身引入额外延迟（虽仅占2.9%），但在超实时场景下仍需进一步优化。
6. **实验覆盖**：缺少与更激进剪枝率（如保留5%）或混合剪枝策略的对比；视频基准仅逐帧应用，未考虑帧间剪枝协同。
7. **消融敏感性**：部分设计选择依赖经验（如第二阶段层选择为第16层），缺乏跨模型或跨任务的自适应机制。
