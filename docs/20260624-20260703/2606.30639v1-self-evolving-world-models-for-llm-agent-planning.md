## 摘要
世界模型为长周期大语言模型智能体提供了一种原则性的方式来实现前瞻能力：在执行前预测行动后果。然而，不可靠的前瞻可能被忽略、误用，甚至降低下游决策质量。本文提出WorldEvolver，一种自我进化的世界模型框架，它在保持下游智能体和所有模型参数冻结的同时，修正其部署时的上下文。WorldEvolver集成了三个模块：（i）情节记忆，通过基于检索的模拟利用真实行动转移；（ii）语义记忆，从预测-观察不匹配中提取持久的启发式规则；以及（iii）选择性前瞻，在将低置信度预测整合到智能体推理上下文之前过滤它们。我们在ALFWorld和ScienceWorld上评估WorldEvolver，在Word2World上测量世界模型预测准确率，在AgentBoard上测量下游智能体成功率。大量实验表明，WorldEvolver在三个骨干网络上取得了最高的预测准确率，并在下游智能体成功率上领先其他世界模型基线，证明了测试时记忆修正增强了预测保真度和规划性能。

## Abstract
World models offer a principled way to equip long-horizon LLM agents with foresight: predictions of action consequences before execution. However, unreliable foresight can be ignored, misused, or even degrade downstream decision-making. In this paper, we introduce WorldEvolver, a self-evolving world model framework that revises its deployment-time context while keeping the downstream agent and all model parameters frozen. WorldEvolver integrates three modules: (i) Episodic Memory, which exploits real action transitions through retrieval-based simulation; (ii) Semantic Memory, which extracts persistent heuristic rules from prediction-observation mismatches; and (iii) Selective Foresight, which filters low-confidence predictions before integrating them into agent reasoning context. We evaluate WorldEvolver on ALFWorld and ScienceWorld, measuring world model prediction accuracy on Word2World and downstream agent success rate on AgentBoard. Extensive experiments show that WorldEvolver achieves the highest prediction accuracy across three backbones and leads other world model baselines on downstream agent success rate, demonstrating that test-time memory revision enhances both predictive fidelity and planning performance.

## 2. 方法论：核心思想、关键技术细节、算法流程
### 核心思想
- **不更新参数**：冻结世界模型和智能体策略的所有参数，仅通过**外部记忆上下文**的持续修订来改进预测。
- **三种记忆机制互补**：
  - **情节记忆（Episodic Memory, M<sub>E</sub>）**：存储已执行的真实转移（o<sub>t</sub>, a<sub>t</sub>, o<sub>t+1</sub>），通过基于动作的 Jaccard 相似度检索最相似的历史转移，作为预测的示例。
  - **语义记忆（Semantic Memory, M<sub>S</sub>）**：将预测-观察不匹配转化为持久的**启发式规则**（例如“检查物体不会移动它”），附带证据得分 e<sub>i</sub>，仅保留高分规则。
  - **选择性前瞻（Selective Foresight）**：基于生成序列的几何平均词概率计算置信度 q<sub>t</sub>，当 q<sub>t</sub> ≥ τ 时才将预测暴露给智能体，否则提供空信号（∅），避免不可靠预测误导。

### 关键技术细节
- **状态分解**：将原始文本观察通过映射函数 g 因子化为三元组（subject, predicate, object），用于精确比较预测与真实观察的差异。
- **语义规则生成**：由 LLM 批评器将不匹配因子三元组转为规则，并累积小批次（k<sub>MS</sub>）进行批量更新。
- **对齐机制**：智能体首先采样草稿动作 a<sub>t</sub><sup>(0)</sup> 并预测，但最终执行的动作 a<sub>t</sub> 可能不同，此时世界模型需用 a<sub>t</sub> 重新预测以确保学习信号与执行动作对齐。

### 算法流程（算法 1）
1. 智能体从策略 π<sub>θ</sub> 采样草稿动作 a<sub>t</sub><sup>(0)</sup>。
2. 从情节记忆 M<sub>E</sub> 检索与 a<sub>t</sub><sup>(0)</sup> 最相似的 k<sub>ME</sub> 个历史转移。
3. 世界模型基于当前状态、行动、情节记忆和语义记忆预测下一步观察 ˆo<sub>t+1</sub> 及置信度 q<sub>t</sub>。
4. 选择性前瞻：若 q<sub>t</sub> ≥ τ 则 F<sub>t</sub> = ˆo<sub>t+1</sub>，否则 F<sub>t</sub> = ∅。
5. 智能体重新采样最终执行动作 a<sub>t</sub>（条件于 (s<sub>t</sub>, F<sub>t</sub>)）。
6. 若 a<sub>t</sub> ≠ a<sub>t</sub><sup>(0)</sup>，用 a<sub>t</sub> 重新查询世界模型获取预测（用于后续更新语义记忆）。
7. 在环境中执行 a<sub>t</sub>，获得真实观察 o<sub>t+1</sub>。

9. 比较预测与真实观察的因子化结果，若有差异则累计不匹配，触发语义记忆更新（产生新规则并更新证据得分）。

1. **WorldEvolver 在预测准确率上显著超越所有基线**：在 ALFWorld 和 ScienceWorld 上，以 Exact Match 为例，提升幅度可达 20–50 个百分点（见表 1）。

## 7. 优点：方法与实验设计的亮点
- **轻量级自适应**：无需参数更新，仅通过添加检索和历史规则来实现在线适应，避免了灾难性遗忘和高计算成本。
