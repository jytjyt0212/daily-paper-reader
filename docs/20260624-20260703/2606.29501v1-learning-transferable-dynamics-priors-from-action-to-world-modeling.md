## 摘要
我们研究以动作为条件的世界建模，作为机器人学习中学习可迁移动态先验的一种可扩展方式。通过预训练一个模型来预测动作如何驱动视觉场景演化，所得的世界模型能够捕捉超越外观级视频生成的可复用交互动态。具体地，我们在大规模机器人操作数据上预训练了一个多视角交互基础扩散世界模型A2World，并带有真实动作标注。我们从两个互补的角度验证了学习到的动态先验。首先，我们将A2World适配为任务或场景专用的真实世界模拟器A2World-sim，其长期展开支持基于模拟器的策略评估和可扩展的假设分析，通过用世界模型展开替代真实机器人展开。其次，从相同的预训练权重出发，我们将A2World适配为视频-动作联合预测模型A2World-policy，该模型在视觉和指令条件下预测动作。在仿真基准和真实机器人环境中的实验表明，以动作为条件的世界模型预训练产生了可迁移的动态先验，对以模拟器为中心和以策略为中心的机器人学习都有益。

## Abstract
We study action-conditioned world modeling as a scalable way to learn transferable dynamics priors for robot learning. By pretraining a model to predict how actions drive visual scene evolution, the resulting world model captures reusable interaction dynamics beyond appearance-level video generation. Concretely, we pretrain a multi-view interactive base diffusion world model, A2World, on large-scale robot manipulation data with real action annotations. We validate the learned dynamics priors from two complementary perspectives. First, we adapt A2World into a task- or scene-specialized real-world simulator, A2World-sim, whose long-horizon rollouts support simulator-based policy evaluation and scalable what-if analysis by replacing real-robot rollouts with world model rollouts. Second, starting from the same pretrained weights, we adapt A2World into a video-action joint prediction model, A2World-policy, that predicts actions under visual and instruction conditioning. Experiments across simulation benchmarks and real-robot settings demonstrate that action-conditioned world model pretraining yields transferable dynamics priors that benefit both simulator-centric and policy-centric robot learning.

### 2. 论文提出的方法论

#### 核心思想
- **动作条件世界建模**：给定初始帧 \(o_t\) 和未来动作块 \(a_{t+1:t+k}\)，预测未来多视角观测 \(o_{t+1:t+k}\)。
- **基础模型 A2World**：基于 DiT（Diffusion Transformer）的多视角扩散世界模型，将动作编码后注入扩散时间步嵌入（通过自适应层归一化），不依赖其他条件（c=0），仅靠动作调制。
- **预训练数据**：收集并统一 2100k+ 轨迹、20+ 种机器人形态的高质量操作数据，将所有动作映射为统一的**双臂格式**（单臂补零），采用**数据集一致批处理**避免视角冲突。

#### 关键技术细节
1. **A2World 设计**：
   - 使用 WAN2.1 分词器提取潜在空间，EDM 去噪得分匹配目标。
   - 多视角生成：将 V 个视角沿时间维度拼接，加入可学习视角嵌入 \(\epsilon_{\text{view}}^{(v)}\)，并在每个 DiT 块中插入**交叉视角注意力**以保持时空一致性。
2. **A2World-sim（长程模拟器）**：
   - 引入历史信息：采用**姿态引导的历史采样**（算法 1），基于动作构建弧长，均匀采样关键帧以覆盖运动轨迹。
   - 历史注入方式：通过交叉注意力（历史 token 作为条件）和自注意力记忆路径（历史 token 作为 K,V 拼接到当前 token）双重融合。
   - 采用 **Self-forcing** 训练策略：在训练中周期性条件于模型自身生成帧，暴露错误并学习修正，提升长程稳定性。
3. **A2World-policy（视频-动作联合预测策略）**：
   - 共享自注意力，但视频和动作各有**专用的 AdaLN 和 MLP 分支**（MoE-like 结构）。
   - 联合扩散：共享基础噪声水平 \(\sigma_{\text{base}}\)，每模态单独缩放 \(\sigma_v = m_v \sigma_{\text{base}}, \sigma_a = m_a \sigma_{\text{base}}\)。
   - 训练使用加权联合去噪目标，推理时使用模态级分类器自由引导（可分别设置 \(s_v, s_a\)）。
