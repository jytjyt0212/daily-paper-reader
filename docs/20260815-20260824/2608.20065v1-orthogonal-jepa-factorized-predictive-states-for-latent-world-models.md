## 摘要
世界模型构建支持对底层系统进行预测、规划和推理的潜在状态。联合嵌入预测架构（JEPAs）提供了一种直接学习此类状态的方法，即在表示空间中预测目标，而不是重建观测的每个细节。然而，标准JEPA通过一个目标嵌入和一条预测路径来组织所有可预测内容。在复杂系统中，这种单体状态可能会将冗余能力分配给主导信号，同时对不太主导的预测结构提供较弱或冲突的梯度。我们引入了\method，一种基于正交预测因子化的潜在世界建模框架。学习到的基矩阵将每个目标状态分解为多个分量，并有一个专门的预测分支从共享上下文表示中估计每个分量。预测回归保留了状态合成所需的因子幅度，正交性目标阻止重复方向，因子活动正则化维持投影目标的变异性，在线方差正则化阻止逐坐标的编码器崩溃。预测的分量被合成一个完整的潜在状态，可用于读出器、解码器、规划器或自回归展开。当目标是时间上的未来、空间上的隐藏或同一系统的其他部分观测时，相同的预测状态机制同样适用。在受控视觉、单细胞转录组学、纵向健康记录、连续控制和分子动力学上的实验评估了表示质量、预测、规划以及长程稳定性。

## Abstract
World models construct latent states that support prediction, planning, and reasoning about an underlying system. Joint-embedding predictive architectures (JEPAs) offer a direct way to learn such states by predicting targets in representation space instead of reconstructing every detail of the observation. Standard JEPAs, however, organize all predictable content through one target embedding and one prediction pathway. In complex systems, this monolithic state can allocate redundant capacity to dominant signals while providing weak or conflicting gradients to less dominant predictive structure. We introduce \method, a latent world-modeling framework based on orthogonal predictive factorization. Learned basis matrices analyze each target state into multiple components, and a dedicated prediction branch estimates each component from a shared context representation. Predictive regression preserves the factor magnitudes required for state synthesis, an orthogonality objective discourages repeated directions, factor-activity regularization maintains variation in projected targets, and online variance regularization discourages coordinate-wise encoder collapse. Predicted components are synthesized into a complete latent state that can be used by a readout, decoder, planner, or autoregressive rollout. The same predictive-state mechanism applies when the target is temporally future, spatially hidden, or another partial observation of the same system. Experiments on controlled vision, single-cell transcriptomics, longitudinal health records, continuous control, and molecular dynamics evaluate representation quality, forecasting, planning, and long-horizon stability.

# 正交JEPA：用于潜在世界模型的因子化预测状态（Orthogonal JEPA）

## 1. 论文的核心问题与整体含义

- **研究背景**：世界模型（World Models）旨在构建能够支持预测、规划与推理的潜在状态。联合嵌入预测架构（JEPA）通过在表示空间内预测目标状态，避免了逐像素/逐细节重建的开销与噪声干扰，成为一种经典的学习范式。
- **核心问题**：标准 JEPA 通过**单一目标嵌入 + 单一预测路径**组织所有可预测内容。在复杂系统中（多实体交互、多尺度变化、局部与全局结构并存），这种单体式（monolithic）设计会导致：
  - 主导信号占用过多表示容量；
  - 次要预测结构获得的梯度较弱甚至冲突；
  - 多个潜在方向可能承担冗余角色。
- **论文提出的问题**：能否将 JEPA 的预测目标分解为多个结构化的预测因子，而非依赖单一路径？
- **整体含义**：论文提出 **Orthogonal JEPA**，通过正交预测分解，把单一目标状态拆解为多个子空间分量，每分量由独立分支预测，再合成完整潜在状态。该方法作为一种通用的潜在世界模型机制，可适配视觉、单细胞、临床、控制、分子动力学等多种领域。

## 2. 论文提出的方法论

- **预测状态接口（Predictive-State Interface）**：
  - 领域适配器 Aδ 将原始观测 x 映射为内容 tokens H 与结构描述符 S（如位置坐标、时间戳、实体 ID）。
  - 视图采样器 Vδ 划分上下文索引 C 与目标索引 T，构成 (HC, SC, T, ST)。
  - 在线编码器 fθ 生成上下文表示 zc；目标编码器 fθ̄（EMA 更新）生成目标状态 zt，目标编码器不接收梯度。
- **正交预测因子化（Orthogonal Predictive Factorization）**：
  - 引入 K 个基矩阵 Bk ∈ R^(d×r)，其中 Kr = d。
  - 对停止梯度（stop-gradient）的目标状态 ezt 进行分解：z(k)_t = Bk⊤ · ezt，每个因子维度为 r。
  - 每个因子由一个专用预测器 qk 从共享上下文 zc 与目标描述符 st 预测：ẑ(k)_t = qk(zc, st)。
  - 预测向量拼接后经伪逆合成完整预测状态：ẑt = (B⊤)† · ût；当 B 正交时，(B⊤)† = B，合成退化为加权求和。
- **损失函数**：
  - **预测回归损失** Lpred：对各因子直接做 MSE 回归，保留方向与幅度信息；
  - **正交性损失** Lorth：鼓励因子内基向量正交、因子间基向量互不重叠；
  - **因子活动正则化** Lfac：约束投影目标坐标的标准差不低于阈值 γfac，防止因子退化；
  - **在线方差正则化** Lenc：对在线编码器上下文表示施加逐坐标方差下限 γenc，防止编码器坍缩。
  - 总目标：**LOJEPA = Lpred + λorth·Lorth + λfac·Lfac + λenc·Lenc**，并允许附加领域标准辅助损失 Laux。
- **理论保证**：命题 1 证明，在完全正交条件下，B 为正规正交矩阵，分解满足范数保持与完美重构（z = Σ Bk Bk⊤ z），即因子分解在极限情况下无损。

## 3. 实验设计

论文在五个差异显著的系统中验证方法，每种场景均固定适配器、编码器、采样策略、优化预算与下游读出，仅替换单体 vs 因子化 JEPA 目标：

1. **受控视觉绑定（Controlled Visual Binding）**
   - 数据集：受控干预的 MuJoCo 渲染场景，采用图像不重叠划分。
   - 骨干：DINOv3 与 SigLIP2（冻结与微调两个版本）。
   - 对比：冻结基座、标准 JEPA、Orthogonal JEPA。
   - 指标：注入式留出细胞准确率（INJ）、坍缩率（Coll.）、网格恢复（Rec.）。

2. **单细胞转录组学**
   - 数据集：约 80 万个人体肾脏细胞预训练；PBMC-10K 聚类评估；Adamson 与 Norman 两个 CRISPR 扰动数据集评估扰动响应。
   - 骨干：scGPT 架构，沿用 Cell-JEPA 的掩码基因重建辅助任务。
   - 对比：scGPT、Cell-JEPA（单体 JEPA）、Orthogonal JEPA。
   - 指标：AvgBIO 聚类质量、扰动后表达预测的 Pearson 相关。

3. **纵向健康记录预测**
   - 数据集：时间排序的临床事件 + 人口统计 + 生化变量，预测未来 1,000+ 临床事件风险。
   - 对比：Random Forest、XGBoost、Qwen2.5-0.5B、Qwen3-0.8B（大语言模型）、Prophet、Delphi、Cross-attention fusion、标准 JEPA、Orthogonal JEPA。
   - 指标：平均 PRAUC。

4. **连续控制规划**
   - 环境：Walker2d-v5、HalfCheetah-v5、InvertedPendulum-v5。
   - 训练：500 条随机动作轨迹离线训练，两层 MLP 骨干。
   - 规划：交叉熵方法（CEM），200 候选、20 精英、5 次迭代、8 步视界。
   - 对比：标准 JEPA 与 Orthogonal JEPA。

5. **无作用力分子动力学**
   - 数据集：液态水、α-石英晶体、气相扑热息痛、苯。
   - 骨干：O(3) 等变自回归网络（TrajCast 风格），因子化仅在兼容的不可约表示通道内进行。
   - 对比：Scratch（无预训练）、TrajCast-JEPA（单体 JEPA）、Orthogonal JEPA。
   - 指标：单步位移 MAE、100 步自回归展开后最终位置 RMSD。

- **因子化预测优于单体预测**：在五个领域中，Orthogonal JEPA 均取得了优于或等于对应单体 JEPA 基线的结果：

## 7. 优点

- **设计新颖且理论有据**：将"冗余降维"（如 Barlow Twins/VICReg）的思想迁移到预测目标分解上，并用命题 1 给出完美正交极限下的重构保证。
- **通用性强**：通过适配器（Adapter）抽象，一套机制可处理图像块、基因表达、临床事件、状态动作对、原子坐标，体现了良好的接口设计。
- **综合正则体系**：正交损失 + 因子活动正则 + 在线方差正则三重约束，同时缓解了因子退化、方向冗余和编码器坍缩三类风险。
- **下游灵活**：预测因子既可合成完整状态用于规划/解码器，也可仅取在线编码器特征用于静态下游任务（EMA 编码器在推理时可弃用）。
- **实验覆盖多样**：从 CV、NLP/表格、强化学习到计算化学，跨领域验证增强了结论可信度。

## 8. 不足与局限

- **正交 ≠ 语义解缠**：作者明确指出，正交性只保证几何方向分离，不保证统计独立性、因果模块性或语义可解释性；因子是否对应真实物理/生物变量仍需额外探针验证。
- **缺乏消融实验**：未单独验证 K 的取值、各正则项权重敏感性、B 的条件数变化影响等，组件贡献难以量化。
- **方差正则不充分**：Lfac 与 Lenc 仅约束边缘坐标标准差，不保证协方差矩阵满秩或特征值分散，存在表示集中在低维子空间的理论风险。
- **状态合成的数值稳定性**：合成依赖 B 的伪逆，B 的病态条件数可能放大预测误差，论文建议监控奇异值但未提供相关实验数据。
- **确定性预测**：当前预测器为确定性的，无法显式建模多模态未来（如随机环境中的多种走向），限制了在随机动力学场景中的适用性。
- **实验覆盖局限**：未涵盖像素级闭环控制、随机未来预测、连续物理场、具有已知因果因子的任务；与更广泛的解耦表示学习方法（如 β-VAE、FactorVAE）缺少横向对比。
- **未披露算力与训练成本**：无法评估方法在资源受限场景下的可行性，复现门槛信息不透明。
