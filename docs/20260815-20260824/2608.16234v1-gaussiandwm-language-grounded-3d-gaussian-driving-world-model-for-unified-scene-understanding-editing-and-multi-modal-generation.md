## 摘要
驾驶世界模型（DWM）近年来随着生成模型的发展取得了快速进展，但现有方法大多主要关注条件场景生成，缺乏显式的三维场景理解、基于语言的推理以及可控的四维编辑能力。此外，常用的点云、占用率或鸟瞰图表示难以实现文本信息与底层三维场景结构之间的细粒度对齐。为解决这些局限性，我们提出了一种基础特征高斯驾驶世界模型，该模型在单一框架内统一了场景理解、基于语言的推理、可控四维编辑以及多模态生成。具体而言，我们引入了一种基础特征高斯分词器，直接将Qwen/SigLIP视觉语言特征蒸馏到三维高斯基元中，构建紧凑的开放词汇高斯语义场。我们进一步设计了一种几何感知高斯适配器，结合重要性感知层级选择与文本条件感知器式交叉注意力，将密集的高斯基元聚合为紧凑的世界标记。为提高表示兼容性，我们引入基于KL散度的高斯-图像分布对齐目标，将高斯世界标记与基础图像标记对齐。基于对齐的高斯表示，我们的框架进一步支持指令可控的场景编辑，包括天气条件生成和动态车辆操控。在更广泛的驾驶基准上的大量实验表明，我们的方法在场景理解、视觉定位、面向规划推理和可控四维生成任务上均达到了最先进的性能。我们将公开发布代码和数据集于Github。

## Abstract
Driving World Models (DWMs) have recently advanced rapidly with generative models, yet most existing methods mainly focus on conditional scene generation and lack explicit 3D scene understanding, language-grounded reasoning, and controllable 4D editing capabilities. Moreover, commonly used point cloud, occupancy, or BEV representations make it difficult to achieve fine-grained alignment between textual information and the underlying 3D scene structure. To address these limitations, we propose a foundation-feature Gaussian driving world model that unifies scene understanding, language-grounded reasoning, controllable 4D editing, and multi-modal generation within a single framework. Specifically, we introduce a foundation-feature Gaussian tokenizer that directly distills Qwen/SigLIP visual-language features into 3D Gaussian primitives, building a compact open-vocabulary Gaussian semantic field. We further design a geometry-aware Gaussian adapter that combines importance-aware hierarchical selection with text-conditioned Perceiver-style cross-attention to aggregate dense Gaussian primitives into compact world tokens. To improve representation compatibility, we introduce a KL-based Gaussian--image distribution alignment objective that aligns Gaussian world tokens with foundation image tokens. Based on the aligned Gaussian representation, our framework further supports instruction-controllable scene editing, including weather-conditioned generation and dynamic vehicle manipulation. Extensive experiments on broader driving benchmarks demonstrate that our method achieves state-of-the-art performance across scene understanding, visual grounding, planning-oriented reasoning, and controllable 4D generation tasks. We will release the code and datasets publicly on Github.

- **本文主张**：3D 高斯泼溅（3DGS）作为一种显式、连续、可微的原始基元表示，天然适合作为统一场景表示——既能支持可微渲染与多视角一致，又能作为基础模型视觉语言特征的显式 3D 载体，从而**统一场景理解、语言推理、可控 4D 编辑与多模态生成**。

## 2. 方法论：核心思想与关键技术细节

### 整体框架（四个核心组件）

1. **基础特征高斯分词器（Foundation-Feature Gaussian Tokenizer）**
   - 使用 Qwen 视觉编码器从多视角图像提取密集视觉语言特征图，通过 **L1 蒸馏损失**将 2D 特征渲染到 3D 高斯基元上（利用 alpha 合成权重）。
   - 引入**紧凑特征自编码器**（compact feature autoencoder）：将高维基础特征压缩为低维潜码存储，配合 L2 重构损失，降低存储成本。
   - 相比会议版本依赖 LangSplat 特征，本版**直接蒸馏 Qwen 特征到高斯基元**，摆脱外部语言高斯构建管线，实现真正的"开放词汇"3D 语义场。

2. **几何感知高斯适配器（Geometry-Aware Gaussian Adapter）**
   - **驾驶感知粗选（Driving-aware Coarse Selection）**：综合高斯内在质量（基于 opacity、scale、旋转有效性）与**轨迹相关性**（到自车未来轨迹的横向距离高斯衰减），经全局 Top-K 与体素覆盖 Top-K 的并集选取候选集，兼顾信息量与空间覆盖。
   - **属性感知高斯投影（Attribute-aware Gaussian Projection）**：对位置采用可学习傅里叶编码，融合位置、尺度、旋转、opacity、基础特征五种属性，经可学习门控加权与残差 MLP 校准入 LLM 隐藏空间。
   - **文本条件感知器式交叉注意力（Text-Conditioned Perceiver Cross-Attention）**：以少量可学习查询（queries）为 Q，以文本池化嵌入调制查询，以候选高斯 token 为 K/V 进行交叉注意力聚合，得到固定数量的紧凑"世界 token"。
   - **KL 高斯-图像分布对齐（Gaussian–Image Distribution Alignment）**：将高斯世界 token 的分布（高斯分布参数 μG、σG）对齐到同一场景的 Qwen 图像 token 分布（stop-gradient 目标），以 KL 散度（按维度归一化）作为正则损失，使紧凑 token 与基础视觉表示更兼容。

3. **场景理解模块（Scene Understanding）**
   - 将图像 token、高斯世界 token、文本 token 拼接注入 LLM（Qwen3-8B），所有下游任务统一表达为前缀语言建模。
   - 两阶段训练：第一阶段冻结 LLM，仅训练高斯分词器和适配器；第二阶段启用 LoRA 微调 LLM，整体联合优化。
   - 额外采用**任务感知批次采样**（task-aware batch sampling）缓解多任务不平衡。

4. **指令可控 4D 生成模块（Instruction-controllable 4D Generation）**
   - 基于**双条件 RGB-D 潜变量扩散**（dual-condition RGB-D latent diffusion），采用 denoising UNet + 冻结 VAE，v-prediction 目标。
   - **低层条件**：将由高斯场景或点云投影到目标视角的稀疏 RGB 与深度图作为纹理与几何引导。
   - **高层语言条件**：由 LLM 基于高斯世界 token 与编辑指令输出语义引导。
   - 支持空间生成（相机横向/纵向平移 ±1m/±2m/±4m）、时间生成（沿未来轨迹预测 1s/2s）、天气条件生成（雨/雾/雪）以及动态车辆操控（插入/移除/变速）等 4D 编辑模式。

## 6. 主要结论与发现

- **基础特征蒸馏到 3D 高斯基元显著提升语言-3D 接地精度**（2D 接地 mAP 较会议版提升约 38%），说明显式 3D 原语级接地优于 BEV/occupancy 级弱对齐。
- **KL 分布对齐对 2D 接地提升幅度最大**（mAP 提升约 39%），但对规划指标帮助有限——图像级兼容性不能替代驾驶推理所需的全局上下文。
- **混合采样策略（全局 Top-K + 体素覆盖 + 查询相似度）** 对规划准确率提升显著（约 64%），说明候选集既需突出显著原语也需空间覆盖。
- **双条件生成中，低层 RGB-D 条件是生成可行的必要前提，高层语言条件进一步降低 FID 约 17%**——两者互补而非冗余。
- **集成框架在不同任务上各有强项**（如完整模型在 2D 接地和规划上最优，但部分 3D 接地指标并非第一），说明理解、接地与推理之间存在内在权衡，统一表示需在任务间取得平衡。
- 总体表明：**3D 高斯表示可作为驾驶世界模型的统一基础表示**，同时支撑语言理解与可控 4D 生成。

## 7. 优点

- **统一性**：在同一 3D 高斯表示上统一理解、接地、推理、编辑与多模态生成，避免多套表示间的语义断裂。
- **显式 3D 语言语义场**：直接蒸馏 Qwen 特征至高斯基元，相比 BEV/LangSplat 方案减少中间环节，支持真正的开放词汇语义接地。
- **工程上的 token 压缩设计巧妙**：重要性选择 + 文本条件 Perceiver 聚合，将十万量级高斯基元压缩为固定数量 LLM 兼容 token，训练与推理可控。
- **KL 分布对齐损失设计新颖**：在不破坏显式 3D 结构的前提下提升与基础图像 token 的表示兼容性。
- **数据集贡献**：构建含 1000 个 nuScenes 场景的 3D 高斯重建 + 高斯感知 QA 标注（NuScenes-GSQA），推动 3DGS 与 LLM 结合方向的社区发展。
- **4D 编辑能力**：在保持时间/几何/语义一致性的前提下支持天气编辑与动态车辆操控，展示作为可控驾驶模拟器的潜力。
- **三阶段渐进式训练策略**：从表示预热、LLM 对齐到生成联合训练，稳定且合理。

## 8. 不足与局限

- **单数据集验证**：全部定量实验基于 nuScenes，未在 Waymo、CARLA 等驾驶数据上验证泛化性。
- **零样本/generalization 能力受限**：OmniDrive 与 NuInstruct 的对比中，本方法为微调模型；与 GPT-4o 等零样本模型的对比不在同一训练条件下的公平设置。规划准确率（81.52）并非较同类最优（DriveMonkey 82.64 胜出）。
- **生成质量指标仍有较大改善空间**：如 ±4m 时 FID 15.02，虽 SOTA 但绝对值仍较高，大基线位移下深度连续性缺少定量评估。
- **推理开销与实时性未分析**：3DGS 重建 + 特征蒸馏 + LLM 解码头 + 扩散生成的端到端 pipeline 计算与内存开销未报告，实际部署到车载平台的可行性存疑。
- **LLM 参数量受限**：仅使用 8B 级 LLM（Qwen3-8B），未探索更大模型（如 14B/72B）对理解性能的上界影响。
- **编辑能力缺少定量指标**：天气编辑与车辆操控仅有定性展示，没有 FID/一致性/编辑成功率的系统量化评估。
- **数据构建成本高且质量依赖重建管线**：1000 个场景的 3DGS 重建与特征蒸馏耗时长，且重建质量直接影响下游语义（文中也承认过滤了严重模糊/曝光异常帧）。
