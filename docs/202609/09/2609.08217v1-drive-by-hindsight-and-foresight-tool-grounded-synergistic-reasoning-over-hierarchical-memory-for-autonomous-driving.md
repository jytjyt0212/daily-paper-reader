## 摘要
视觉语言模型（VLM）在自动驾驶中展现出潜力，但仍存在幻觉、时空感知薄弱和泛化能力有限的问题。最近的方法通过思维链（CoT）解释、检索增强生成或静态注入工具输出，改进了推理和决策。尽管这些机制丰富了上下文，但模型既不会主动感知场景信息，也不会在回答后积累经验。为克服这些局限，我们提出了——据我们所知——首个将分层记忆与主动工具调用紧密耦合于闭环推理循环中的协同框架。我们的贡献有三方面。（i）分层驾驶记忆：场景级短期记忆维持动态场景状态，而不断演化的长期记忆检索可复用的经验和工具策略。（ii）记忆-工具协同推理框架：在场景状态和检索经验的引导下，模型在推理时自适应地调用工具来优化推理，并在离线时将可复用经验整合到长期记忆池中。（iii）数据生成与两阶段训练流程：利用多步教师展开构建的经过验证的记忆-工具轨迹，通过SFT和GRPO进行训练。我们的7B模型在DriveLMM-o1上达到了80.03的总体推理得分和79.09%的多项选择准确率，比最强基线高出7.74个MCQ点，并在多个基准上表现出强大的泛化能力。值得注意的是，消融和分析研究验证了各组成部分的有效性，并进一步揭示了分层记忆的互补作用。短期记忆增强了时空理解，使STSBench准确率提高了24.2个百分点，而离线长期记忆整合在全部参数冻结的情况下额外获得了3.57个MCQ点的提升，展示了通过积累驾驶经验实现持续自我进化的能力。

## Abstract
VLMs have shown promise for autonomous driving, yet still suffer from hallucination, weak spatio-temporal perception, and limited generalization. Recent methods improve reasoning and decision-making through CoT explanations, retrieval-augmented generation or the static injection of tool outputs. Although these mechanisms enrich the context, the model neither proactively perceives scene information nor accumulates experience after answering. To overcome these limitations, we present, to our knowledge, the first synergistic framework that tightly couples hierarchical memory with proactive tool invocation in a closed reasoning loop. Our contributions are threefold. (i) Hierarchical Driving Memory: a scene-level short-term memory maintains the dynamic scene state, and an evolving long-term memory retrieves reusable experience and tool strategies. (ii) Memory-Tool Synergistic Reasoning Framework: guided by the scene state and retrieved experience, the model adaptively invokes tools to refine its reasoning at inference time and consolidates reusable experience into a long-term memory pool offline. (iii) Data Generation and Two-stage Training Pipeline: verified memory-tool trajectories built by multi-step teacher rollout are used to train with SFT and GRPO. Our 7B model reaches an overall reasoning score of 80.03 and MCQ accuracy of 79.09% on DriveLMM-o1, surpassing the strongest baseline by 7.74 MCQ points and generalizes strongly across benchmarks. Notably, ablation and analysis studies validate the effectiveness of each component and further reveal the complementary roles of hierarchical memory. Short-term memory strengthens spatio-temporal understanding, improving STSBench accuracy by 24.2 points, while offline long-term memory consolidation yields an additional 3.57-point MCQ gain with all parameters frozen, demonstrating continual self-evolution through accumulated driving experience.

- **核心问题**：能否通过整合**时空感知、主动感知和经验积累**，在统一的闭环推理框架中捕捉人类驾驶的"先见"与"后见"的双重特征？

## 2. 论文提出的方法论

### 核心思路
提出 **MTSR（Memory-Tool Synergistic Reasoning）**框架，把分层记忆与主动工具调用耦合到一个闭环推理流程中。

### 2.1 分层驾驶记忆

- **场景级短期记忆（STM）**：用预训练BEV感知模型对相邻两帧t−1和t的六视角图像编码，生成结构化的语义描述和场景属性，组织成场景图 Ms=(V,R)。V为自车/交通参与者/道路元素，R为其时空和交互关系。STM只随场景前进刷新，推理期间只读。
- **跨场景长期记忆（LTM）**：每条目为 ei=(ci, ri, p⁺i, π^tool_i, wi)，分别描述适用场景/任务条件、风险因素、可复用推理模式、有效工具使用策略和检索效用。检索公式：S(ei|q,Ms)=sim(Em([q;Ms]), Em(ei))+λw̄i，取TopK。
- **离线整合**：完成且通过验证的轨迹经"过滤→去重→冲突消解→合并"后进入LTM；已有条目的效用权重 wi ← wi+η·gi(C) 得到增强。

### 2.2 记忆-工具协同推理循环

轨迹定义为 C=(x0, s1, ..., sT, y)，其中每个思考动作步 st=(ht, at, ot, ut)。策略迭代执行：
1. **Think**：识别当前证据缺口；
2. **Action**：生成工具调用 at∈T∪{finish}；(ht, at)∼πθ(·|x0, H<t)；
3. **Observation**：执行工具，获得真实观测并追加到上下文；
4. **Update**：更新瞬态场景信念 ut；
5. 直到模型判定证据充足，输出 y∼πθ(·|x0,H≤T)。

在单次查询中，STM和LTM均保持不变；只有瞬态信念随观测不断演化。

### 2.3 数据生成与两阶段训练

- **多步教师展开**：以Qwen3.6-Plus为教师，在初始化LTM上生成7,000条工具执行轨迹，经最终答案正确性、工具调用合法性、推理-观测一致性三重验证后，6,383条合格。验证后的轨迹整合进 LTM。
- **两步SFT**：
  - Phase 1：删除执行器返回的观测；训练模型选择合法工具与参数（13,679条记录，3 epochs）；
  - Phase 2：基于Phase-1检查点，在完整记忆+工具反馈下训练观测引导的推理（20,062条记录，20 epochs）。执行器观测只作上下文已掩码不计loss。
- **轨迹级GRPO**：G=8，基于Phase-2检查点。分层奖励（Tier 1~6）：正确+工具+引用记忆 +0.7；正确+工具+未引用记忆 +0.5；正确+无工具 0.0；错误+工具 0.2；错误无工具 0.0。工具奖励**刻意不设全正确门槛**，作为冷启动引导，但在组内标准化时被正确样本支配。

1. **DriveLMM-o1主结果**：推理得分80.03、MCQ准确率79.09%，比Qwen2.5-VL-7B骨干分别高28.26/41.28点，比AgentThink高7.74个MCQ点；在规则遵守和场景感知上排首位。

3. **STM价值**：在STSBench上加入STM后准确率比基础模型提升24.2个百分点（55.61% vs 31.38%），说明显式时空状态组织远优于塞入更多视觉帧（6帧输入仅35.64%）。
4. **LTM离线积累**：参数全部冻结条件下，MCQ从79.09%升至82.66%（第9轮），净增3.57点；第10轮略回落，说明存储饱和，仍展示"非参数化持续自我进化"的有效性。

## 7. 优点

- **概念上的原创性**：首次将"短期感知记忆 + 长期经验记忆 + 主动工具调用"耦合为闭环，较"静态注入/单次RAG"有本质差别。
- **对应人类驾驶认知**：以foresight（STM追踪时空）与hindsight（LTM积累经验）为设计隐喻，动机清晰自然。
- **方法链条完整**：从记忆构造 → 检索 → 闭环推理 → 数据验证 → 两阶段训练 → 离线整合，环环相扣。
- **训练数据泄漏控制严谨**：使用DriveLMM-o1训练集；LTM初始化仅从训练场景提取；检索排除同场景近邻帧；推理视图剥离教师决策和身份字段；checkpoint由验证集（非测试集）挑选；合并用训练标签验证。附录C.3等多处有清晰说明。

- **推理中拒绝"无证据猜测"**：定性案例显示在距离估计、恶劣天气决策、时空预测等场景中，模型将答案锚定在工具观测和经验记忆上；与Qwen3-VL-32B对比明显。

## 8. 不足与局限

- **延迟过高，不适用于实时驾驶**：中位数延迟约35 s/查询。作者明确说明框架面向离线场景理解、数据标注和仿真评估，而不等于整车部署能力；作者也明确说该工作是把驾驶benchmark当作多步接地推理的测试床，而非车辆就绪的证据。
- **RL奖励设计偏置**：GRPO只直接优化MCQ正确性和工具纪律，对开放式回答的描述完整性没有直接的强化信号。其最弱维度Semantic Coverage-Step仅61.26，深度的描述性不足——当可用证据足以区分选项时推理提前终止。
- **难以复现**：教师模型是第三方API别名（不提供精确版本），其调用窗口内的真实构建不可回放；轨迹已冻结作为记录，但读者不能自行重复生成过程。
- **单一训练运行**：论文说明"管线只训练一次"，附录CI仅覆盖测试集采样方差，不覆盖多个独立训练运行的变异；RL阶段即便固定种子也不可逐位复现。
- **离线LTM演化观察有限**：只观察到单一整合轨迹，第10轮的饱和是一次性的，其方差和渐近行为未刻画。
- **网络效应的局限**：DriveLMM-o1上Risk Assess维度（76.95）低于AgentThink（80.51），即主动交互+工具并未在风险研判文本质量上全面领先；研究者需进一步改进检索可靠性和信念冲突消解。
- **长距离度量精度欠佳**：定性案例中3D测距仍有误差（如用MDE测距得到的41.0 m对45.22 m真实值），提示细粒度物理精确度量还不是该框架的强项。
- **实验覆盖局限**：未报告跨随机种子的训练变异性；对时间表示做消融时仅做STSBench，没有检验STM改动对DriveLMM-o1推理质量的影响。
