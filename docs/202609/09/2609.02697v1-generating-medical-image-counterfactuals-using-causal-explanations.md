## 摘要
深度学习模型在医学图像诊断中取得了显著性能，但其在临床环境中的部署仍受到可解释性有限的制约。反事实图像提供了一种审计模型行为的方式，通过展示图像需要如何变化才能使分类器产生不同的预测。现有方法通常使用辅助模型（包括生成对抗网络和扩散模型）来生成此类解释。虽然这些方法通常能够生成视觉上逼真的图像，但它们用一个黑盒模型来解释另一个黑盒模型，使得将分类器的决策过程与生成器的归纳偏差分离开来变得困难。我们提出了一种新颖的反事实生成框架，该框架不需要生成模型。相反，反事实图像直接根据从分类器中提取的因果证据来构建。所提出的方法具有确定性，不需要额外的模型训练，并且能够在用户指定的感兴趣区域内进行可控编辑。在真实世界医学影像数据集上的实验表明，所提出的方法能够成功改变分类器的预测，同时比生成式基线方法更接近原始图像，从而为分类器的决策边界提供了更直接、更透明的视图。

## Abstract
Deep learning models have achieved impressive performance in medical image diagnosis, yet their deployment in clinical settings remains constrained by limited explainability. Counterfactual images provide one means of auditing model behavior by showing how an image would need to change for a classifier to produce a different prediction. Existing approaches typically generate such explanations using auxiliary models, including generative adversarial networks and diffusion models. While often capable of producing visually realistic images, these methods explain one black-box model using another, making it difficult to separate the classifier's decision-making process from the inductive biases of the generator.   We propose a novel counterfactual-generation framework that requires no generative model. Instead, counterfactuals are constructed directly from causal evidence extracted from the classifier. The resulting approach is deterministic, requires no additional model training, and enables controllable edits within user-specified regions of interest. Experiments on real-world medical imaging datasets demonstrate that the proposed method successfully changes classifier predictions while remaining closer to the original image than generative baselines, providing a more direct and transparent view of the classifier's decision boundary.

## 2. 论文提出的方法论：核心思想、关键技术细节、公式或算法流程

### 2.1 核心思想
- **将分类器视为因果模型**：把图像像素当作原因变量，分类输出作为结果，分类器网络视为因果机制。借助实际因果理论中的定义（充分解释、完整解释）获得因果像素集。
- **关键词：因果检索而非生成建模**：不从零合成图像，而是从已有的、分类器正面分类（疾病类）的图像中，检索其因果解释中选中的像素值，并将其“移植”到待解释的阴性图像上，从而触发分类器将输出改为阳性。

### 2.2 关键概念与定义
- **充分解释（MSPS，Minimal Sufficient Pixel Set）**：满足两个条件：
  - EXIM1：只保留解释像素（其余用基线值替换）后，分类结果不变；
  - EXIM2：该像素集是最小的（任意真子集都不满足 EXIM1）。
- **完整解释（Complete Explanation）**：在充分解释的基础上，还要求：
  - EXN1：将这些像素移除后，分类结果改变；
  - EXN2：在同时满足充分性和必要性条件下最小。
- 解释工具使用 ReX：通过迭代地对超像素组合进行遮盖并测试分类器，计算因果责任并提取 MSPS/完整解释。ReX 复杂度为 O(2^{s}·n·N)，其中 s 为分区大小（默认 4），n 为像素数，N 为初始分区数。

### 2.3 算法流程（Algorithm 1：CausalCounterfactual）
输入：分类器 N、阴性图像 x、阳性图像集合 P、预计算的因果解释集合 Pexp、距离函数 d、掩码集合 M、距离阈值 t。
步骤：
1. 在阳性参考集 P 中找到离 x 最近的图像 p'（按距离函数 d）；
2. 从 Pexp 中取出 p' 对应的解释（二进制掩码 E'_p）；
3. 将该解释掩码应用到 p' 上，提取实际像素值并排序得到 V'_p；
4. 计算解释掩码的几何中心（或由用户指定区域）作为突变位置；
5. 主循环：对每种掩码 m（由小到大）：
   - 将掩码施加在 x 的指定位置，得到初始候选 x'；
   - 逐步将掩码下的像素值向 V'_p 中的最近值移动（单调逼近）；
   - 若 x' 与原图 x 的距离小于阈值 t 且分类器判定为阳性，则返回平滑后的 x'；
   - 否则增大步长或使用更大的掩码继续尝试；
6. 若所有掩码和值组合均失败，返回空集。
- 算法是确定性的，无需训练任何额外模型，每次修改都可追溯到具体的因果解释像素。
- 后处理：使用 SLIC 超像素分割对掩码边界进行平滑，减少硬边伪影。

## 3. 实验设计：数据集 / 场景、benchmark、对比方法

### 3.1 数据集
- **脑 MRI 数据集（低级别胶质瘤，LGG）**：来自 The Cancer Imaging Archive，110 位患者、共 3929 张 FLAIR/对比前/对比后三通道轴向切片。使用 Legastelois 等提供的预训练 ResNet50 分类器，按患者划分训练/测试（80%/20%），未做额外训练。
- **皮肤病变数据集（ISIC）**：共 1250 张良恶性皮肤病变图像，使用基于 VGG 的注意力 CNN（来自 [31]）作为分类器，也未额外训练。
- **评估对象**：所有被分类器预测为“阴性”的图像（包括真阴性和假阴性），数量：MRI 560 张，ISIC 277 张。

### 3.2 benchmark / 评估指标
- 采用**距离约束下的成功率**：成功 = 分类改变且 d(x, x') < t。
- 距离度量：L1、L2、SSIM（用 1-SSIM）、LPIPS。算法内找最近阳性图像和迭代控制使用 L2（因为其透明、非黑箱）。
- 设定了最大距离阈值：基于数据集中所有图像对的 99th 百分位距离作为合理上界。
- 还比较了变换前后图像集合的**两两距离分布**，判断各方法是否改变原始数据流形的结构。

### 3.3 对比方法
- **因果方法变体（本身）**：
  - SE：使用充分解释（MSPS）
  - CE：使用完整解释
  - NSE / NCE：朴素版本——直接将最近阳性图像的解释区域原样粘贴到阴性图像上

  - GANterfactual（GAN）
  - MoPaDi（扩散模型 DM）
- 所有方法获得相同的训练数据；因果方法只用阳性训练样本预计算解释数据库。

### 3.4 实验内容
- 在两个数据集上，分别用四种距离度量（LPIPS、1-SSIM、L1、L2）绘制距离-成功率曲线。

## 6. 论文的主要结论与发现

- 提出的基于因果解释的反事实生成方法**无需任何生成模型**，仅用分类器自身提取的因果证据即可构造反事实，且是确定性的。
- 在**低距离阈值**下，因果方法（特别是 CE）在两个数据集上均优于 GAN 和扩散模型，成功率更高（MRI 上 SSIM 0.2 / LPIPS 0.25 时成功率约 85%；ISIC 上 SSIM 0.21 / LPIPS 0.48 时约 67%）。
- 生成式模型虽然能在较大扰动下达到高成功率，但需要的修改幅度显著更大，实用性下降。
- 因果方法生成的反事实能够保持原图的数据分布特性（两两距离分布接近原始分布），而 GAN 和部分扩散方法生成的反事实呈现“集中模式”，暗示可能学到了捷径或生成模式单一。
- 朴素粘贴方法（NSE/NCE）成功率虽在较大距离下有时更高，但其修改范围往往过大（如把整块病灶取代），不如逐步调整方法精细。
- 整体表明：以因果解释作为反事实生成的主要表示，能更直接、透明地暴露分类器的决策边界，避免生成器引入的混淆因素。

## 8. 不足与局限

- **参考集依赖**：反事实的质量强烈依赖参考阳性图像集合的多样性和解释质量；若阳性样本中缺少某些病理形态，则无法生成对应反事实。
- **可解释性与数理性之间的张力**：虽然比生成模型更直接，但仍属于“检索+移植”，可能导致视觉上不自然或有拼接痕迹；平滑策略仅为启发式。
- **结果不稳定风险**：算法依赖“最近阳性图像”的选择，不同距离度量可能得到不同结果；论文只以 L2 作为内部选择标准，缺乏对距离函数选择的敏感性分析。

- **数据集规模有限**：仅两个数据集，且预训练分类器未从零训练，无法判断方法在自训练模型上的表现。
- **算力/效率信息不足**：未给出 ReX 预计算时间和整体运行时间的具体数值，难以与其他方法进行定量时间成本比较。
