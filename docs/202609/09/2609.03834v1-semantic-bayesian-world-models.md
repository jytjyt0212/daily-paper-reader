## 摘要
知识图谱以明确的断言描述现实，而如今消费它们的系统——基础模型与自主智能体——则以概率进行原生推理。我们认为，这种不匹配正是语言模型与知识图谱的整合仍停留在数据供给管线、而非统一推理架构的原因。我们设想语义贝叶斯世界模型（SBWM）：一种万维网，它不是将世界描述为事实数据库，而是描述为知识图谱之上共享的、不断演化的信念结构，其中本体论公理约束先验，观测通过贝叶斯条件化更新信念，行动则对世界进行干预。我们探讨智能体从这种模型中获得何种收益：一个判断门口人影是快递员还是窃贼的家居安全智能体；一种通过蕴含关系而非字符串频率聚合的精算估计；一项语言模型可靠失败规划任务；以及估算任何文档都未曾提及的量。随后，我们阐述了为使这些模型成为可能，社区必须构建的内容：基于RDF 1.2的信念标注、概率蕴含机制、语义校准层，以及从未谋面的智能体之间可以交换并对校准信念产生分歧的协议。

## Abstract
Knowledge graphs describe reality in crisp assertions, while the systems now consuming them, foundation models and autonomous agents, reason natively in probabilities. We argue that this mismatch is why the integration of language models and knowledge graphs remains a data-feeding pipeline rather than a unified reasoning architecture. We envision Semantic Bayesian World Models (SBWMs): a Web that describes the world not as a database of facts but as a shared, evolving fabric of beliefs over knowledge graphs, where ontological axioms constrain priors, observations update beliefs by Bayesian conditioning, and actions intervene upon the world. We work through what an agent gains from such a model: a home-security agent deciding whether the figure at the gate is a courier or a burglar, an actuarial estimate aggregated by entailment rather than by string frequency, a planning task that language models reliably fail, and the estimation of quantities that no document has ever stated. We then set out what the community must build to make them possible: belief annotation over RDF~1.2, probabilistic entailment regimes, semantic calibration layers, and protocols by which agents that have never met can exchange, and disagree over, calibrated beliefs.

## 1. 核心问题与研究动机

- **问题核心**：知识图谱用布尔逻辑（三元组要么成立要么不成立）描述世界，而基础模型和自主智能体以概率分布为原生推理方式。二者之间的“表征失配”导致当前语言模型与知识图谱的整合只是“数据喂送管道”，而非统一推理架构。
- **更深的洞察**：这种失配不是技术困难，而是表征层面难以跨越——知识图谱缺少“信念度”这一维度，语言模型又缺少稳定的符号参照系，二者都无法用对方的方式表达自身的认知状态。
- **论文愿景**：提出语义贝叶斯世界模型（SBWM）——一种不把万维网当作事实数据库、而当作“知识图谱上的共享信念网络”的世界模型。本体公理约束先验，观测经贝叶斯条件化更新信念，动作通过图编辑（SPARQL UPDATE）对世界产生因果干预。
- **强猜想**：如果知识仍然以“子串间的统计关联”（即语言模型的方式）来组织，那么语言模型本身无法扩展到超级智能；知识必须以语义化、概率化的命题组织——具有稳定身份标识的命题，并携带遵循概率公理的连贯置信度。

## 2. 方法论与技术细节

### 2.1 形式化定义
SBWM 被定义为一个四元组 M = (Σ, P₀, T, O)：

- **Σ**：词汇表 + TBox（本体公理集）。
- **P₀**：RDF 图集合上的先验分布。
- **T**：转移核 T(G′|A,G)，刻画动作 A 如何改变知识图 G（即图编辑动力学）。
- **O**：观测模型 O(o|G)，将噪声感知数据（传感器、抽取器输出、语言模型的 log 概率）映射为对三元组的似然。

信念状态就是图上的分布，贝叶斯规则是更新规则，“本体就是先验”。

### 2.2 本体的概率约束
- **核心一致性条件**：
  \[
  A \models B \implies P(A) \le P(B)
  \]
  即逻辑蕴含必须携带概率单调性约束。由此从 TBox 自动推导出一系列不等式约束：
  - 子类关系中实例类型概率继承；
  - 子属性关系中三元概率继承；
  - 不相交类（disjointWith）关系下二者合取概率为 0；
  - 属性定义域决定逻辑必然的概率为 1。
- **层级先验**：沿类层级定义的概率先验自然满足子类不等约束，使从未观测到的子类从父类获得先验概率质量。
- **语义校准层**：神经网络的输出（如视觉模型对“杯子”置信度 0.9、对“容器”置信度 0.6，违反蕴含约束）可以投影到由公理定义的多面体可行域上，这一校准层可微分且可嵌入任意架构，以 de Finetti 的 coherence（赌博不输）论证作为规范依据。

### 2.3 因果干预的落地方式
- **SPARQL WHERE 对应条件化（seeing）**；
- **SPARQL UPDATE 的 DELETE/INSERT 对应 Pearl 的 do 算子（doing）**，对世界图本身执行“图手术”；
- RDF 1.2（基于 RDF-star）原生支持语句级元数据标注，例如给三元组附加概率值；
- 条件结构以“提升的贝叶斯网络”（lifted networks）表达，其节点是三元组模式，CPT 表可发布为链接数据。

### 2.4 规模化表征：语义贝叶斯张量
- 知识图上的分布可表示为稀疏张量：先验是一个三维张量（subject × predicate × object），一阶条件化是六维张量，二阶是九维。
- 由于实际观测只覆盖少量条目，大部分条目缺失，因此提出 **语义贝叶斯张量补全**——借鉴知识图补全思想，利用语义相邻单元估计缺失的先验概率。
- 例如，“20-22 岁人群访问伊比沙岛”的概率虽无文档记录、也无单元格存储，但可以从相邻年龄区间、父类/兄弟类的年龄画像等张量信息中通过传输/插值估算。
- 论文指出，万亿级三元存储已存在（AllegroGraph 2011、Oracle 的 1.08 万亿边、Stardog 的跨云万亿规模），相对前端大语言模型的资源开销较小。

### 2.5 端到端构建方案
- 使用小型语言模型或依赖解析器从多语言 Web 文本抽取类型化三元组；
- 直接使用抽取器的 log 概率（而非人工赋值）作为初始置信度；
- 跨语言聚合：同一命题（如德文和葡萄牙文来源）以同一 URI 表示，构建“语义贝叶斯知识图”；
- 通过张量补全估算文档未支持的条目，形成可用先验 P₀；
- 加入转移核和观测模型，即从先验转化为世界模型。
- 论文强调：真正缺的不是组件，而是“在每一步保留概率而非在一开始就用阈值砍掉”的承诺。

## 3. 场景实验设计

- **本文非实验导向论文**，没有传统意义上的数据集、量化基准或模型对比；而是采用了三个定性场景用例（scenario vignette）来展示 SBWM 的推理能力如何超越单纯的语言模型或知识图谱。
- **场景一（花园摄像头——分类与因果干预）**：
  - 家庭安全智能体在夜间用摄像头检测到门口有人持盒。需要判定是快递员还是窃贼。
  - 采用贝叶斯分解 P(Theft|o) ∝ P(o|Theft)P(Theft)，假设空间包括 Theft/Delivery/Visit。
  - 所需信念来自不同发布者：警方开放数据的入室盗窃率、快递公司的投递时间分布、自家订单图、邻里位置信号、本机视觉模型的感知似然。
  - 智能体评估干预效果（打开泛光灯）时，直接对世界图执行 INSERT DATA 修改光照状态，再从转移核中估计目标人物离开概率——快递员不会因灯而逃逸，窃贼会。
  - 本体约束（Courier 与 Burglar 不相交）保证假设竞争时满足概率公理。
- **场景二（精算聚合）**：由事故率、天气、车型、年龄组估算保险风险时，SBWM 通过图模式蕴含关系聚合并关联每个子类和每个实例，中文索赔与德文索赔更新同一个信念。这替代了纯语言模型按字符串频率统计的近似方式。
- **场景三（“洗车测试”——规划）**：我的车脏了，洗车场只有 100 米远，该走路还是开车？
  - 语言模型常答“步行”，因为它认为步行足够且忽略了汽车必须在洗车场才能洗车这一隐藏前提。
  - SBWM 通过少量三元组规则化解此问题：如果清洗动作的域为 CarWash（位置约束），要通过反链实现“车干净”目标必须将车子移到洗车场位置，因此需要开车去。
  - 在不确定感知下，该推理仍然保证置信度向下传播。

- **补充能力展示**：用语义张量补全回答“从未有文档表述过的量”，例如估计 20-22 岁人群访问伊比沙岛的条件概率。

## 6. 主要结论与发现

1. 知识图谱的布尔语言与神经模型的概率推理之间是深层的“表征误差”，而非单纯的工程接口问题。
2. 概率化世界观可被“本体作为先验”来实现：子类/子属性/不相交集等公理会自动给出概率约束，把语义校准层架在神经打分器与图数据库之间，以统一一致概率空间。
3. SBWM 在条件化、干预、多主体信息整合、可分离更新、以蕴含而非字符串频率聚合、对文档未曾表述的量进行估算等任务上优于纯 LLM 或纯 KG。
4. 一个可证伪的核心断言得到支撑：仅靠词元间统计关联的组织方式，语言模型做不到连贯的贝叶斯推理和可靠的规划；符号化的信念分布是达到超人类模型的基础。
5. 工程上论文认为各零件均已在业界存在，问题在于当前的抽取管线/存储/推理方案容忍概率被尽早丢去，SBWM 的价值是由应用驱动形成统一的、可溯源信念流。
6. 最后寄希望于社区围绕五个基础设施方向投入研发：RDF 1.2 上的信念标注、概率蕴含机制、概率 SHACL、“语义校准层”、联邦式的可信信念交换协议。

## 8. 局限与值得警惕的问题（批判性评估）

- **可行域约束的由来尚存循环论证风险**：论文声称“本体公理自动给出概率约束”，但公理本身的置信度从何而来？若公理也是从文本或数据中抽取的，则又会退回到“用统计生成逻辑、再用逻辑约束统计”的循环；若公理由人工设定，则在 Web 规模上难以维持。
- **后验更新规则在开放世界中的语义并不清爽**：经典贝叶斯更新要求观测空间是预先定义的，而语义 Web 的开放世界允许新实体、新谓词随时出现。SBWM 的转移核与观测模型如何对新谓词做条件化，论文没有给出形式化处理。
- **“以共享 URI 为身份锚”的假设回避了真正的知识融合难题**：不同来源对同一实体/关系使用不同 URI，或同一 URI 被不同社区赋予冲突内涵时，SBWM 并未提出解决方案；实体链接与本体匹配的科学问题被隐式地当作已解决或可由社区标准解决的工程问题。
- **大规模贝叶斯推断的复杂度可能重新引入近似误差，削弱“概率公理一致性”的承诺**：为进行#P-hard 推理，任何实际系统都不得不采用近似推断，而近似误差可能淹没公理约束带来的校准增益。文中没有对这一根本张力给出策略。
- **先验获取的可行性仍被高估**：论文建议依赖抽取器的 log 概率与张量补全来初始化先验。但 Web 文本常含偏见、重复样本与非独立生成过程，直接把文本频率当作先验会导致系统性偏差；张量补全只能平滑已知区域，无法创造新知识。
- **与 LLM 的关系处理过于二元化**：SBWM 处处以“仅靠符号与统计关联不可成”为靶子，但实际上神经模型完全可以充当 SBWM 内部的感知层、似然估计器甚至先验生成器。论文未深入探讨这种“混合架构”的对称优势，使立场显得比实际更对立。
