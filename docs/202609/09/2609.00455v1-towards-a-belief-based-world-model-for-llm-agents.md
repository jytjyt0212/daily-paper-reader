## 摘要
大型语言模型（LLM）正被用作许多领域中自主决策和规划的策略。尽管具有强大的推理能力，但LLM在处理长时间跨度任务时仍存在困难，尤其是在部分可观测性条件下。世界模型是一种在训练和推理过程中增强策略性能的有前途的方法。在推理过程中，智能体目前使用世界模型在采取行动之前模拟候选行动的结果，这可以改进决策制定。然而，我们认为在部分可观测性下，仅靠模拟并不能为决策提供完整的接口：模拟无法充分捕捉对当前状态的不确定性，而智能体可能需要这种不确定性来进行准确的决策。我们通过基于信念的世界模型（BB-WMs）来解决这一局限性，该模型建模并维护一种信念，LLM可以查询该信念以获取关于当前状态已知和不确定信息。在开发学习准确BB-WMs的方法之前，我们首先提出一个更基本的问题：将世界模型的信念直接暴露给LLM策略是否会改善决策？我们的结果表明，在部分可观测性下，让LLM智能体访问世界模型信念可以提高任务表现，同时与现有的基于模拟的世界模型保持互补。代码已发布在https://github.com/skumar-ml/belief-world-models。

## Abstract
Large language models (LLMs) are being used as policies for autonomous decision-making and planning in many domains. Despite their strong reasoning capabilities, LLMs struggle with long-horizon tasks, especially under partial observability. World models are a promising way to enhance policy performance, both during training and inference. During inference, agents currently use world models to simulate the consequences of candidate actions before committing to an action, which can improve decision-making. However, we argue that simulation alone is an incomplete interface for decision-making under partial observability: simulation doesn't adequately capture uncertainty about the current state, which agents may need for accurate decision-making. We address this limitation with Belief-Based World Models (BB-WMs), which model and maintain a belief that LLMs can query to access information on what is known and uncertain about the current state. Before developing methods to learn accurate BB-WMs, we first ask a more fundamental question: does exposing a world model's belief directly to an LLM policy improve decision-making? Our results show that giving LLM agents access to world model beliefs improves task performance under partial observability, while remaining complementary to existing simulation-based world models. Code is released at https://github.com/skumar-ml/belief-world-models.

## 1. 核心问题与整体含义（研究动机与背景）

- 近年来，LLM 已被广泛用作自主决策与规划的策略模型，但其在**长时间跨度、部分可观测（partial observability）** 的任务中表现欠佳。部分可观测性要求智能体不仅要规划未来，还要持续推断“当前真正处于什么状态”。
- 现有基于 LLM 智能体的世界模型（world model）普遍采用**仿真（simulation）接口**：给定当前状态表示和候选动作，模型预测未来轨迹，帮助策略评估动作的后果。
- 论文指出，这种“仅仿真”的接口在部分可观测条件下**并不充分**：仿真结果混合了当前状态的不确定性与未来转移的随机性，无法让智能体直接了解“此刻环境中哪些信息已知、哪些信息未知、各项可能性有多大”。
- 为此，作者提出**基于信念的世界模型（Belief-Based World Models, BB-WMs）**：世界模型显式维护对当前隐状态的信念分布，并允许 LLM 策略通过自然语言查询该信念，从而将信念追踪的负担从 LLM 策略中解耦出来。
- 在探索如何学习大规模 BB-WM 之前，论文聚焦于一个更基础的问题：**直接向 LLM 策略暴露世界模型的信念，能否改善部分可观测条件下的决策质量？** 实验给出的答案是肯定的，且信念查询与仿真接口具有互补性。

## 2. 方法论：核心思想与技术细节

### 2.1 核心思想

- 延续 POMDP 与部分可观测强化学习中的经典思路（信念状态估计可提升决策），将其带入 LLM 智能体的模块化设定中：
  - 预训练 LLM 提供通用推理与动作选择；
  - 外部世界模型负责环境知识与信念维护；
  - 两者通过自然语言接口解耦交互，无需重新训练 LLM。
- BB-WM 的标志性特征是**信念显式化与可查询化**，而非仅作为内部表征。

### 2.2 形式化表述

- 智能体在时刻 t 接收观测 oₜ、执行动作 aₜ，环境返回新观测 oₜ₊₁。
- BB-WM 的内部状态表示为：

  xₜ = (bₜ, ξₜ)

  其中 bₜ = P(sₜ | hₜ) 是对当前环境隐状态 sₜ 的信念（即给定全部历史 hₜ 的后验分布），ξₜ 为其他附加信息。

- 世界模型的核心操作：

  - **先验预测**：执行动作 aₜ 后，得到下一时刻的先验表示 xₜ₊₁⁻ = Predict(xₜ, aₜ)；
  - **后验更新**：观察到 oₜ₊₁ 后，更新为后验表示 xₜ₊₁ = Update(xₜ₊₁⁻, oₜ₊₁)。

- BB-WM 对外暴露两个互补接口：

  1. **仿真接口（Simulation interface）**：给定候选动作 aₜ⁽ⁱ⁾，预测未来内部状态并输出策略可读的结果 y_sim = R_sim(x̂ₜ₊₁⁽ⁱ⁾)，用于评估“务实动作（pragmatic action）”的后果。
  2. **信念查询接口（Belief-query interface）**：策略可以直接发出查询 q，世界模型返回 y_bel = R_bel(bₜ, q)，用于支持“认知动作（epistemic action）”（如检查盲区、确定目标物体位置），即判断是否需要通过额外探索来消除不确定性。

### 2.3 基准任务上的实例化方式（关键：用于隔离验证）

- 由于论文的核心是验证“暴露信念是否有用”，而非提出可扩展的信念学习算法，作者在 ALFWorld 和 ScienceWorld 两个文本环境中**手工指定**了：
  - 任务相关的状态空间；
  - 先验信念 Predict(·)；
  - 后验信念更新 Update(·)。
- 信念均以**物体位置上的类别分布**形式表示：

  - ALFWorld：物体可能位于哪些 receptacle（如 fridge、cabinet、countertop 等）。
  - ScienceWorld：物体可能位于哪一房间（10 个固定房间）。

- 信念更新采用简单的“存在/不存在再归一化”规则：
  - 在某个容器/房间找到目标物体 → 信念坍缩为点估计；
  - 搜索后未找到 → 将该位置的概率置零并在剩余位置间重新归一化。
- 信念先验来自环境本身的物体摆放规则：均匀分布在该物体允许出现的容器/房间集合上。
- 状态空间分为两部分：
  - **确定性/记忆部分（deterministic memory）**：如智能体位置、物品栏、已观察容器内容、任务目标等，由规则逻辑更新；
  - **概率部分（probabilistic belief）**：对未观测目标物体位置的信念分布。

### 2.4 动作与查询提示结构

- 在与 LLM 的交互中，智能体额外拥有 `query` 动作（不消耗环境步数），可查询：
  - `query where is {obj}`：目标物体最可能的位置列表（由概率排序）；
  - `query what is in {recep}`：某容器/房间已见内容；
  - `query searched {recep/room}`：某位置是否搜索过；
  - `query state`：当前已知确定性状态摘要。
- 仿真接口方面：
  - ALFWorld 上采用 **WALL-E**（基于规则的“动作有效/无效”校验器，不预测完整下一状态，也不维护信念）；
  - ScienceWorld 上没有现成的 WALL-E 实现，故采用 **Oracle 版本**：直接调用环境判断动作有效性并给出通用反馈。

## 3. 实验设计

### 3.1 基准环境与数据集

- **ALFWorld**：文本版家务智能体环境（部分可观测，物体位置随机初始化且容器内容需实际搜索才能发现）。任务包括：拾取/放置、清洁、加热/冷却等。评测使用 **unseen split**。在 30 步内完成任务，采用提前终止逻辑（连续 10 次无效动作或 10 次连续 WM 查询则终止）。
- **ScienceWorld**：小学科学实验类文本环境，固定 10 房间，任务包括物态变化、植物种植、化学混合等。评测 24 种测试任务类型，每个任务族有各自的步数预算。奖励范围为 [0, 100]，允许部分奖励。

### 3.2 评测的 LLM 与 Agent 框架

- LLM（3 种，覆盖不同规模/厂商）：
  - Llama-3.1-8B-Instruct
  - Qwen3-14B
  - Sonnet 4.6
- Agent 框架（2 种）：
  - **ReAct**：推理 + 行动交替
  - **ReflAct**：基于目标状态反思的决策框架

### 3.3 对比方法

| 方法 | 仿真接口 | 信念查询接口 |
|---|---|---|
| Base (ReAct / ReflAct) | ✗ | ✗ |
| + Belief | ✗ | ✓ |
| + WALL-E（ALFWorld）/ + Oracle（ScienceWorld） | ✓ | ✗ |
| + BB-WM | ✓ | ✓（两者组合） |

- 另设 **Memory-only 消融**：仅保留确定性记忆组件，去掉概率信念，用于区分性能提升究竟来自“记忆”还是“信念”。

### 3.4 评测指标

- ALFWorld：**SR@1**（首次尝试成功率，取任务解决与否）+ 平均步数（仅统计解决的任务，衡量效率）。
- ScienceWorld：**AR**（平均奖励，0–100）+ **AR/step**（单位步长奖励，衡量效率）。

### 3.5 实验次数

- Llama 和 Qwen：每组条件运行 **3 次**，报告均值和标准差。
- Sonnet：仅进行 **1 次运行**，无标准差。

## 6. 主要结论与发现

1. **暴露信念显著提升部分可观测场景下的决策质量**：BB-WM 在几乎所有“LLM + 框架 + 基准任务”组合下，相对于基础智能体都带来了更高的成功率和更优的效率。
2. **仿真接口与信念查询接口具有互补性**：二者分别弥补基础智能体的不同短板。例如 ALFWorld 中 Llama+ReAct 在单独使用 Belief 或 WALL-E 时各有增益，而二者组合（BB-WM）进一步提升；在部分情况下单独使用 WALL-E 甚至有害（如 Qwen3-14B+ReflAct 于 ALFWorld），但组合进 BB-WM 后反而超过单独 Belief 的效果。
3. **信念的价值独立于确定性记忆**：Memory-only 消融下性能明显回退，某些情况下甚至与基础智能体相当，说明概率信念（对未观测位置建模）才是增益的关键来源。
4. **模型能力影响世界模型的边际价值**：对较小/较弱模型（Llama-3.1-8B）增益最明显；对能力极强的模型（Sonnet），在较简单任务上其本身已能隐式追踪状态，因此额外增益有限——ALFWorld 有轻微提升，ScienceWorld 上主要是效率改善，性能无显著变化。
5. **世界模型可以通过信念暴露世界知识**：例如 ALFWorld 案例中，WALL-E 无法告知 LLM“鸡蛋不可能出现在紫色容器中”，而 BB-WM 的先验信念可以；ScienceWorld 案例中，信念查询引导智能体将橘子树苗种在温室的合适容器中，而不是浴缸里。

## 7. 优点与亮点

- **切入点有新意**：将经典 POMDP 中“信念状态”的概念系统引入 LLM 智能体的世界模型接口设计，与已有世界模型研究形成明确区别。
- **概念框架清晰**：形式化定义了 BB-WM 的内部结构（信念 + 附加信息）、先验预测（Predict）、后验更新（Update）以及对外双接口（仿真 + 信念查询），为后续研究提供了可扩展的抽象框架。
- **问题隔离策略得当**：通过手工指定状态空间和更新规则，刻意避开“如何学习精确世界模型”这一难题，从而干净地回答“暴露信念是否有用”的问题，研究设计逻辑合理。
- **消融设计严谨**：Belief vs. Simulation vs. BB-WM 的分解实验 + Memory vs. Belief 消融，使得主要结论排除了主要混杂因素。
- **与现有工作兼容**：BB-WM 不排斥现有仿真接口，而是将信念查询作为补充——在 WALL-E 之上叠加信念接口即可生效，具备实践上的集成便利性。
- **结果稳健且直觉一致**：验证了“模型越弱或任务越难，外部化信念追踪的收益越大”这一合理假设；对于强大模型的能力饱和现象也做出了合理解释。

## 8. 不足与局限

- **不涉及可扩展学习 BB-WM 的方法**：论文使用的状态空间、先验与更新规则均为手工设计，无法直接推广到真实复杂环境；作者也明确指出可扩展学习方法留待后续研究。
- **验证限于简单文本环境**：ALFWorld 和 ScienceWorld 均为结构化文本模拟，不确定性局限于物体位置，无法充分代表视觉/物理世界中的部分可观测问题。
- **实验样本数有限**：主要模型的运行次数为 3 次（Sonnet 仅 1 次），部分条件下性能标准差较大，统计显著性较为有限。
- **可能低估“仿真+信念”耦合的价值**：手工的 WALL-E 仅提供“有效/无效”的二元校验，并未完整预测下一状态，因此组合接口的真实潜力可能被低估，同时也意味着组合效果未得到最完整的检验；论文中 ScienceWorld 使用的 Oracle 版本也提供不了像 WALL-E 那样具体的反馈。
- **对失败模式的分析较浅**：虽然提供了若干成功轨迹，但缺少系统性的失败案例分析（如增加信念后仍然失败的情况），也没有统计不同类型的错误减少情况。
- **局限在“物体位置”单类不确定性**：未讨论信念在更复杂状态（如进程状态、关系状态或动态变化）中的表示和更新方式，领域泛化性尚不明确。
