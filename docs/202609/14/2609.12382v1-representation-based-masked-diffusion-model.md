## 摘要
掩码扩散模型（MDMs）已成为一种引人注目的语言建模范式，能够高效地并行生成文本。然而，现有的并行采样方法通常独立地更新多个掩码 token，并忽略了掩码 token 之间复杂的相互依赖关系。这种独立更新机制缺乏全局协调，可能导致输出不连贯。为解决这一局限，我们提出基于表示的掩码扩散模型（RMDM），该框架利用文本表示来显式编码全局语义，并帮助更精确地并行更新 token。具体而言，我们首先使用预训练编码器将文本编码到连续语义空间，并学习一个可逆变换，将表示分布归一化为高斯先验，从而在生成过程中实现高效采样。以该潜在语义表示为条件，我们训练一个掩码扩散模型来学习条件文本分布，其中表示作为全局语义指导，协调并行 token 更新并忠实地逼近目标分布。实证结果表明，RMDM 显著提升了生成质量，尤其是在激进的少步采样设置下。

## Abstract
Masked Diffusion Models (MDMs) have emerged as a compelling paradigm for language modeling, offering the capability for efficient parallel text generation. However, existing parallel sampling methods typically update multiple masked tokens independently and ignore the complex mutual dependencies among the masked tokens. This independent updating mechanism lacks global coordination and might lead to incoherent outputs. To address this limitation, we propose Representation-based Masked Diffusion Model (RMDM), a framework that leverages the text representation to explicitly encode global semantics and help to parallel update tokens more precisely. Specifically, we first encode text into a continuous semantic space using a pretrained encoder and learn an invertible transformation that normalizes the representation distribution to a Gaussian prior, facilitating efficient sampling during generation. Conditioned on this latent semantic representation, we train a masked diffusion model to learn the conditional text distribution, where the representation serves as global semantic guidance to coordinate parallel token updates and faithfully approximate the target distribution. Empirical results demonstrate that RMDM significantly improves generation quality, particularly in aggressive few-step sampling regimes.

# 论文总结：Representation-based Masked Diffusion Model (RMDM)

## 1. 核心问题与整体含义

- **背景**：自回归（AR）语言模型推理受 O(L) 串行复杂度制约；掩码扩散模型（MDMs）通过迭代去噪实现并行 token 生成，成为有吸引力的替代范式。
- **核心问题**：现有并行采样方法在单次迭代中独立更新多个掩码 token，隐式地将联合后验因子化为各位置边缘分布的乘积：$p_\theta(x_M|x_U) \approx \prod_{i\in M} p_\theta(x_i|x_U)$。
- **问题后果**：自然语言中掩码 token 间存在由句法一致、长程约束、多词表达、实体一致性等引起的残余依赖，因子化假设与之不符，激进并行化会产生"局部合理、全局不一致"的输出。
- **形式化**：论文用条件总相关定义 **Conditional Dependency Gap** $T(x_M|x_U)$，衡量未被观测上下文解释的掩码 token 内在依赖，并围绕缩小该鸿沟构建方法。

## 2. 方法论

### 核心思想
- 引入全局连续潜在变量 $z$ 编码整句语义（主题、意图等共享全局因子），作为掩码 token 的"共同原因"（见图 2 因果图），条件化后可"解释掉"残余相关，使并行独立采样逼近真实联合分布。

### 两阶段训练（算法 1）
- **Stage I：表示映射（MeanFlow 对齐）**
  - 用预训练编码器 $g_\psi$ 将文本编码为上下文嵌入 $z_1 = g_\psi(x_0)\in\mathbb{R}^{L\times D_z}$。
  - 用 MeanFlow $u_\phi$ 学习从嵌入分布到标准高斯先验 $z_0\sim\mathcal{N}(0,I)$ 的传输，采用线性插值路径 $z_t=(1-t)z_0+tz_1$ 与平均速度场，目标为 MeanFlow 恒等式（式 2），总导数通过 JVP 计算。
  - 训练后支持一步反演：$z_0 = z_1 - u_\phi(z_1,0,1)$；UMAP 显示 $z_0$ 分布稳定、$z_1$ 保留语义结构。
- **Stage II：条件生成建模**
  - 冻结编码器与 MeanFlow，计算数据相关潜在表示 $z_0 = g_\psi(x_0) - u_\phi(g_\psi(x_0),0,1)$。
  - 训练 RMDM $p_\theta(x_0^i|x_t,z_0)$，损失为式 3（MDM 标准 ELBO 加 $z_0$ 条件）。
- **推理（算法 2）**：直接从先验采样一次 $z\sim\mathcal{N}(0,I)$，全程固定复用；**编码器与 MeanFlow 网络在生成时不参与**，无额外推理开销。

### 理论支撑
- **Proposition 3.1**：残差依赖鸿沟 $T(x_M|x_U,z)=0$ 当且仅当掩码 token 在 $(x_U,z)$ 下条件独立；引入 $z$ 带来的鸿沟缩减为 $\Delta T = \sum_{i\in M} I(x_i;z|x_U) - I(x_M;z|x_U)$。
- **Proposition 3.2**：联合 KL 的三元分解——(I) MeanFlow–先验失配、(II) 残余条件依赖、(III) 逐 token 预测误差，分别对应两阶段框架的优化目标。

### 架构细节
- MeanFlow 与 RMDM 均采用 **DiT** 骨干（12 层、768 隐维、12 头）。
- 通过 **AdaLN** 将 $z$ 注入每个 Transformer 块：$f_{\text{AdaLN}}(h;z)=f(\gamma(z)\odot \text{LN}(h)+\beta(z))\odot\alpha(z)+h$。
- **潜在稳定化**：正交线性映射做通道瓶颈降维（$d_z < D_z$），并在训练时注入各向同性高斯噪声 $\epsilon\sim\mathcal{N}(0,\sigma^2 I)$ 作平滑正则，缓解对训练潜在表示的过拟合。

## 6. 主要结论与发现

- **质量提升**：OWT 上 RMDM 在所有采样预算下 GenPPL 与 LLM 评委分数均优于 MDLM/SEDD，且**采样步数越少优势越明显**（16 步时 GenPPL 126.58 vs MDLM 213.44）。
- **效率提升**：同质量下吞吐量约 **3.5–3.6×**（如 GenPPL≤50：MDLM 1024 步 80 tok/s → RMDM 256 步 287 tok/s）；同步数下仅损失约 10% 吞吐。
- **似然不退化**：LM1B 测试 PPL 达 **17.00**（1M iterations），优于 MDLM† 的 27.60、SEDD 的 32.79，甚至优于 AR 基线；作者推测部分得益于 LM1B 中大量 [PAD] token 可被句级表示识别。
- **零样本泛化**：OWT 训练模型在 6 个测试集上零样本 PPL 全面优于扩散基线，接近但未超越 AR。
- **消融结论**：仅替换为独立采样的高斯 $z$ 显著变差，说明增益来自**数据相关的语义表示**而非单纯增加条件通路；编码器敏感性实验表明收益不局限于特定编码器族，但幅度依赖表示源质量。

## 7. 优点

- **理论扎实**：将并行采样的因子化误差形式化为条件总相关，并给出残差鸿沟归零的充要条件与联合 KL 三元分解，为两阶段设计提供统一解释。
- **工程实用**：推理时只从先验采样一次 latent，编码器与 MeanFlow 均不下场，几乎不增加采样显存与延迟（同步数仅慢约 10%）。
- **训练-推理失配处理得当**：用 MeanFlow 做群体级分布对齐而非 VAE 式逐样本后验约束，规避了高容量语言模型中的 KL 与重建目标冲突及后验坍塌。
- **架构兼容性强**：AdaLN 注入 + 通道瓶颈 + 噪声正则，便于接入不同编码器（BERT、Qwen3、ModernBERT 均验证有效）。
- **评测规范**：双独立 LLM 评委 + 置信区间 + 自复现基线 + 同 tokenizer/骨干/优化配置的对照，减少评测偏差。

## 8. 不足与局限

- **规模与任务覆盖有限**：仅做 GPT-2 级规模的无条件生成，未验证更大模型与条件生成（如翻译、摘要、可控生成）的可迁移性，作者在 Limitations 中已承认。
- **训练成本偏高**：未缓存实现下 RMDM 训练约为基线的 1.6 倍时长（5 天 vs 3 天 5 小时），虽理论上可缓存，但实际报告成本较高。
- **外部知识不对称**：RMDM 额外使用预训练编码器表示，基线未获同等外部知识，绝对性能对比存在先天优势，难以完全归因于方法本身。
- **指标代理性**：GenPPL 依赖 GPT-2 作为评测器，与人类感知质量存在偏差；LLM 评委绝对分数普遍偏低（1–2.4/10 区间），判别分辨率有限。
- **LM1B 结论的特殊性**：作者自述 LM1B 的优异表现可能与大量 [PAD] token 有关，该结论对其他语料的推广性存疑。
- **残余依赖未完全消除**：理论分解中的 (II) 项由编码器表示能力决定，无法保证归零，输出样例中仍可见重复与语义漂移。
- **潜在表示质量依赖编码器**：ModernBERT 版本改进幅度明显小于 Qwen3，说明方法对表示源较敏感，缺乏对弱编码器场景的鲁棒性分析。
