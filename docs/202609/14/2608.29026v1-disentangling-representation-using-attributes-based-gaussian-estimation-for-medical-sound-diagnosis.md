## 摘要
深度学习具有强大的特征提取能力。然而，深度神经网络缺乏公平性和可解释性，限制了其在医学领域的应用。本文提出了一种解耦表示学习（DisenRL）框架，称为基于属性的高斯估计解耦表示（AGEDR），其中包含属性映射嵌入（AME）模块，旨在将属性映射为向量，并将其与变分自编码器（VAE）中潜在向量的一部分对齐。这部分潜在向量将通过最小化互信息与其余潜在向量解耦。然后，使用来自VAE的潜在向量的均值参数训练分类器。大量实验表明，AGEDR优于传统分类模型和现有的解耦表示学习方法。消融实验也表明了AGEDR的解耦能力和公平性。源代码公开于 https://github.com/ZhaoKe1024/DisentangledRepr。

## Abstract
Deep learning has a powerful capability of feature extraction. However, the lack of fairness and interpretability in deep neural networks poses limitations to their adoption in the medical domain. This paper proposes a disentangled representation learning (DisenRL) framework, named the Attributes-based Gaussian Estimation for Disentangled Representation (AGEDR), which incorporates Attribute Mapping Embedding (AME) modules designed to map attributes into vectors and align them with a subset of the latent vectors in a Variational AutoEncoder (VAE). This part of the latent vector will be disentangled from the remaining latent vectors by minimizing mutual information. A classifier is then trained using the mean parameters of the latent vectors from the VAE. Extensive experiments demonstrate that AGEDR outperforms both conventional classification models and existing disentangled representation learning methods. The ablation experiments also indicate the disentangling capability and fairness of AGEDR. The source code is publicly available at https://github.com/ZhaoKe1024/DisentangledRepr.

## 1. 核心问题与研究动机

- **背景**：深度学习在医学信号分析（如咳嗽音诊断）中特征提取能力强大，但存在两大落地障碍：
  - **缺乏公平性**：模型对不同性别、病史、生活习惯的人群产生系统性偏差；
  - **缺乏可解释性**：自动提取的特征是黑箱，难以被临床信任。
- **根源问题**：人体体质、年龄、性别、生活方式、病史、地域环境等差异导致 **域偏移（domain shift）**，使模型在不同属性人群上的泛化能力下降。
- **已有方案**：解耦表示学习（DisenRL）通过获得可分解结构的潜向量，缓解偏差与域偏移；其中**有监督解耦**可将潜向量与真实语义对齐，从而真正提升可解释性。
- **关键痛点**：现有方法（InfoGAN、GSL、IDB-SR 等）需引入属性/结构先验。若仅用普通深度网络 + 分类任务训练，提取的属性相关潜向量**没有先验分布**，无法做概率密度估计，因而无法计算 KL 散度与互信息（MI）。VAE 具备概率建模能力，但需要额外的机制把属性语义"注入"并对齐到潜向量中。
- **整体含义**：本文试图在**保持分类性能**的前提下，把属性语义从潜表示中显式分离出来，从而同时获得**可解释性、公平性与可靠性**，服务于医学音频诊断。

## 2. 方法论（AGEDR）

### 2.1 核心思想

- 构建由 **AME（属性映射嵌入）模块 + VAE** 两部分组成的框架：
  - **AME**：把标量属性映射为高斯分布参数，经重参数化得到属性潜向量 $\hat{z}_\alpha$；
  - **VAE**：从原始音频中提取潜向量 $z = \text{concat}(z_\beta, z_\alpha)$；
  - 用 **KL 散度** 把 AME 的 $\hat{z}_\alpha$ 与 VAE 的 $z_\alpha$ 对齐（使 VAE 无需额外标注即可提取属性信息）；
  - 用 **互信息最小化** 让 $z_\alpha$ 与 $z_\beta$ 解耦。

### 2.2 关键技术细节

- **AME 模块（三步）**：
  1. **映射函数**：类别型属性用 one-hot 从矩阵 $M_{dis}\in\mathbb{R}^{n^{(i)}\times c^{(i)}}$ 中选列；连续型属性用列矩阵 $M_{con}$ 变换；
  2. **估计器**：两层神经网络估计正态分布参数 $(\hat{\mu}^{(i)}, \hat{\sigma}^{(i)})$；
  3. **重参数化**：$\hat{z}^{(i)} = \hat{\mu}^{(i)} + \hat{\sigma}^{(i)} \odot \epsilon^{(i)},\ \epsilon^{(i)}\sim N(0,1)$。
- **潜向量划分**：VAE 潜维 $N$ 被划分为
  - $z_\alpha = \text{concat}(z^{(1)},\dots,z^{(r)})$，维度 $n^{(1)},\dots,n^{(r)}$，对应 $r$ 个属性；
  - $z_\beta$，维度 $n^{(0)}$，表示除这些属性外的其余混合信息；
  - 满足 $\sum_{i=0}^{r} n^{(i)} = N$。
- **属性对齐损失**（KL 散度作为正则项，含显式解析式）：
  - $L_{attri}^{(i)} = \sum_{i=1}^{r} D_{KL}(z^{(i)} \| \hat{z}^{(i)})$，展开为对数标准差项 + 均值/方差项 − r/2。
- **解耦损失**：由于 $z_\alpha$ 与 $z_\beta$ 的联合分布未知且各属性维度不等，无法直接算 KL；采用**互信息的变分上界（ELBO）**：
  - $MI(z_\alpha,z_\beta) \le L_{Disen}$，由三项组成：
    1. $E_{x,x'}\,KL(p(z_\alpha|x)\,\|\,p(z_\alpha|x'))$（不同样本后验间的差异）
    2. $E_{x,x'}\,KL(p(z_\beta|x)\,\|\,p(z_\beta|x'))$
    3. $-E_{x,z}\, \log q(x|z)$（重构项，来自 MI 的 ELBO）
- **分类任务**：
  - 因重参数化引入噪声（利于生成、不利预测），**直接取编码器输出的均值参数 $\mu$** 作为分类器输入；
  - 使用 **focal loss** 应对类别不平衡；
  - 总损失为四项加权组合：$L_{total} = w_1L_{cls} + w_2L_{vae} + w_3\sum_i L_{attri}^{(i)} - w_4L_{Disen}$，其中 $L_{Disen}$ 进一步展开为 $v_1,v_2,v_3$ 加权的三个 MI 项。
- **超参数设置**：潜维 30 = 6（cough type）+ 8（severity）+ 16（非属性）；$w_1{=}2.0, w_2{=}0.3, w_3{=}0.0025, w_4{=}0.01$；$v_1{=}1.0, v_2{=}1.25, v_3{=}5.0$；学习率 AME/VAE/分类器分别为 0.0003 / 0.0001 / 0.0002；Adam 优化器；训练 370 轮收敛。
