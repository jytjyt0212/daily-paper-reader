## 摘要
预训练的驾驶视觉语言模型（VLM）将视觉、路线、语言和驾驶上下文整合为丰富的驾驶先验，但其表示目标仍与连续驾驶规划相分离。现有方法通常仅在VLM形成最终条件后才开始生成轨迹，使深度维度上的条件计算游离于轨迹状态的逐步形成之外。我们提出DiffAdapterVLA，实现了“在主干中规划”：它将显式轨迹token注入选定的VLM后部层，使轨迹状态进入主干前向计算，并在不同深度与驾驶条件共同演化。轻量级逐层DiffAdapter将这一计算组织为递归轨迹细化，而非对称联合注意力保持从条件流到轨迹规划的有向引导。通过将规划置于现有主干计算中，而非依赖独立的轨迹规划器，DiffAdapterVLA仅调整轻量级轨迹模块，即可将现有驾驶先验转化为高效的连续规划能力。NAVSIM结果表明，它仅使用少量可训练参数，就以较低的端到端延迟实现了高质量的闭环规划，并证明在VLM后层计算中联合演化轨迹状态与深度维度上的驾驶条件能够有效实现连续轨迹规划。

## Abstract
Pretrained driving vision-language models (VLMs) integrate visual, route, language, and driving context into rich driving priors, yet their representation objectives remain separated from continuous driving planning. Existing methods typically begin trajectory generation only after the VLM has formed a final condition, leaving depth-wise condition computation outside the stepwise formation of trajectory state. We introduce DiffAdapterVLA, which realizes Planning in the Backbone: it injects explicit trajectory tokens into selected VLM late layers, bringing trajectory state into backbone forward computation, where it co-evolves with driving conditions at different depths. Lightweight layer-wise DiffAdapters organize this computation into recursive trajectory refinement, while asymmetric joint attention preserves directed guidance from the condition stream to trajectory planning. By placing planning within existing backbone computation rather than relying on an independent trajectory planner, DiffAdapterVLA adapts only lightweight trajectory modules to turn existing driving priors into efficient continuous planning capability. NAVSIM results show that it achieves high-quality closed-loop planning with low end-to-end latency using few trainable parameters, and demonstrate that jointly evolving trajectory state and depth-wise driving conditions in VLM late-layer computation effectively realizes continuous trajectory planning.

- **核心问题**：预训练驾驶 VLM 的表征目标与连续驾驶规划之间存在鸿沟。VLM 通常通过离散序列预测学习视觉-语言语义，而驾驶需要几何精确、时间连续、动态可行且满足实时约束的轨迹。
- **现有接口的局限**：论文将现有“理解—动作”接口归为三类：

  - Final-cache 动作生成：将 VLM 最终层隐状态、规划 token 或条件 cache 传给下游动作专家/扩散规划器；
  - 自回归动作 VLA：将动作或轨迹离散化为 token 进行下一 token 预测。
- **关键不足**：前两类中，轨迹演化在 VLM 条件计算完成之后才开始；第三类把连续规划重构为离散生成。三者都导致 VLM 内部深度演化中的驾驶条件无法直接参与连续轨迹状态的形成。
- **整体含义**：论文提出 **Backbone-native continuous planning**，即“Planning in the Backbone”。让显式轨迹状态进入 VLM 后层前向计算，与不同深度的驾驶条件共同演化，使轨迹不再是场景理解的最终输出，而是在后层计算中逐层成形。

## 2. 方法论

### 2.1 核心思想

- 在冻结的驾驶 VLM 主干中，将显式轨迹 token 注入选定的后 K 层。
- 轨迹状态在主干前向计算中与深度演化的驾驶条件共同更新，实现递归轨迹细化。
- 不依赖独立的外部轨迹规划器，仅训练轻量级轨迹模块，将已有驾驶先验转化为连续规划能力。

### 2.2 基础设置与问题定义

- 条件输入：\(c_t = (I^{1:M}_t, r_t, h_t)\)，包括多相机视觉观测、路线/导航信息、车辆历史与驾驶上下文。
- 目标：生成 H 个未来路点轨迹 \(x_0 = [p_{t+1}, \dots, p_{t+H}] \in \mathbb{R}^{H \times d}\)。
- 使用预训练驾驶 VLM \(F_\theta\)，共 L 层 Transformer；论文实例化为 **Cosmos-Reason2-8B** 主干，来自 Alpamayo-1.5-10B，训练中保持 \(\theta\) 冻结。
- 条件扩散建模：对干净轨迹 \(x_0\) 加高斯噪声得到 \(x_s\)，条件去噪器预测噪声 \(\hat{\epsilon} = \epsilon_\phi(x_s, s; c_t)\)，训练目标为标准噪声预测损失。
- 推理使用 DDPM 噪声预测参数化与 DDIM 确定性采样思想。

### 2.3 历史轨迹编码器

- 将 ego-motion 历史映射为紧凑上下文向量 \(g_t\)，为去噪提供运动连续性锚点。
- 每个历史位置构造 7 维描述符：绝对位置、平面位移、有效性 mask、有效历史统计量。
- 经线性投影、归一化、无效位置 mask 后，使用 depthwise 时间卷积（kernel=3）捕捉局部运动变化。
- 通过 masked mean pooling 聚合，再用两个残差 MLP 变换，输出 \(g_t \in \mathbb{R}^D\)。
- \(g_t\) 被所有选定的后层 DiffAdapter 共享，提供持续的历史相关运动上下文。

### 2.4 DiffAdapter 与轨迹 token

- 将噪声未来轨迹 \(x_s\) 表示为 VLM 隐空间中的轨迹 token：
  - 线性投影 \(W_{traj}x_{s,i}\)；
  - 加未来位置 embedding；
  - 加轨迹 token 类型 embedding；
  - 加扩散步 embedding。
- 前 \(L-K\) 层冻结 VLM 层处理多模态条件 \(c_t\)，保持原始计算。
- 后 K 层中，轨迹 token 被附加到条件 token 后共同前向传播。
- 每层后接独立 DiffAdapter：
  - 只更新轨迹 slice，条件 slice 保持原 VLM 传播；
  - bottleneck 维度 384，8 个注意力头；
  - 使用扩散步 \(s\) 的 sinusoidal embedding 经 SiLU MLP 产生 AdaLN 仿射调制和残差门控；
  - 包含 depthwise 卷积混合邻近未来路点、多头自注意力捕捉长程依赖、交叉注意力读取当前条件表示、历史摘要门控融合、门控 FFN；
  - 外层残差连接写回轨迹 token。
- 最终轨迹 token 经 VLM 最终归一化层和轻量线性 readout 解码，预测噪声 \(\hat{\epsilon}_s\)。

### 2.5 条件保持的非对称联合注意力

- 后 K 层接收条件 token 与轨迹 token 的联合序列，二者读权限不对称。
- 注意力 mask 设计：
  - 条件 token 之间保留原 VLM 因果 mask；
  - 条件 query 不能关注轨迹 token；
  - 轨迹 token 之间可双向交互；
  - 轨迹 token 可关注所有有效条件 token，无效条件位置被排除。
- 效果：条件流保持原始传播，不受噪声轨迹信息污染；轨迹状态可获得当前深度驾驶条件、其他未来路点信息以及 DiffAdapter 更新。
- 信息流是定向的：驾驶条件引导轨迹去噪，噪声轨迹不进入条件流。

### 2.6 推理与条件复用

- 从高斯噪声开始，使用 **5 步等间隔确定性 \(x_0\) 投影** 恢复规划轨迹。
- 每一步估计裁剪后的干净轨迹并重缩放到下一噪声水平。
- 由于驾驶条件在去噪中固定，早期层条件隐状态、有效性 mask、位置信息可缓存并跨去噪步复用。
- 历史编码器每样本只计算一次 \(g_t\)，跨所有去噪步和选定后层共享。

### 2.7 训练流程

- 仅训练线性轨迹 embedding、DiffAdapter、历史轨迹编码器、轻量轨迹 readout，共约 **3.05% 模型参数**。
- 将 12 个 layer-specific DiffAdapter 插入最后 \(K=12\) 层。
- 第一阶段：SFT 80 epochs，DDPM 噪声预测目标，100 个扩散步。
- 第二阶段：从 SFT 检查点出发，使用 DiffGRPO 再训练 10 epochs。
