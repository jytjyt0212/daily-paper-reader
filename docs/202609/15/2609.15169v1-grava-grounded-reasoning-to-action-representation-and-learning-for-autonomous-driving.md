## 摘要
驾驶视觉-语言-动作（VLA）模型越来越多地先推理后行动，但其中间推理往往缺乏对物理场景证据的坚实锚定，且与可执行行为联系松散。我们提出 GRAVA，一个围绕基于物理场景锚定的推理到动作（Grounded Reasoning-to-Action, GRA）构建的框架，它在单一自回归流中统一了锚定、推理与动作生成。GRA 将动作相关的语言指代与二维视觉区域和自车中心物理状态相关联，在轨迹锚定的类型化图中组织对象交互与决策，并将该结构序列化为有物理依据的推理。单个 VLM 生成该推理，随后生成紧凑的 Executable Planner 动作，该动作被确定性地解码为连续轨迹。我们进一步提出一个智能体式 GRA 数据构建流程，它将前向场景锚定与后向轨迹锚定相结合，并用其构建了包含 220 万条有依据的问答对和 7 万条 GRA 推理轨迹的 GR-NavSim。一种渐进式训练策略通过预训练发展有依据的认知，通过模仿建立推理到动作的接口，并通过强化学习与探索改进驾驶行为。在仅使用约 60% 的可用人类驾驶演示进行动作监督的情况下，GRAVA-8B 在完整 NAVSIM 基准上取得了纯自回归驾驶模型中的最先进性能。在内部长尾基准上，完整 GRA 相比仅动作预测，将关键对象合规性和闭环驾驶得分分别提升了 19.3% 和 20.5%。这些结果表明，在从有依据的推理到可执行动作生成的过程中保留动作相关的物理证据具有优势。

## Abstract
Driving vision-language-action (VLA) models increasingly reason before acting, but their intermediate reasoning is often weakly grounded in physical scene evidence and loosely connected to executable behavior. We present GRAVA, a framework built around Grounded Reasoning-to-Action (GRA), which unifies grounding, reasoning, and action generation in a single autoregressive stream. GRA links action-relevant language references to 2D visual regions and ego-centric physical states, organizes object interactions and decisions in a trajectory-anchored typed graph, and serializes this structure into grounded reasoning. A single VLM generates this reasoning followed by a compact Executable Planner action that is deterministically decoded into a continuous trajectory. We further introduce an agentic GRA data construction pipeline that combines forward scene grounding with backward trajectory anchoring, and use it to build GR-NavSim with 2.2M grounded question-answer pairs and 70K GRA reasoning traces. A progressive training strategy develops grounded cognition through pre-training, establishes the reasoning-to-action interface through imitation, and improves driving behavior through reinforcement learning and exploration. Using about 60% of the available human driving demonstrations for action supervision, GRAVA-8B achieves state-of-the-art performance among purely autoregressive driving models on the full NAVSIM benchmark. On an internal long-tail benchmark, full GRA improves key-object compliance and Closed-loop Driving Score by 19.3% and 20.5% over action-only prediction, respectively. These results show the benefit of preserving action-relevant physical evidence from grounded reasoning through executable action generation.

## 一、核心问题与研究动机

- **背景**：视觉-语言-动作（VLA）模型正成为自动驾驶的新范式，把多模态场景理解、推理与动作生成整合进一个通用生成模型。近期工作（EMMA、DriveVLM、DriveLM、AutoVLA 等）在动作预测前引入显式中间推理，以应对复杂与长尾场景。
- **关键观察**：对驾驶而言，推理不仅要指出"哪些交通参与者相关"，还必须刻画它们的**物理状态与交互关系**如何约束自车行为。例如前车的影响取决于其车道占用、距离与运动状态。
- **两个核心缺陷**：
  - **接地鸿沟（G1, grounding gap）**：语言推理与物理场景证据脱节。动作相关实体常以自由文本或高层语义描述，未显式解析到图像区域与度量状态，导致"语义上合理"的理由可能悬空于真实物体、距离、运动之外。
  - **推理到动作的割裂（G2, reasoning-to-action fragmentation）**：即便有接地，也往往被放入独立的感知/问答任务，或由分离的功能模块实现；某个任务中建立的接地对象与状态，不必然被保留为后续交互推理、决策与动作生成的证据。
- **核心主张**：需要一个**以动作为导向的接地表示**，把物理证据按其"在驾驶决策中的角色"组织起来，并让该证据在整条推理链直至可执行行为中保持连续。场景相关性是动作依赖的——视觉显著物体未必是约束自车行为的物体。

## 二、方法论

### 2.1 总体框架

- **GRA（Grounded Reasoning-to-Action）表示**：在**轨迹锚定的类型化有向无环图**中组织场景上下文、接地对象、物理状态、交互、决策与规划锚点；再将其序列化为 VLM 可生成的接地推理文本，后接紧凑的 Executable Planner 动作，由**无参数固定几何解码器**转成连续轨迹。
- **生成过程**：输入 `x = (V_env, s_ego, c)`（视觉观测、自车状态、导航命令）；令 `G_a` 为动作相关子图，`r = Ser(G_a)` 为接地推理序列；随后预测动作 `a = (p, g, ϕ)`（运动基元、挡位、基元专属参数）。
- **自回归分解**：`πθ(y | x) = πθ(r | x) · πθ(a | x, r)`，`y = [r; a]`。两个因子构成连续信息流：推理引入接地对象并解释其行为相关性，动作在此上下文下生成。
- **轨迹解码**：`τ̂ = D_p(g, ϕ; s_ego)`，解码器**无可学习参数**，动作选择仍留在 `πθ(a | x, r)` 内，几何实现无需额外的学习式轨迹策略。
- **训练监督来源**：离线构建目标图 `G* = A(x, τ*, z)`，其中 `τ*` 为专家轨迹、`z` 为特权标注证据。图查询提供认知型 QA 目标，动作相关路径提供推理目标 + 专家派生的规划动作。推理时**只需 x**，不需要专家轨迹或特权证据。

### 2.2 类型化接地推理图

- 图定义为 `G = (V, E, ν, η)`；节点集分解为 `V = V^S ∪ V^O ∪ V^Ψ ∪ V^D ∪ {v_δ, v_a}`：
  - `V^S` 场景/路线上下文节点；`V^O` 接地对象节点；`V^Ψ` 交互节点；`V^D` 对象级决策节点；`v_δ` 自车级决策节点（汇聚各对象响应）；`v_a` 终端动作锚点（**不含**规划器参数）。
- **对象节点**：`o_i = (m_i, b_i, σ_i)`，`m_i` 语言指代，`b_i ∈ [0,1000)^4` 归一化 2D 框，`σ_i` 自车中心物理状态（类别、相对位置、距离、速度、朝向）。
- **对象级推理路径**：`(V^S, o_i) → {ψ^ℓ_i} → d_i, i ∈ C`（C 为关键对象集）；再在自车级合并：`(V^S, {d_i}) → v_δ → v_a`。分支-合并拓扑记录"每个响应由哪个对象支持"。
- **结构接地约束**（防止推理悬空）：
  - 每个交互/对象级决策节点必须可追溯到至少一个接地对象：`∀v ∈ V^Ψ ∪ V^D, Anc_G(v) ∩ V^O ≠ ∅`；
  - 每个对象级决策必须贡献到自车决策：`d_i → v_δ`；
  - 自车决策必须抵达动作锚点：`v_δ → v_a`。

### 2.3 轨迹锚定的图构建

- **前向场景接地**：识别候选交通参与者与场景元素，赋予视觉区域与物理状态，产生 `V^S`、`V^O`，但本身不判定哪些对象约束示范动作。
- **后向轨迹锚定**：从专家轨迹 `τ*` 出发，把示范行为回溯到关键对象、交互与决策，确立**行为相关性**。
- 两个方向合起来把"可观测证据"与"动作相关推理"连接；不贡献于示范决策的对象与关系被排除。特权证据仅用于离线构建与训练。

### 2.4 序列化与共享监督

- 取动作锚点严格祖先集的诱导子图：`G_a = G[Anc_G(v_a)]`，序列化得 `r = Ser(G_a)`；序列化遵循拓扑顺序，先引入带框 token 与物理状态的对象，再描述交互与对象级决策，最终汇聚到自车决策。**动作锚点本身不进入 r**，完整链条为 `G_a → r → a → τ̂`。
- **两类监督共享同一图**：
  - 认知目标：`L_QA = -E[log πθ(u | x, q)]`；
  - 规划目标：`r* = Ser(G*_a)`，`L_plan = -E[log πθ([r*; a*] | x)]`。
  - 通过单个问题学到的接地概念，会再次出现在支持动作的推理中，保证跨任务的对象身份、物理状态与交互语义一致。

### 2.5 Executable Planner（可执行规划器动作空间）

- 动作 `a = (p, g, ϕ)`，基元集 `P = {STOP, CRAWL, CURVE, CRUISE}`，挡位 `g ∈ {D, R}`，可执行动作空间 `A_exec = ⋃_{p∈P} ({p} × M × Φ_p)`。
- 参数空间（自车坐标系）：
  - **STOP**：endpoint ∈ R²（近静止/停止）；
  - **CRAWL**：8 个点 ∈ R^{8×2}（低速走走停停，保留逐点灵活性，坐标范围窄故直接预测可行）；
  - **CURVE**：三次 Bézier 控制点 p1,p2,p3 ∈ R^{3×2}（转弯/大曲率）；
  - **CRUISE**：progress_end、v_end、lat_end ∈ R³（车道保持与跟车）。
- 序列化形式 `Ser(a) = {planner: p, gear: g, params: ϕ}`；固定解码器输出 4 秒时域内的 8 路点轨迹 `τ̂ ∈ R^{8×2}`。STOP 依当前速度展开平滑剖面，CURVE 用三次 Bézier 在 t = 1/8…1 求值，CRUISE 用三次 Hermite 保证纵向单调 + 横向线性插值。
- 监督目标由专家轨迹**确定性**导出：先按运动剖面与导航命令定基元 `p*`，再定挡位 `g*`，只拟合对应 `Φ_p*` 的参数并量化序列化，得 `y* = [r*; a*]`。

### 2.6 渐进式训练策略

1. **GRA 预训练**：用 `L_QA` 学场景理解、指代消解、物理状态推理、交互与决策语义。
2. **Planner 轻量 warm-up**：用 `L_plan` 学"接地内容如何支持可执行动作"，建立推理→动作接口（表 S1：3 epoch，LR 1e-5）。
3. **验证式自蒸馏（verified self-distillation）**：从 warm-up 检查点采样完整序列，按解码轨迹的闭环奖励选优，保留同一 rollout 的 `y+_i = [r+_i; a+_i]`；该检查点初始化 Active RL 并作为冻结参考策略 `π_ref`。
4. **Active RL Loop**：
   - 对每个 `x` 采样 K 条完整 rollout，解码并计算奖励 `s_i = R(D_p(g,ϕ;s_ego); x)`（NAVSIM 用 PDMS；不可解析/违反 schema 记 0 奖励）；
   - **可恢复场景筛选**：先取贪心输出不足的场景 `D_g(θ) = {x : s_greedy(x) < τ_g}`，再要求组内 `max_i s_i ≥ τ_hi`、`min_i s_i < τ_lo`、`std_i(s_i) ≥ τ_σ`（补充材料：`min < 0.8`、`max ≥ 0.9`、`std ≥ 0.10`）；
   - **组相对优势**：`Â_i = (s_i - s̄)/(σ_s + ε)`；
   - **重要性比与 DAPO 式非对称裁剪**：`ρ_{i,t}(θ) = πθ/π_old`，`ℓ_{i,t} = min{ρ Â_i, clip(ρ, 1-ε⁻, 1+ε⁺) Â_i}`；
   - **序列级目标**：`J_RL = E[ (1/K) Σ_i (1/|y_i|) Σ_t ℓ_{i,t} - β D_KL(πθ ‖ π_ref) ]`，同一优势同时更新 `r_i` 与 `a_i` 的 token 概率，**以完整 [r; a] 为学习单元**；

### 2.7 数据构建流水线

- **智能体式（agentic）多智能体标注**：工具盒含相机、2D 检测、3D 状态、BEV、自车状态、轨迹绘图、标志/OCR、案例召回；前向接地 + 后向轨迹锚定。

## 三、实验设计

- **数据集 / 语料**：
  - **GR-NavSim**：基于 **nuPlan** 训练场景构建。107K 标注场景、**2.2M** 接地问答对、415K 前视相机 Executable Planner 样本、70K 接地轨迹（GRA 路径 + 规划器动作）；官方评测缓存有效场景 102,861 个，接地一致性过滤后 62,111 个用于 planner warm-up。作者称其为**目前最大的开放词汇、非模板化自动驾驶问答数据集**。
  - **NAVSIM navtest v1**：官方完整协议，单样本、每场景一次贪心自回归补全，指标 **PDMS**（含 NC、DAC、EP、TTC、Comf）。
  - **内部长尾基准**：覆盖路线阻塞、借道、路面危险；50K 片段、700K 帧；关键对象表示为 `o_j = (t_j, Ω_j, p_j)`（类型、BEV 区域、可通行性）。指标：**CDS = Safety × (0.45·KOC + 0.35·Progress + 0.20·Comfort)**，Safety 为碰撞门与不可行驶区域门的乘积（硬门），KOC 用通过/等待的几何约束而非单一日志轨迹匹配。
