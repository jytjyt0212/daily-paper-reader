## 摘要
自动驾驶语义分割需要在类别严重不平衡的情况下可靠检测弱势道路使用者（VRU）。我们提出 CLFTv2，一种层次化相机-LiDAR融合框架，它用基于 Swin 的多尺度编码器和轻量级 FPN 风格残差解码器替代全局 ViT 注意力。CLFTv2 在二维透视域中运行，通过移位窗口注意力和逐尺度残差融合集成多尺度几何线索，避免了查询匹配解码器的计算开销。在三个驾驶数据集上，CLFTv2 持续提升 VRU 召回率。在 ZOD 上，CLFTv2-Large 达到 53.5% mIoU，相较于之前的 CLFT 模型，将行人 IoU 从 35.5% 提升至 44.9%。在 Waymo 上，CLFTv2 达到 61.7% mIoU。此外，一项模态隔离研究表明，ViT 的全局感受野仅在密集 LiDAR 回波下带来更强的融合增益。与基于 Swin 的 Mask2Former 改编版本相比，CLFTv2 所需的 GFLOPs 少 1.4 倍，吞吐量高 2.2 倍，同时达到相当的整体精度。这些结果表明，层次化局部注意力融合为智能交通系统中的实时车载感知提供了一种高效、可扩展的替代方案，可替代全局注意力和基于查询的解码器。源代码已公开。

## Abstract
Semantic segmentation for autonomous driving requires reliable detection of vulnerable road users (VRUs) despite heavy class imbalance. We introduce CLFTv2, a hierarchical camera-LiDAR fusion framework replacing global ViT attention with a Swin-based multi-scale encoder and a lightweight FPN-style residual decoder. Operating in the 2D perspective domain, CLFTv2 integrates multi-scale geometric cues through shifted-window attention and per-scale residual fusion, avoiding the computational overhead of query-matching decoders. Across three driving datasets, CLFTv2 consistently improves VRU recall. On ZOD, CLFTv2-Large achieves 53.5\% mIoU, improving pedestrian IoU from 35.5\% to 44.9\% over the prior CLFT model. On Waymo, CLFTv2 reaches 61.7\% mIoU. Additionally, a modality-isolation study suggests ViT's global receptive field yields stronger fusion gains only under dense LiDAR returns. Compared to a Swin-based Mask2Former adaptation, CLFTv2 requires 1.4$\times$ fewer GFLOPs and delivers 2.2$\times$ higher throughput, while achieving comparable overall accuracy. These results demonstrate that hierarchical local-attention fusion offers an efficient, scalable alternative to global-attention and query-based decoders for real-time on-vehicle perception in intelligent transportation systems. Source code is publicly available.

## 1. 核心问题与整体含义（研究动机与背景）

- **安全关键需求**：自动驾驶语义分割必须可靠检测弱势道路使用者（VRU，如行人），其在透视图像中的像素占比极小（约 0.3–0.4%），漏检代价极高，而数据存在极端类别不平衡（背景常超过 95%）。
- **多模态互补性**：相机提供高空间分辨率的密集颜色/纹理但缺乏度量深度；LiDAR 提供三维几何但点云随距离增加而稀疏。融合可弥补各自短板，但需在高空间分辨率下处理密集多模态流，受严格延迟约束。
- **既有方法的瓶颈**：
  - 前作 CLFT 使用 ViT 编码器提供优秀跨模态上下文，但标准 ViT 具二次复杂度且仅单一固定空间分辨率，生成小目标所需多尺度特征金字塔代价高昂。
  - 查询式通用分割解码器（MaskFormer/Mask2Former）面向开放式场景分解，对闭集固定类别分割引入匈牙利匹配、深层监督等训练开销，与任务需求不直接对应。
- **整体含义**：CLFTv2 提出以 Swin 层次化局部注意力替代全局注意力，以轻量 FPN 式残差解码器替代查询匹配解码器，在 2D 透视域内实现高效、可扩展的相机-LiDAR 融合，面向实时车载感知。

## 2. 方法论

### 核心思想
- 在 2D 透视投影域中运行：LiDAR 点投影到图像平面并编码为三通道坐标图（X, Y, Z），从而可直接使用 ImageNet 预训练视觉骨干，无需专用 3D 处理。
- 用 Swin Transformer 的移位窗口注意力实现线性复杂度与原生四阶段多尺度特征金字塔，替代 ViT 的全局二次注意力与单尺度输出。
- 用逐尺度残差融合 + 由粗到细的 FPN 式累积，替代查询匹配解码器。

### 关键技术细节
- **层次化骨干（Swin）**：
  - 输入分为 4×4 非重叠 patch，经过四个层次化 Transformer 阶段。
  - 每个阶段在 M×M 非重叠窗口内计算局部自注意力；交替块使用移位窗口（SW-MSA，位移 (⌊M/2⌋, ⌊M/2⌋)）实现跨窗口信息流。
  - W-MSA 复杂度为 Ω = 4hwC² + 2M²hwC，即 O(hw)，优于全局注意力的 O((hw)²)。
  - 阶段间 Patch Merging 使空间分辨率减半、通道翻倍，产生步长 Sᵢ ∈ {4, 8, 16, 32} 的四级金字塔；嵌入维度随模型规模变化（Tiny: 96/192/384/768；Base: 128/256/512/1024；Large: 192/384/768/1536）。
  - 使用 SwinV2 + ImageNet 预训练权重（Tiny 用 ImageNet-1k，Base/Large 用 ImageNet-22k），含余弦相似度注意力与对数间隔连续相对位置偏置。
- **孪生特征编码**：
  - RGB 图像 I_RGB 与投影 LiDAR 张量 I_LiDAR 分别通过共享参数 θ_enc 的两个 Swin 骨干，得到两组四阶段特征金字塔。
  - LiDAR 输入为稠密 3 通道坐标图（每像素存储最近投影点的 X, Y, Z），孪生权重共享使参数量减半并复用预训练权重。
- **层次化融合解码器**：
  - **通道投影**：每级特征经 1×1 卷积统一投影到 D=256，保持原生空间分辨率。
  - **由粗到细残差融合**：从最粗级 i=4（stride 32）到最细级 i=1（stride 4）逐级累积。每级先由模态专属残差卷积单元（ResConv，两个 3×3 卷积 + ReLU + 恒等跳跃连接）分别精炼 RGB 与 LiDAR 特征，再与上一级上采样 2× 的累积表示相加，最后经共享输出 ResConv。
    - 最粗级：A₄ = R_out(R_RGB(F'_RGB,4) + R_LiDAR(F'_LiDAR,4))
    - 后续级：Aᵢ = R_out(R_RGB(F'_RGB,i) + R_LiDAR(F'_LiDAR,i) + Up₂×(A_{i+1}))
  - 递归项 Up₂×(A_{i+1}) 是精度主导因素；移除后 ZOD mIoU 从 35.9% 降至 23.1%（绝对下降 12.8%）。用五种门控/注意力加权替代逐元素相加，mIoU 变化不超过 ±0.7%，说明当前监督条件下额外融合参数不必要。
  - **分割头**：对 A₁（H/4 分辨率）经 3×3 卷积 + BN + ReLU，再 1×1 卷积并 4× 上采样至原分辨率，输出类别 logits。
- **损失函数**：加权交叉熵，权重由各类像素频率经近似逆平方根调度得到（背景权重低至 0.1，行人权重高达 20）。

## 6. 主要结论与发现

- **整体性能**：ZOD 上 CLFTv2-Large 达 53.5% mIoU（CLFT-Large 为 46.8%），行人 IoU 从 35.5% 提升至 44.9%，标志 IoU 从 33.2% 提升至 43.2%；Waymo 上 CLFTv2 达 61.7% mIoU。
- **排名依赖数据集**：ISEAuto 上查询式模型领先（MaskFormer-Large 75.6%、Mask2Former-Large 75.4% vs CLFTv2-Large 73.3%），ZOD 上 CLFTv2-Large 领先。
- **全局 vs 局部注意力的关键发现**：Waymo 上 ViT 系 CLFT 完全胜出（CLFT-Large 68.3% vs CLFTv2-Large 61.7%），而单模态下两者 mIoU 差距仅 0.2–0.4%，说明差距源于融合交互机制——ViT 的无限制全局自注意力能跨整个稠密 Waymo LiDAR 点云建立长程跨模态关联，而 Swin 局部窗口限制了这一能力；即使扩大窗口也无法完全弥合。
- **模态隔离研究**：融合在所有 32 种设置下均优于 RGB-only；Waymo 呈几何主导（LiDAR-only 在 5/6 Transformer 设置中超过 RGB-only），CLFT 平均融合增益 +10.52%，CLFTv2 仅 +4.85%（约小 2.2 倍）；ISEAuto 融合增益仅 +0.34% 至 +1.21%。
- **融合设计结论**：残差传播是精度主导因素（23.1% → 35.9%），代价是延迟从 10.8 ms 增至 13.2 ms（+22.2%），属有利的精度-延迟权衡；门控机制未带来提升。
- **效率结论**：CLFTv2-Tiny 22.0 ms / 187 MB，对比 Mask2Former-Tiny 48.4 ms / 314 MB（快 2.2×、显存低约 40%）；CLFTv2-Large 204.4G FLOPs / 81.8 ms，轻于且快于 Mask2Former-Large（265.3G / 118.2 ms）；相比 Swin 版 Mask2Former 整体少 1.4× GFLOPs、高 2.2× 吞吐且精度相当。
- **安全剖面**：CLFT
