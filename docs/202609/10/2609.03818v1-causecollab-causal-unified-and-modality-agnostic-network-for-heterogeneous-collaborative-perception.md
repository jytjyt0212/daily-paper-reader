## 摘要
协同感知通过多智能体信息共享增强环境理解，但其在真实场景中的性能受限于异构传感器模态和模型架构。近期基于协议的两阶段方法通过将异构特征映射到共享协议空间来缓解这一问题；然而，独立训练的模态特定转换器通常会产生模态特定的伪协议分布，导致语义不一致和误差累积，这在模态差异较大的场景中尤为明显。为解决这一问题，我们提出 CauseCollab，一种因果统一且模态无关的网络。CauseCollab 从因果视角构建协议空间中的表示学习，通过因果度量学习显式地将语义因素与模态特定的统计混杂因素解耦。同时，CauseCollab 采用上下文引导的统一转换器处理异构模态，以确保跨模态语义一致性。此外，集成新模态仅需训练具有极少参数的适配器。在 OPV2V 和 DAIR-V2X 数据集上的大量实验表明，CauseCollab 达到了当前最优性能，并在涉及较大模态差距的场景中取得更显著的增益。

## Abstract
Collaborative perception enhances environment understanding through multi-agent information sharing, but its performance in real-world scenarios is constrained by heterogeneous sensor modalities and model architectures. Recent protocol-based two-stage methods alleviate this problem by mapping heterogeneous features into a shared protocol space; however, independently trained modality-specific converters often generate modality-specific pseudo-protocol distributions, leading to semantic inconsistency and error accumulation, which is particularly pronounced in scenarios with large modality discrepancies. To address this issue, we propose CauseCollab, a causal unified and modality-agnostic network. CauseCollab formulates representation learning in the protocol space from a causal perspective, explicitly disentangling semantic factors from modality-specific statistical confounders via causal metric learning. Meanwhile, CauseCollab adopts context-guided Unified Converter for heterogeneous modalities to ensure cross-modal semantic consistency. In addition, integrating new modalities only requires training adapters with minimal parameters. Extensive experiments on the OPV2V and DAIR-V2X datasets demonstrate that CauseCollab achieves state-of-the-art performance, with more significant gains in scenarios involving large modality gaps.

## 一、核心问题与研究动机

- **背景**：协同感知（Collaborative Perception）通过多智能体间共享中间特征，弥补单车视角盲区与遮挡，是提升自动驾驶系统鲁棒性的关键技术。
- **现实挑战**：真实部署中，协同智能体往往来自不同厂商与平台，在**传感器模态**（LiDAR / Camera）、**体素尺寸**、**网络架构**等方面存在显著异构性，导致中间特征难以直接融合。
- **现有方案的两条路线**：
  - **一阶段对齐**（如 MPDA、HEAL）：为每一对异构模态学习专用映射，训练成本随模态数快速增长，可扩展性差。
  - **两阶段协议空间**（如 PnPDA、STAMP）：引入统一协议模态作为中间表示，为每种模态训练转换器与重建器，可扩展性更好。
- **核心痛点**：两阶段方法中，各模态的转换器**独立训练**，各自学习局部自洽的映射，导致协议空间中出现**模态特定的伪协议分布（pseudo-protocol distribution）**，表现为语义响应和统计分布不一致，进而造成**语义不一致与跨阶段误差累积**。该问题在**模态差距大**时尤为严重（背景区域出现噪声响应与虚假激活）。
- **根因分析**：现有方法仅将协议空间视为分布对齐的中间媒介，**未能显式刻画哪些语义因素应跨模态共享、哪些模态特定统计混杂因素应被解耦**。
- **整体含义**：论文从**因果视角**重新形式化协议空间表示学习，目标是在保留模态不变语义因素 S 的同时，抑制模态统计噪声 Np/Nm，实现真正模态无关的统一协议表示。

## 二、方法论

### 2.1 核心思想
将异构协同感知建模为**两阶段框架**：Stage-1 在因果建模下学习语义一致的协议空间，Stage-2 为每种模态独立重建局部语义。通过**结构因果模型（SCM）**区分因果因素与统计混杂，并用**反事实干预 + 因果度量学习**强制各模态协议表示向弱观测的协议模态对齐。

### 2.2 整体流程
- 每个模态 m 使用编码器 Em 得到特征 fi；ego 特征为 fε。
- Stage-1：共享协议空间 P，将协作智能体特征转换为协议表示 pi。
- Stage-2：ego 使用重建器 Rmε 将协议特征映射回局部空间 L，得到 ˜fi。
- 融合：Fpyramid = Φε(fε, ˜f1, …, ˜fN)，再经任务头 Hε 输出检测结果 z。

### 2.3 结构因果模型（SCM）
- 变量：协议模态表示 P、异构模态表示 Fm、协议空间异构表示 Fm→p、局部重建表示 Fm→p→m、真实语义因素 S、协议模态统计噪声 Np、异构模态统计噪声 Nm。
- 因果因素为 S，混杂因素为 Np 与 Nm。
- 学习目标：保持 Fm→p 对 S 的高敏感性，同时降低对 Np、Nm 的依赖。
- 由于 S 不可直接观测，训练时用**协议模态表示 P 作为弱观测**。

### 2.4 MGI-SPD：基于 SPD 特征几何的掩码引导干预
- 将 BEV 特征视为从空间位置采样的高维随机向量集合，在**对称正定（SPD）协方差矩阵几何**上构建闭式统计映射。
- 用语义掩码 mi 生成非负权重 w，定义加权一阶统计量 μ 与二阶统计量 Σ（含 εI 保证数值稳定）。
- **白化–着色线性映射**实现源统计 (μs, Σs) 到目标统计 (μt, Σt) 的闭式变换：
  Ts→t(X) = μt + Σt^(1/2) Σs^(−1/2) (X − μs)
- **正负样本构造**：
  - **正样本 p+**：将通道统计映射到中性目标分布 (μ0, Σ0)=(0, I)，经掩码引导空间插值，抑制模态统计而保留空间语义结构（去模态化）。
  - **负样本 p−**：在抑制基础上，通过同构统计映射与空间调制，受控注入异构模态统计 (μh, Σh)，构造带有受控模态偏移的**难负样本**。
- 关键性质：仅在 Stage-1 训练时使用，**推理阶段不参与**。

### 2.5 语义上下文提取器（SCE）
- 分层结构，通过两级下采样与语义提取构建 x(1)、x(2)，融合得到全局语义上下文 ci。
- 融合操作：1×1 卷积对齐通道 → 插值空间对齐 → 加权拼接 → 深度可分离 3×3 卷积 → SE 通道重校准 + 归一化。

### 2.6 上下文引导动态精炼器（CGDR）
- 将局部模态特征 fi 与对齐后的上下文 ˆci 作为联合输入，逐层生成协议空间特征 pi。
- 每个动态精炼块：FiLM 风格多头特征调制 → 门控函数 gate(·)（1×1 卷积 + SiLU）抑制非信息区域 → 残差连接 + Layer Scale → MLP → 再残差。

### 2.7 训练目标
- **Stage-1**：LStage-1 = λcon Lcontrast + λctx(Lctx-ssim + Lctx-cos) + λssim Lssim + λ(1)task Lptask
  - Lcontrast：InfoNCE 风格对比损失，以 pi 为锚，p+ 为正、p− 为负。
  - Lctx-ssim / Lctx-cos：语义上下文与下采样正样本间的空间结构与通道响应一致性约束。
  - Lssim：协议模态特征 fp 与转换表示 pi 的语义一致性。
  - Lptask：协议头检测损失（focal + smooth L1）。
- **Stage-2**：LStage-2 = λ(2)task Lϵtask + λmse Lmse + λcons Lcons
  - 冻结 Stage-1 统一转换器，为每种模态训练 ConvNeXt 架构的重建器。

### 2.8 泛化机制
- 新增模态时**冻结统一转换器骨干**，仅在 SCE 下采样后与 CGDR 模块之间插入**轻量级低秩瓶颈适配器**（α=0 初始化），Stage-2 训练新模态的重建器。
- 适配过程中，已有模态的编码器、融合模块、检测头保持冻结且不可访问，满足隐私保护与不可修改性要求。
