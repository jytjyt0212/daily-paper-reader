## 摘要
最近的视频世界模型能够生成越来越逼真且可交互的视觉体验，但缺乏可靠的机制来维持持久的世界状态，并在长时间交互中强制执行可编程规则。我们提出可编程世界模型（Programmable World Model），一个将世界状态演化与视觉观测生成解耦的框架。一个智能体将自然语言指令转换为可执行程序，这些程序指定实体状态和状态转移规则，从而能够直接控制单个实体及其交互。一个轻量级引擎执行这些程序，以更新并维护显式、持久的全局世界状态，包括屏幕外实体和非视觉属性。为了将世界状态与视觉生成连接起来，我们引入状态增强的3D有向包围盒（OBBs）作为中间表示。该表示与目标相机轨迹一起，被确定性地编译为像素对齐的时空条件信号，用于作为生成渲染器的预训练视频模型。这种设计允许用户创建具有预定义机制的可玩游戏，直接控制单个实体，并在整个游戏过程中保持持久的世界状态。我们进一步提出CombatStateBench，一个用于评估可编程世界模型的基准。在CombatStateBench上，我们的方法达到94%的计数准确率和98%的状态准确率，显著优于现有的交互式视频世界模型，同时支持连贯的长时程生成。这些结果表明，将显式状态演化与生成式渲染分离，对于构建持久、可编程的世界是有效的。

## Abstract
Recent video world models generate increasingly realistic and interactive visual experiences, yet lack reliable mechanisms for maintaining persistent world state and enforcing programmable rules over extended interactions. We introduce Programmable World Model, a framework that decouples world-state evolution from visual observation generation. An agent translates natural-language instructions into executable programs that specify entity states and state-transition rules, enabling direct control over individual entities and their interactions. A lightweight engine executes these programs to update and maintain an explicit, persistent global world state, including off-screen entities and non-visual attributes. To connect world state with visual generation, we introduce state-augmented 3D oriented bounding boxes (OBBs) as an intermediate representation. This representation, together with the target camera trajectory, is deterministically compiled into pixel-aligned spatiotemporal conditioning signals for a pretrained video model serving as the generative renderer. This design allows users to create playable games with predefined mechanics, direct control over individual entities, and persistent world state throughout gameplay. We further introduce CombatStateBench, a benchmark for evaluating programmable world models. On CombatStateBench, our method achieves 94% Count Accuracy and 98% State Accuracy, substantially outperforming existing interactive video world models while supporting coherent long-horizon generation. These results demonstrate the effectiveness of separating explicit state evolution from generative rendering for building persistent, programmable worlds.

## 1. 核心问题与研究动机

- **背景**：近期视频世界模型（video world models）在生成逼真、可交互的视觉体验方面进展迅速，支持动作条件生成、相机控制、实时交互与长时程 rollout。
- **核心痛点**（论文明确列出三点）：
  - **实体级控制缺失**：现有控制接口主要指定相机、动作或高层提示，难以直接寻址和操纵单个实体。
  - **缺乏显式持久全局状态**：模型没有独立于当前视角、可被读取和更新的权威状态，无法可靠记录屏幕外实体、库存、任务进度、交互历史等非视觉信息（这对多人世界引擎尤其重要）。
  - **规则不可编程**：用户无法定义世界演化的可执行规则（例如门在什么条件下打开、某次交互如何影响其他实体）；提示词无法建立一致生效的可执行规则。
- **关键研究问题**：什么样的表示既能支持可编程的世界状态演化，又能保留视觉生成所需的空间与语义结构？
- **整体含义**：论文主张将"世界状态演化"与"视觉观测生成"解耦——状态由轻量引擎显式维护，视频模型仅充当生成式渲染器。由此可构建持久、可编程、可玩的交互世界。

## 2. 方法论

### 2.1 核心思想
- 将交互循环拆分为四步：**状态转移 F（引擎）→ 控制编译 P（确定性编译器）→ 生成渲染 G（视频模型）**，形式化为：
  - `s_{t+1} = F(s_t, a_t)`
  - `M^{ctrl}_{t+1} = P(s_{t+1}, C_{t+1})`
  - `I_{t+1} = G(I_0, C, M^{ctrl})`
- 规范世界状态定义为 `s_t = (E_t, A_t, Q_t; R_t)`，即实体与 3D 位姿、语义/功能属性、实体间关系、可执行世界规则。

### 2.2 关键组件
- **智能体编排的世界编程**：VLM 编码智能体（coding agent）结合初始观测的 3D 检测结果与自然语言描述，生成引擎可读的"世界程序"，包括实体初始状态、属性、关系、可执行动作与规则（如 `on_hit: hp -= damage`、`on_hp_zero: status = down`、胜负条件等），并实例化初始状态 `s_0`。
- **轻量引擎执行**：每步对动作做合法性检查、施加效果、解析触发事件，更新实体/属性/关系/规则集；同时维护健康值、库存、阵营等**不直接呈现在画面上的潜在世界事实**。

### 2.3 状态增强 3D OBB 与确定性控制编译
- 每个实体由 **3D 有向包围盒（OBB）** 表示（位置、尺寸、朝向），并附加持久身份、语义类别、动态状态与外观信息；无需网格、材质、骨架或预定义动画。
- 编译器将 OBB 沿目标相机轨迹投影并栅格化，生成三种像素对齐控制图，通道拼接为 `M^ctrl = Concat(M^id, M^sem, M^dir)`：
  - **身份图**：K 个可学习身份嵌入构成嵌入库，按持久实体 ID 分配固定槽位；训练时样本内随机分配但序列内固定，防止身份嵌入与特定类别/外观/视角产生伪关联；推理时跨交互步保持槽位不变，应对遮挡与离屏再入。
  - **语义图**：由预训练文本编码器对规范状态中的语义标签编码得到，背景置零；重叠时用 z-buffer 深度感知栅格化保留可见实体。
  - **方向图**：由引擎维护的**世界坐标速度**旋转到目标相机坐标系，量化为 7 种状态（前/后/左/右/静止/上/下），配 7 个可学习嵌入。关键在于用世界速度而非图像位移，从而区分物体自身运动与相机引起的表观运动。

### 2.4 生成式渲染器
- 基于 **LingBot-World-v1** 预训练相机控制视频生成骨干；**冻结主分支及其相机条件通路**，仅训练新引入的 **Structured Spatial ControlNet** 分支，控制特征逐层注入主块（`h_main += r`）。
- 相机模块控制全局视角演化，空间控制分支约束实体出现位置、持久身份、语义类别与自身运动方向；细粒度几何、纹理、材质、关节、光照与次级动态由生成先验补全。

### 2.5 分块自回归长时程渲染
- 块内去噪为双向，块间因果传播；后续块额外接收：
  - **时间历史**：按近/中/远多尺度组织潜变量历史，并保留初始帧潜变量作为持久锚点；训练时对历史做噪声扰动、特征损坏与部分丢弃，增强对不完美上下文的鲁棒性。
  - **几何对齐空间记忆**：沿用 AlayaWorld 机制，用估计深度与相机参数把已完成 RGB 帧提升到世界空间，检索并重投影到目标视角作为条件，仅由已完成的历史块更新，保持因果性。

### 2.6 自动训练数据管线
- **相机参数估计**：ViPE 估计内参、位姿与度量深度。
- **语义类别发现**：Qwen3-VL 生成全局描述并确定可数物体类别集合。
- **实例分割与跟踪**：SAM3 输出时序关联掩码、2D 框、语义标签与持久轨迹 ID；过滤可见面积过小的掩码。
- **物体轨迹恢复**：Wild-Det3D 结合 RGB、深度、内参估计逐帧 3D OBB，用相机位姿变换到共享世界坐标系；由相邻世界坐标中心位移（而非图像位移）估计物体运动并量化为 7 态。
- **条件图生成**：投影 OBB 并栅格化身份/语义/方向图，z-buffer 解决遮挡。

### 2.7 表示权衡论证（论文的重要理论贡献）
- 训练方向是"已实现动态 → 结构表示"，推理方向是"状态转移 → 结构表示 → 生成动态"，存在**训练-推理不对称**。
- 表示越精细，控制越精确，但训练监督成本越高、推理时需自行求解的低层自由度越多，甚至退化为动画/运动生成/物理仿真问题。
- 因此选择 OBB 作为**中间抽象**：显式表示实体持久性、世界一致性与状态相关变化所需的最小结构，把精细动态实现交给生成模型。
