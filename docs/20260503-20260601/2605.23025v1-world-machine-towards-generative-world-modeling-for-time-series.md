## 摘要
世界模型代表了生成式人工智能的一种范式转变，旨在以结构化和可泛化的方式追求对环境的预测性理解和可控模拟。我们提出了世界机器，一种用于时间序列的生成式世界建模架构。它是一种基于Transformer的架构，具有潜在状态，能够适应不同数量的观测数据和上下文。这相比传统Transformer有所改进，传统Transformer的计算和内存成本随上下文呈二次方增长。在提出的合成数据集Toy1D上的实验验证了该方法的可行性，展示了传统Transformer所不具备的能力，并突出了训练协议中每个组件的贡献。

## Abstract
World models represent a paradigm shift in generative AI, pursuing predictive understanding and controllable simulation of environments in a structured and generalizable way. We present World Machine, a generative world-modeling architecture for time series. It is a transformer-based architecture with latent states that enables adaptation to different amounts of observed data and contexts. This shows an improvement over traditional transformers, which have a computational and memory cost that scales quadratically with the context. Experiments on a proposed synthetic dataset, Toy1D, validate the approach's feasibility, demonstrate capabilities not found in conventional transformers, and highlight the contributions of each component of the training protocol.

### 2. 论文提出的方法论：核心思想、关键技术细节

#### 核心思想
- **生成式世界模型**：模型不仅预测时序值，还维护一个随时间演化的**潜在世界状态向量序列** `ws_t`。该状态编码当前世界配置，并由 **Core**（基于 Transformer 块）通过自回归方式更新。
- **单一端到端架构**：将观察（sensory channels）、动作等统一视为感官输入，通过单个模型联合学习状态表示与状态转移，优化单一感官损失。

#### 关键技术细节
- **状态发现（State Discovery）**：
  - 初始 `ws` 随机初始化 `~Uniform(-1,1)`。
  - 每轮训练后，将预测的 `ws` 序列左移一位，覆盖下一轮输入（第一状态始终为零向量）。通过此过程，模型自主发现合理的潜在状态表示。
- **Core 模块**：
  - 使用 **Transformer 解码器**，包含标准块和条件块（adaLN-Zero），条件块根据感官数据动态缩放/平移状态。
  - 状态激活采用 **tanh**（实验证明对稳定性至关重要）。
  - 位置编码采用 **ALiBi**（非绑定、注入注意力矩阵），支持变长序列且不干扰状态向量。
- **训练协议（含多个增强步骤）**：
  - **感官掩蔽（Sensory Masking）**：随机遮蔽部分感官数据，训练模型在缺失数据时仍能预测。
  - **序列分裂（Sequence Breaking）**：将长序列随机切分为 k 段，分别处理并计算损失，迫使模型掌握从中间状态恢复的能力。可选 **Fast Forward** 将上一段最后状态直接传递到下一段，强化信息传播。
  - **噪声添加**：对 `ws` 或感官维度添加高斯噪声。
  - **短时召回（Short Time Recall）**：创建额外的合成感官通道，包含过去/未来固定步长的数据投影，增强上下文记忆。
  - **局部模式（Local Mode）**：随机禁用注意力，仅利用当前状态和感官数据，模拟 RNN 行为。
- **损失函数**：各输出感官维度的 MSE 加权求和。

### 3. 实验设计

#### 数据集
- **Toy1D**：自行生成的合成一维时间序列，模拟阻尼物理系统（式 4）。由初始随机状态和随机方波/脉冲波激励生成。仅使用位置作为 `external state` 通道（1 维），`measurement` 通道（2 维）由线性变换加 tanh 获得。共生成 10,000 条长度 1000 的序列，再切分为 40,000 条长度 200 的序列，缩放至 [-1,1]。训练/验证/测试=60%/20%/20%。

#### 评估任务（均基于相同 MSE/SDTW 损失）
| 任务 | 描述 | 关键能力 |
|------|------|----------|
| Normal | 标准自回归推理（从零状态开始） | 基础生成 |
| Use State | 仅使用已编码的潜在状态（无感官数据）并行推理前50%序列 | 状态表示质量 |
| Prediction | 使用前50%已编码状态预测后50%（无感官） | 多步预测 |
| Prediction Shallow | **仅使用一个已编码状态**预测后50% | **上下文截断能力（核心优势）** |
| Prediction Local | 局部模式（无注意力）预测下一步 | 极限简化 |
| Mask Sensory@x | 随机遮蔽 x% 感官数据全序列推理 | 鲁棒性 |

#### 对比方法
- 论文未与传统 Transformer 直接对比（因传统模型无法完成上述任务），而是通过消融实验对比不同训练协议变体：

  - **Complete Protocol**：所有协议步骤。
- 另设 **配置实验**：定义 15 个超参数变量（如序列分裂类型、状态保存方式、噪声、短时召回、局部模式等），共 9600 个变体组合，用于冲击测试。

### 6. 论文的主要结论与发现

1. **可行性**：World Machine 通过状态发现和训练协议成功训练，能生成连贯的预测序列。
2. **上下文截断潜力**：Prediction Shallow 任务（仅用一个历史状态预测后续50%）虽为最难任务，但完整协议显著提升了性能，表明模型能利用潜在状态实现**低成本推理**（将二次复杂度降为常数）。
3. **训练协议各组件贡献**：
   - **tanh 激活**对稳定性至关重要（无 tanh 时发散概率高达20%，其余情况<1%）。
   - **感官掩蔽、序列分裂、短时召回、噪声添加**均有正向影响，但效果随任务而异。
   - **局部模式**能显著缩短训练时间（因跳过注意力计算），同时保持良好性能，性价比高。
4. **代表性**：Use State 和 Prediction Shallow 任务间相关性低，可作为模型性能的两个独立评价维度。
