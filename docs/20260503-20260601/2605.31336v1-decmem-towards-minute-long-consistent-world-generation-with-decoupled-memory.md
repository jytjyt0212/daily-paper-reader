## 摘要
视频生成模型的最新进展促进了可控世界模型的快速发展。然而，在长期推理下保持细粒度时空一致性仍是一个关键挑战。在这项工作中，我们超越了显式3D内存和粗粒度的帧级隐式建模，提出了一种细粒度、可学习且可扩展的内存，用于一致的世界生成。我们首先识别了朴素可学习内存架构在长期外推中的两个基本局限性，即计算效率低下和注意力分散。通过对注意力分散的系统分析，我们提出了DecMem，一种解耦内存架构，采用稀疏全局内存实现高效细粒度访问全局历史，并采用锚定局部内存实现稳定高质量外推。大量实验表明，DecMem显著优于当前最先进的方法。通过确保精确高效的长期记忆并实现卓越的外推能力，DecMem能够实现高保真度和一致性的分钟级可控长视频生成。

## Abstract
Recent advances in video generative models have promoted rapid progress in controllable world models. However, maintaining fine-grained spatio-temporal consistency under long-horizon reasoning remains a key challenge. In this work, we move beyond explicit 3D memory and coarse frame-level implicit modeling, and propose a fine-grained, learnable, and scalable memory for consistent world generation. We first identify two fundamental limitations of naïve learnable memory architectures in long-horizon extrapolation, namely computational inefficiency and attention dispersion. Through a systematic analysis of attention dispersion, we propose DecMem, a decoupled memory architecture that employs Sparse Global Memory for efficient fine-grained access to global history and Anchored Local Memory for stable and high-quality extrapolation. Extensive experiments demonstrate that DecMem significantly outperforms current state-of-the-art methods. By ensuring precise and efficient long-term memory and achieving superior extrapolation capabilities, DecMem enables minute-level controllable long video generation with high fidelity and consistency.

## 1. 核心问题与整体含义（研究动机和背景）

- **核心问题**：在长时程（分钟级）可控视频生成中，维持细粒度的时空一致性极具挑战。现有方法在“重访”场景（revisit scenarios）下，随着推理延伸常会遗忘先前生成场景，导致严重的时间不一致。
- **已有方法的局限**：
  - **显式3D记忆**（如3D表示）：受限于3D估计器的精度，误差累积会侵蚀长程一致性，且维护3D表示有额外开销。
  - **隐式记忆**（帧级检索或注意力）：基于FOV的帧检索不可学习；基于注意力的隐式方法虽可端到端学习，但将每帧作为不可分割单元，无法捕捉子帧级的时空对应关系。
- **朴素密集注意力的两大根本局限**：
  - **计算低效**：每token对全部历史特征做密集注意力，计算量随序列线性增长，难以扩展到分钟级视频。
  - **注意力分散（attention dispersion）**：随着上下文增长，大量弱相关历史特征涌现，稀释了关键特征的注意力权重，导致质量退化与结构崩溃。
- **研究意义**：提出一种细粒度、可学习、可扩展的记忆机制，实现分钟级高保真一致的视频生成，推动可控世界模型的长时应用。

## 2. 论文提出的方法论

### 2.1 核心思想

- 提出**解耦记忆架构 DecMem**，将全局历史检索与局部注意力锚定解耦，从而同时解决注意力分散和计算低效问题。

### 2.2 关键技术细节

#### (1) Sparse Global Memory (SGM) — 稀疏全局记忆

- **两阶段过程**：
  - **块级稀疏检索**：将每帧划分为 $M$ 个不重叠块（block），通过池化获得块特征。当前帧查询块与所有历史块计算相似度，取 top-$k$ 最相关块作为细粒度记忆上下文。
  - **上下文感知注意力**：查询块中的每个token仅与检索到的 top-$k$ 块中的token进行密集注意力计算。这避免了计算量随序列增长线性上升。
- **粒度优势**：块级检索比帧级更精细，且全程可学习。

#### (2) Anchored Local Memory (ALM) — 锚定局部记忆

- **滑动窗口注意力**：严格将注意力限制在最近 $w$ 帧（实验中取8帧），作为高置信度锚点，消除远距离干扰，稳定注意力分布。
- **门控融合**：通过可学习门控 $G_t$ 自适应融合 SGM 输出 $o^{sgm}_t$ 和 ALM 输出 $o^{alm}_t$：
  $$ o_t = o^{alm}_t + G_t \odot o^{sgm}_t $$
  ALM提供稳定基线，SGM提供细粒度长期记忆，实现自适应权衡。

#### (3) Multimodal Position Embedding — 多模态位置编码

- 扩展视频 RoPE，将通道分为三组，分别编码**相机几何（PRoPE）**、**空间坐标（2D轴向RoPE）**、**帧索引（1D RoPE）**，并在注意力中调制Q-K内积，同时在Value和输出上对相机和空间通道施加变换。
- 公式示意：$R^{(i)}_{full} = \text{diag}(R_{cam}, R_{sp}, R_{tem})$，用于位置编码查询和键。

#### (4) 整体流程

- 采用自回归方式，每块生成4个latents，块内可互注意，块间因果。
- 训练采用两步策略：第一阶段（25K步）将预训练全序列扩散模型改造为因果生成架构；第二阶段（25K步）联合训练SGM和ALM。
