## 摘要
本报告介绍了AlayaWorld的改进版本。虽然骨干架构、分块自回归生成方案和训练数据与前一版本保持一致，但我们大幅修改了条件信号的表示方式及其融入模型的方式。新设计遵循一个简单原则：条件信号应在潜在表示和时间结构上尽可能与生成内容匹配。为此，我们做了两项重大改动。首先，我们将先前基于深度扭曲的空间记忆替换为流式3D点缓存渲染器。其次，我们重新设计了条件处理流程，使视觉条件在相同的因果VAE潜在空间中进行编码，且其时间统计特征与生成视频保持一致。具体而言，新版本引入了六项修改：（1）将静态帧图像条件替换为运动感知潜在条件；（2）将重新渲染的空间记忆作为连续序列进行因果编码；（3）在像素空间中对齐时间记忆窗口；（4）采用硬记忆丢弃，即移除记忆令牌而非将其置零；（5）统一训练和推理过程中的VAE编码与解码协议；（6）移除相机AdaLN分支，使视点控制完全通过重新渲染的空间条件提供。

## Abstract
This report presents an improved version of AlayaWorld. While the backbone architecture, chunk-wise autoregressive generation scheme, and training data remain unchanged from the previous release, we substantially revise how conditioning signals are represented and integrated into the model. The new design is guided by a simple principle: conditioning signals should match the generated content as closely as possible in both latent representation and temporal structure. To this end, we make two major changes. First, we replace the previous depth-warping-based spatial memory with a streaming 3D point-cache renderer. Second, we redesign the conditioning pipeline so that visual conditions are encoded in the same causal-VAE latent space, with temporal statistics consistent with those of the generated video. Concretely, the new version introduces six modifications: (1) replacing static-frame image conditioning with motion-aware latent conditioning; (2) causally encoding re-rendered spatial memory as a continuous sequence; (3) aligning the temporal-memory window in pixel space; (4) adopting hard memory dropout that removes memory tokens rather than zeroing them; (5) unifying the VAE encoding and decoding protocol across training and inference; and (6) removing the camera AdaLN branch, such that viewpoint control is provided entirely through the re-rendered spatial condition.

### 一、论文的核心问题与整体含义

- **研究动机**：在交互式长时程视频生成（World Modeling）中，模型需要同时理解文本指令、历史视觉记忆、空间几何以及相机运动等复杂条件。然而，AlayaWorld v1.0 版本的条件信号处理方式存在关键缺陷——视觉条件被独立编码，时间记忆与因果 VAE 的因果结构不完全对齐，相机轨迹通过 AdaLN 分支单独注入，导致条件信号与生成视频在潜空间表征和时间结构上不一致，制约了长时程生成的稳定性和可控性。
- **核心问题**：如何设计条件信号的表示与融合方式，使其在潜在表征空间和时间结构上尽可能与生成视频“同分布”，从而实现更稳健、更一致的交互式长时程世界建模。
- **整体含义**：论文提出一个简单但关键的设计原则——**条件信号应与生成内容最大化对齐**（在潜在表征和时间结构两个方面），并通过系统性的工程改造验证了这一原则的有效性，为长时程世界模型的条件控制提供了新的范式参考。

### 二、论文提出的方法论

- **核心思想**：以统一的因果 VAE 潜空间作为所有视觉条件的“共同语言”，让所有视觉条件（图像、空间记忆、时间记忆）都按生成视频相同的方式和时间结构被编码；同时将相机控制从独立的参数化分支（AdaLN）转变为几何对齐的视觉条件，使视点信息以视觉特征的形式自然融入生成过程。
- **两项重大改动**：
  1. 用流式 3D 点缓存渲染器替代基于 DA3（Depth Anything 3）的深度扭曲空间记忆。通过 ViGeo 估计逐像素 3D 几何，将每块生成结果的 3D 点注册到持久缓存中，再从下一块的规划视点重新渲染，使空间条件具备几何一致性。
  2. 重新设计条件流程：所有视觉条件统一编码进 causal-VAE 潜空间，且时间统计特征与生成视频对齐。
- **六项具体修改**：
  1. **运动感知图像条件**：图像条件不再是单帧独立编码，而是构造包含条件帧及其前 8 帧的 9 帧窗口，整体因果编码后取第二个潜变量作为图像条件；单帧仅作为解码器前缀。块间交接也采用同等的 9 帧编码模式。
  2. **流式 3D 空间记忆的因果编码**：每块生成后，逐像素 3D 点注册入持久缓存；从下一块规划视点重渲染；通过前缀位移的两两中位数比值进行尺度对齐，相机内参由针孔模型最小二乘拟合后固定；重渲染帧前加一个真实前缀帧，整体因果编码后丢弃前缀潜变量；无效渲染区域的 token 直接删除而非掩码（兼容 FlashAttention）。
  3. **像素级对齐的时间记忆**：时间记忆从六个潜变量减少为四个；N=4 时精确编码 25 帧（1 + (N−1)×8），确保帧到潜变量的边界一致，消除 off-by-one 边界泄漏问题。
  4. **硬记忆丢弃**：从“置零但保留位置”改为“直接移除 token”，真实改变序列长度；推理第一步不使用时间记忆，与训练中无记忆的情况一致。
  5. **统一 VAE 编解码协议**：训练、自回归推理和评估使用统一的像素–潜变量接口；块交接使用锚定帧 + 9 帧因果窗口；解码支持直接潜变量续接和 RGB 解码–重编码两条路径。
  6. **几何化相机控制**：移除 AdaLN 相机分支，相机轨迹仅用于确定点缓存重渲染的视点，视点信息经因果编码后以视觉条件呈现，将相机控制与场景几何（尺度、可见性、视差）自然耦合。文本条件继续负责语义，空间条件负责视点。

### 六、论文的主要结论与发现

- **条件信号对齐原则的有效性**：在骨干架构、训练数据和生成方案完全不变的前提下，仅通过改进条件信号的表示与融合方式，即在一致性指标上取得显著提升，验证了“条件信号应与生成内容尽可能对齐”这一设计原则的有效性。
- **一致性优势突出**：AlayaWorld 在 WBench 基准上取得 **Consistency 综合得分 89.5（最佳）**，在背景一致性（94.1）、透视一致性（86.6）、主体一致性（93.4）和几何一致性（94.1）四项上均获第一，空间一致性和门控空间一致性排名第二。这体现了 3D 空间记忆与时间记忆机制在长时程视觉保持和几何稳定上的有效性。
- **画质与稳定性平衡良好**：Video Quality 平均 79.3，其中画质（Imaging）67.7 为最优、美学质量 62.8 具有竞争力，接近最强方法；但短期时间动态（Flickering、Dynamic、Smoothness）不占优势。
- **交互与物理仍有提升空间**：导航得分 79.9（非最优）；物理类指标（Causal Fidelity 65.1）相对偏弱，说明环境级语义保持和物理交互建模仍是未来优化方向。

### 七、优点

- **设计原则清晰且简洁**：以“条件与内容在表征和时间结构上对齐”这一原则统摄六项修改，方法论系统性强、逻辑自洽。
- **工程实现的严谨性**：关注到非常细节但关键的问题，如时间记忆窗口的 off-by-one 边界、训练推理协议不一致、无效区域掩码与 FlashAttention 的兼容性、训练与推理的记忆丢弃差异等，体现高度的工程成熟度。
- **3D 空间记忆的流式设计**：以 3D 点缓存 + 重渲染替代深度扭曲，实现了长时程空间中相机运动的几何一致性，是该方法的突出技术亮点。
