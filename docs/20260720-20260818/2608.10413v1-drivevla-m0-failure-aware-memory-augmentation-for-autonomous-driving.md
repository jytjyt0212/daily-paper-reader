## 摘要
视觉-语言-动作（VLA）模型最近已成为端到端自动驾驶的一种有前景的范式，它能够在感知、语言和规划之间实现统一推理。然而，现有方法缺乏利用过去失败或适应分布偏移的机制，导致模型在先前失败的类似场景中持续表现不佳。在本文中，我们提出了DriveVLA-M0，一种具有故障感知潜在记忆的检索增强VLA。我们构建了一个潜在记忆池，存储失败案例及其结构场景表示和专家轨迹标签，并设计了一个专门的检索模型，该模型将静态道路结构和动态智能体交互进行解耦，以实现结构层面的检索。在推理时，检索到的案例通过一种轻量级解耦的基于LoRA的测试时训练（TTT）机制注入模型，从而实现有针对性的、场景特定的修正，而无需修改骨干网络。在NAVSIMv1和NAVSIMv2基准上的大量实验表明，我们的方法始终优于先前方法，在Navtest上达到94.1 PDMS，在Navhard上达到47.0 EPDMS，且仅产生26.44毫秒的TTT反向延迟开销。此外，我们展示了DriveVLA-M0可随额外记忆有效扩展，通过扩展记忆在无需训练的情况下即可获得性能提升。代码可在https://github.com/ZebinX/DriveVLA-M0获取。

## Abstract
Vision-Language-Action (VLA) models have recently emerged as a promising paradigm for end-to-end autonomous driving by enabling unified reasoning across perception, language, and planning. However, existing approaches lack mechanisms to exploit past failures or adapt to distribution shifts, causing the model to persistently underperform on similar scenarios where it has previously failed. In this paper, we propose DriveVLA-M0, a retrieval-augmented VLA with failure-aware latent memory. We construct a latent memory pool that stores failure cases along with their structure scene representations and expert trajectory labels, and design a dedicated Retrieve Model that decouples static road structure and dynamic agent interactions to enable structurally grounded retrieval. At inference time, retrieved cases are injected into the model via a lightweight decoupled LoRA-based test-time training (TTT) mechanism, allowing targeted and scenario-specific correction without modifying the backbone. Extensive experiments on NAVSIMv1 and NAVSIMv2 benchmark demonstrate that our approach consistently outperforms prior methods, achieving 94.1 PDMS on Navtest and 47.0 EPDMS on Navhard with only 26.44 ms TTT backward latency overhead. Furthermore, we show that DriveVLA-M0 scales effectively with additional memory, enabling training-free performance gains through memory expansion. The code is available at https://github.com/ZebinX/DriveVLA-M0.

## 2. 论文提出的方法论

### 核心思想

构建故障感知的潜在记忆池，存储失败案例及其结构化场景表示和专家轨迹标签；训练专门的检索模型对静态道路结构与动态智能体交互进行解耦，实现结构化检索；在推理时通过解耦 LoRA 测试时训练（TTT）机制将检索到的案例注入模型，实现场景特定的针对性修正。

### 算法整体流程（Algorithm 1）

1. **输入**：基础模型 B、检索模型 R、oracle 评分器 PDM、记忆池 M、阈值 β/λ、TTT 步数 S、学习率 η。
2. **[M] 离线记忆生成阶段**：对每个场景运行基础模型得到轨迹和中间特征，用检索模型提取检索键，用 PDM 评估轨迹质量，若 Q(τ̂) < β 则将其（键、特征、标签）存入记忆池。
3. **[I] 在线推理+TTT 阶段**：编码当前场景，用检索模型查询记忆，按相似度阈值 λ 触发 TTT（仅在需要时激活）；初始化 Map/Agent 两个 LoRA 分支，在检索案例上优化轨迹损失和评分损失；生成并评分修正后的轨迹候选，按聚合分数选择最优输出。

### 关键组件细节

- **基础模型（Base Model）**：
  - VLM 骨干：InternVL3（微调于大规模自动驾驶问答数据，含约 77.5 万 QA 对）。
  - 特征压缩：Q-Former 风格压缩模块（N=16, D=256），将 2800×1536 的超大 LLM 特征压缩 1050 倍。
  - Action Decoder 分为 Trajectory Head（生成 M 个多样化轨迹簇）和 Score Head（对每个轨迹生成 K 个子分数，覆盖碰撞率、可行驶区域等安全准则）。

- **检索模型（Retrieve Model）**：
  - 采用轻量级预训练 DINOv2 作为特征提取器，用 LoRA 微调。
  - **解耦 LoRA 策略**：并行路由 Map（静态）和 Agent（动态）两个 LoRA 分支，同时输出 F_map 和 F_agent。
  - 使用 Transformer decoder + 可学习 query 聚合特征，预测 occupancy grid（map 与 agent），用 BCE 损失训练：L = BCE(ˆM_map, M_map) + α·BCE(ˆM_agent, M_agent)，α=10。
  - 可视化注意力图验证：map 嵌入关注道路边界和车道线，agent 嵌入关注前方车辆。

- **记忆构造**：
  - 每条记忆包含三类信息：检索键 k（F_map, F_agent）、适配输入 x（F_lang, F_ego, T̂）、监督目标 y（专家轨迹 τ、oracle 评分 S）。
  - 失败判定：PDM 评分 Q(τ̂) < β（β=0.5）。
  - 写入前使用余弦相似度去重，控制记忆池规模（Base 约 4K 条，Scale 约 10K 条）。

- **TTT 推理注入**：
  - 检索在 map 层和 agent 层分别独立进行，取各自 top-k。
  - **触发机制**：余弦相似度超过阈值 λ（默认 0.9）才激活 TTT，避免无关检索引入噪声。
  - **解耦 LoRA TTT**：map 检索案例只微调 Map（静态）LoRA 分支，agent 检索案例只微调 Agent（动态）LoRA 分支；推理时，可行驶区域类分数用 Static LoRA，碰撞避免类分数用 Dynamic LoRA。
  - LoRA 权重对每个测试场景重新初始化，确保场景特定适配。
  - 采用分层检索策略：先 map 嵌入粗筛 top-k₁，再 agent 嵌入精筛 top-k₂（k₁=3k₂, k₂=3）。
  - TTT 默认配置：AdamW，学习率 2×10⁻⁴，3 个优化步。

- **结构化检索优于语言检索**：语言嵌入检索 PDMS 90.7（低于基线 91.0），Map 检索 91.7，Map+Agent 检索 92.3，验证了解耦静态/动态特征的检索设计价值。

## 7. 优点

- **问题洞察深刻**：从人类失败关联机制出发，明确指出现有 VLA 记忆方法在自动驾驶场景中忽略结构信息（道路拓扑、智能体布局）的关键缺陷。
- **方法设计巧妙**：
  - 解耦静态/动态检索键的设计在 VLA 自动驾驶记忆增强领域具有创新性；
  - "检索触发 + 选择性 TTT" 机制在性能与开销间取得良好平衡；
  - 解耦 LoRA 对应检索分支（Map→静态分数、Agent→动态分数）的路径感知分数融合逻辑清晰合理。
- **记忆可扩展的实用价值**：记忆扩充无需重训练即带来性能增益，支持外部数据持续积累，符合实际部署的数据增长模式。
- **实验严谨**：消融实验系统覆盖核心设计决策；提供了详尽的延迟分解；对 TTT 超参数做了鲁棒性验证（PDMS 波动 ≤0.3）。
- **可视化直观**：注意力图验证了解耦检索的有效性，轨迹分布图直观展示了 TTT 注入前后轨迹簇质量的右移。

## 8. 不足与局限

- **输入模态限制**：仅使用单目前视相机，未利用环视相机或 LiDAR，在感知层面的鲁棒性上限可能受限（对比的 Centaur 等使用三目+更多信息）。
- **记忆依赖外部评分器**：失败案例的判定依赖 PDM oracle 评分器，评分器的局限会影响记忆构造质量。
- **检索召回依赖于 DINOv2 特征**：检索模型对未见过的场景结构或极端天气的泛化能力未充分验证。
- **合成数据验证有限**：Scale 实验使用 SimScale 合成数据，但未对合成数据与真实数据的分布差异做量化分析，存在域偏差风险。
- **Navhard 对比不充分**：新基准上多个 VLA 基线未报告结果，横向对比覆盖不完全；Stage 2 伪闭环评估的场景分支机制未做深入分析。
