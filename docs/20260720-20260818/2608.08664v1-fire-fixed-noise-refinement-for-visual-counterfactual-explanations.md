## 摘要
视觉反事实解释旨在通过现实且局部的编辑改变分类器决策，同时保留与决策无关的内容。现有的基于DDPM的方法通常沿较长的反向去噪轨迹执行分类器引导编辑。不断变化的噪声水平使得语义可编辑性和空间控制难以平衡，且可编辑状态是带噪声的，而目标分类器是在干净图像上训练的。因此，这些方法要么需要昂贵的递归去噪，要么需要低质量的一步估计来获得面向分类器的干净图像。我们提出FiRe，一种用于视觉反事实解释的固定噪声细化框架。FiRe不沿反向去噪轨迹，而是将输入映射到固定噪声水平，并迭代细化该水平下的噪声状态。为了为分类器引导提供干净图像，FiRe首先将Pixel Mean Flow适配到视觉反事实解释，从而能够从噪声状态直接预测干净图像。为了使固定噪声细化产生最小且局部的反事实编辑，FiRe引入了三种FiRe特有的控制：动态双掩码策略、自适应引导和早停，它们分别决定编辑在何处累积、哪些变化变得可见以及细化何时停止。在三个数据集的五个任务上的实验表明，与最近的最强基线相比，FiRe在获得相当或最先进的反事实质量的同时，实现了约3倍的在线推理加速和8倍的FLOPs减少。

## Abstract
Visual counterfactual explanations aim to change classifier decisions through realistic and localized edits while preserving decision-irrelevant content. Existing DDPM-based methods typically perform classifier-guided editing along a long reverse denoising trajectory. The changing noise levels make semantic editability and spatial control difficult to balance, and the editable state is noisy, whereas the target classifier is trained on clean images. As a result, these methods require either costly recursive denoising or low-quality one-step estimates to obtain classifier-facing clean images. We propose FiRe, a Fixed-noise Refinement framework for visual counterfactual explanations. Rather than following a reverse denoising trajectory, FiRe maps the input to a fixed noise level and iteratively refines the noisy state at that level. To provide clean images for classifier guidance, FiRe first adapts Pixel Mean Flow to visual counterfactual explanation, enabling direct clean-image prediction from noisy states. To make fixed-noise refinement produce minimal and localized counterfactual edits, FiRe introduces three FiRe-specific controls: a dynamic dual-mask strategy, adaptive guidance, and early stopping, which determine where edits accumulate, which changes become visible, and when refinement stops. Experiments on five tasks across three datasets show that, compared with the strongest recent baseline, FiRe achieves about 3$\times$ faster online inference and 8$\times$ fewer FLOPs while obtaining comparable or state-of-the-art counterfactual quality.

## FiRe：用于视觉反事实解释的固定噪声细化

### 1. 核心问题与整体含义（研究动机与背景）

视觉反事实解释（Visual Counterfactual Explanations, VCE）旨在通过生成一个经过**最小化、局部化编辑**的替代图像，使分类器改变其决策，同时保留与决策无关的图像内容。该类方法在可解释人工智能（XAI）中具有重要价值——不同于显著性图仅指出"哪里重要"，反事实解释能展示"需要改变什么才能改变预测"。

现有最先进的VCE方法多基于去噪扩散概率模型（DDPM），利用其强大的图像先验生成真实的反事实图像。然而，这类方法普遍存在两个核心瓶颈：

- **时间步依赖的编辑性与空间控制冲突**：DDPM方法沿反向去噪轨迹（从高噪声到低噪声）执行分类器引导编辑。在高噪声阶段，编辑空间大但难以局部化；在低噪声阶段，空间控制好但可编辑空间受限，可能无法完成所需的语义改变。
- **噪声状态与分类器输入不匹配**：分类器在干净图像上训练，而DDPM的编辑状态是带噪声的。现有方法要么通过递归去噪获得干净的分类器输入（计算开销大），要么使用单步估计（质量差、梯度不稳定）。

FiRe的核心洞见是：**反事实编辑不一定要沿DDPM反向轨迹进行**。通过将输入固定在一个中间噪声水平并迭代细化，可以在保持语义可编辑性的同时实现局部化的空间控制，从而兼顾效率与质量。

### 2. 方法论：核心思想、关键技术细节与算法流程

#### 2.1 核心思想：固定噪声细化（Fixed-Noise Refinement）

FiRe将反事实解释重新定义为**在单一中间噪声水平下的迭代细化问题**。给定输入图像 X₀：

- 首先通过前向加噪将其映射到固定噪声状态：Z₀ᵗ = (1−t)X₀ + tZ₀
- 然后在该噪声水平下执行 K 次细化更新（k = 0, 1, …, K−1）
- 每次更新修改噪声状态，并通过Pixel Mean Flow（PMF）预测对应的干净图像供分类器使用

这里的 k 是优化步数，而非DDPM时间步，因此整个序列 Z₀ᵗ → Z₁ᵗ → … → Zₖᵗ 不是反向去噪轨迹。

#### 2.2 关键技术组件

| 组件 | 作用 |
|------|------|
| **Pixel Mean Flow（PMF）干净图像预测** | 从噪声状态直接一步预测干净图像，避免递归去噪的高成本和单步DDPM估计的低质量。这是FiRe实现高效分类器引导的关键 |
| **动态双掩码策略** | 区分"噪声状态控制"与"干净图像可见性控制"。硬掩码（hard mask）的并集决定了编辑在噪声状态中何处累积；软掩码（soft mask）决定了哪些变化在干净图像中可见 |
| **自适应引导** | 根据细化进度和目标置信度动态调整引导强度：接近目标决策时减弱引导，困难样本则加强引导 |
| **早停** | 当目标类别概率达到阈值（P_flip）时立即停止，避免过度编辑 |

#### 2.3 损失函数与更新规则

联合损失包含三项：

- **分类损失**：推动图像朝向目标类别
- **感知损失（Perceptual Loss）**：保持与原始图像的内容一致性
- **全变分损失（TV Loss）**：抑制局部伪影

噪声状态更新公式：

```
Z_{k+1}^t = M_hard ⊙ (Z_k^t − η_k ∇ L_joint) + (1 − M_hard) ⊙ Z_0^t
```

硬掩码内部累积反事实变化，掩码外部则重置为初始噪声参考，防止无关区域漂移。

#### 2.4 算法流程

1. 前向加噪：将输入映射到固定噪声水平
2. 初始化硬掩码为空，以原始图像作为初始干净图像
3. 循环执行（k = 0 至 K−1）：
   - 基于当前干净图像计算分类器梯度显著性图（SmoothGrad平滑）
   - 构建当前原始掩码 → 更新并集硬掩码 → 构建羽化软掩码
   - 计算联合损失，通过PMF反向传播获得噪声状态梯度
   - 计算自适应引导系数，在硬掩码约束下更新噪声状态
   - PMF一步预测干净图像，软掩码混合保留无关区域
   - 若目标概率达到阈值则早停返回

### 6. 主要结论与发现

1. **固定噪声细化优于反向轨迹编辑**：在PMF引导的反事实生成中，固定在同一噪声水平的细化显著优于沿DDPM反向轨迹的编辑，产生更集中、更干净的编辑。

2. **效率提升显著**：在CelebA Smile任务上，FiRe生成1,000个反事实仅需6.37分钟、1.28 PFLOPs，比最强基线MaskDiME快约**3倍**，FLOPs减少约**8倍**。

3. **质量达到最优或相当**：
   - 在所有四个面部任务上取得最优FID和sFID
   - 在大多数情况下取得最优或并列最优的MNAC（非目标属性变化更少）
   - FR在几乎所有任务上达到或接近100%
   - 在CheXpert上四项指标全面最优

4. **三个特定控制的必要性**：动态双掩码、自适应引导和早停各自对最终的局部性和质量均有显著贡献。去除早停会使FID从1.98恶化到3.47，MNAC从1.22恶化到1.42。

5. **超参数敏感性**：t = 0.4和K = 15提供了最佳权衡。过低的噪声水平限制可编辑性（FR降至87.3%），过高的噪声水平损害真实感。

### 7. 方法或实验设计的亮点

1. **问题重构角度新颖**：将反事实解释从"沿轨迹引导"重构为"固定点细化"，从根本上规避了时间步相关的不平衡问题，而非在现有框架内打补丁。

2. **干净图像预测的优雅解决方案**：引入PMF做一步式干净图像预测，恰好解决分类器需要干净输入而编辑状态是噪声的失配问题，且避免了递归去噪和单步估计的各自缺陷。

3. **精细的空间控制分层设计**：将"编辑累积位置"（硬掩码并集）与"可见变化位置"（软掩码羽化）分离，是一个值得关注的巧妙设计——分别对优化空间和视觉输出施加不同粒度的控制。

4. **自适应引导与早停的协同设计**：针对固定噪声细化的特有需求（同一状态反复更新，容易过编辑），设计了基于置信度进度双重调节的引导强度，配合早停保证"最早充分反事实"，而非过度编辑。

5. **消融实验的高质量设计**：从基本PMF引导出发逐步构建完整框架，每一步都能清晰区分特定设计决策的贡献，具有较强的说服力。

### 8. 不足与局限

1. **CD和COUT并非最优**：FiRe在多个面部任务上的CD（属性相关性一致性）和COUT（分类器输出转换）不如MaskDiME或RCSB。论文将其解释为"满足即停"的设计权衡，但这是否在更广泛的应用场景（如需要较强决策偏移的场景）中是一个劣势，值得进一步讨论。

2. **需要额外训练PMF模型**：FiRe需要为每个数据集训练一个PMF模型（总计约41 GPU小时），而部分DDPM基线可以直接复用预训练权重。在资源受限场景下，这一额外成本可能抵消部分效率优势。

3. **实验覆盖范围的局限**：
   - 仅覆盖面部和胸部X光两类图像域，未涉及自然场景图像、细粒度分类等更多样的VCE应用场景
   - 三个数据集的分类器相对简单（二分类属性/捷径移除），未验证在更复杂多类任务上的表现

4. **医学应用的谨慎性**：CheXpert实验仅展示了方法在医学图像上的初步适用性，论文也声明"不声称广泛的医学泛化能力"。在实际临床可用之前，还需要更严格的医学验证。

5. **固定噪声水平的选择**：t = 0.4虽在敏感性分析中表现最佳，但该值可能对不同任务、不同数据分布需要重新调整，缺乏自适应选择机制。

6. **梯度稳定性依赖SmoothGrad**：使用SmoothGrad（N=20）稳定显著性图增加了计算成本，且该方法对N的取值可能敏感，论文未充分讨论这一敏感性。
