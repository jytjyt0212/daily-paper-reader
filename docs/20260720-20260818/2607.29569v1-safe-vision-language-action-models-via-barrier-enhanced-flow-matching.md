## 摘要
本文提出了一种模块化推理框架，将流匹配生成模型与形式化的控制屏障函数（CBF）安全保证相结合。与现有方法对模型最终输出应用外部安全过滤器不同，我们的方法修改模型内部的流匹配去噪过程，从而固有地生成安全轨迹。通过采用平滑的对数-求和-指数聚合屏障，我们在整个动作块上强制执行安全性。这种聚合屏障确保了计算开销的最小增加，并且不改变模型的语义意图。我们表明，在所提出的框架内，生成分布与目标分布之间的2-Wasserstein距离保持有界。我们的方法无需特定安全数据集或昂贵的模型重新训练，为安全推理提供了一种通用解决方案。我们在两个机器人操作平台和一个2D导航基准上验证了该方法，证实了我们的框架能够在不降低模型成功率的情况下实现可靠的安全性。

## Abstract
This article presents a modular inference framework that integrates Flow Matching generative models with formal Control Barrier Function (CBF) safety guarantees. Unlike existing methods that apply external safety filters to a model's final output, our approach modifies the Flow Matching denoising process within the model to inherently generate safe trajectories. By employing a smooth Log-Sum-Exponential aggregate barrier, we enforce safety over entire action chunks. This aggregate barrier ensures a minimal increase in computational overhead and does not alter the semantic intent of the model. We show that, within the proposed framework, the 2-Wasserstein distance between the generated distribution and the target distribution remains bounded. Our method eliminates the need for safety-specific datasets or costly model retraining, providing a versatile solution for safe inference. We validate the approach on two robotic manipulation platforms and a 2D navigation benchmark, verifying that our framework achieves reliable safety without degrading the success rate of the model.

### 1. 论文的核心问题与整体含义（研究动机和背景）

- **研究背景**：随着Transformer、视觉语言模型（VLM）、扩散策略和多模态数据集的发展，通用机器人策略（Generalist Robotic Policies）已成为现实。现代视觉语言动作（VLA）模型（如π0、OpenVLA、SmolVLA）通过Flow Matching实现动作块（Action Chunk）的生成，具备强大的语义理解和动作规划能力，但在安全关键场景下仍缺乏形式化的安全保证。
- **核心问题**：现有安全集成方法大多采用**事后过滤**（post-hoc filtering）——对模型最终输出施加CBF安全滤波器。这种方式存在两个关键缺陷：
  - 可能生成**分布外样本**，损害轨迹质量和任务成功率（论文实验中也验证了这一点）。
  - 无法在生成过程内部提供内生安全保障，缺乏对最终输出安全性的形式化保证。
- **解决思路**：直接在Flow Matching去噪过程中嵌入控制屏障函数（CBF），让模型"内在"地生成安全轨迹，而非在输出后修正。该方法不需要额外的安全数据集，也不需要模型重训练，可作为一个即插即用的模块化推理安全层。

### 2. 论文提出的方法论

#### 核心思想
- 将CBF安全约束以二次规划（QP）形式嵌入Flow Matching去噪过程中，在每个去噪步对向量场施加最小修正，使得整个动作块满足预定义的安全约束（如：避免碰撞、限制速度）。
- 同时引入**轨迹平滑性**优化目标，在保证安全的前提下提升生成轨迹质量。

#### 关键技术细节

**（1）平滑聚合屏障（Log-Sum-Exp Aggregate Barrier）**

动作块 `z = [q₁, q₂, ..., q_H]` 包含H个连续时刻的目标状态。直接使用逐点min操作定义"整个动作块安全"虽然直观，但不可微且可能高度非凸。论文采用Log-Sum-Exp函数（公式8）平滑地逼近min操作：

```
h(z) = -(1/κ) * ln( Σ_{i=t}^{t+H} e^{-κ h(q_i)} )
```

该函数满足以下有界误差保证（Theorem 2）：

```
min(h(q_i)) - ln(H)/κ ≤ h(z) ≤ min(h(q_i))
```

κ为平滑参数：κ越大越接近min算子但安全裕度越小；κ越小越平滑。通过该聚合，动作块的H个安全约束可以被**单个CBF约束**替代，大幅降低QP求解的计算开销。

**（2）Barrier-Enhanced Flow Matching**

修改原始Flow Matching ODE（公式1），增加修正项δ_s：

```
dψ_s(z, τ)/dτ = v(τ, ψ(z, τ)) + δ_s
```

通过以下QP求最优δ\_s（公式19，含速度约束和平滑正则项）：

```
δ_s = argmin_δ  ½||δ||² + λ||D(z + (v_θ + δ)Δt)||²
s.t.   ∂h/∂z · (v_θ + δ) ≥ -α h(z)          （CBF约束）
       v_min ≤ D(z + (v_θ + δ)Δt) ≤ v_max   （速度约束）
```

其中K矩阵为稀疏矩阵，计算相邻动作间的有限差分速度。

该QP存在闭式解（公式13）：

```
δ_s = ReLU(-αh(z) - ∇_z h(z)v_θ(τ, z)) / ||∇_z h||² · ∇_z h
```

**（3）安全保证与分布偏移分析**

- **Theorem 3（有界发布偏移）**：在Flow Matching的L2近似误差、Lipschitz连续性等假设下，修正后的生成分布与目标分布之间的2-Wasserstein距离保持有界。Corollary 1进一步证明了CBF修正项的引入仅使误差界有限膨胀，**不会导致分布偏移失控**。
- **Theorem 4（安全性保证）**：设噪声采样时屏障函数值为h₀，最坏情况下屏障衰减率为M。当安全过滤在τ_s≥τ阶段启用且满足τ_s ≤ h₀/M时，最终生成的轨迹满足 h(ψ(z,1.0)) ≥ (h₀ - Mτ_s)e^(-α(1-τ_s)) > 0，即**安全得到形式化保证**。实际应用中，即使条件不完全满足，CBF的指数收敛特性也会使轨迹迅速回归安全集。

**（4）算法流程（Algorithm 1）**

1. 采样噪声 z₀（Beta分布）；
2. 每个去噪步求解目标动作块 v_θ（VLA推理）；
3. 当 τ ≥ τ_s 时，计算聚合屏障 h(z) 及其梯度 ∇h/∂z（基于λ_i加权）；
4. 求解QP（公式19）获取修正项 δ_s；
5. 使用修正后的向量场更新z；
6. 去噪完成后输出安全动作块 z₁.₀。

#### 支持的屏障函数示例

- **平面墙壁屏障**：h(q) = ⟨n, p_ee⟩ - d，阻止末端夹爪穿过平面（如桌面或墙壁）；
- **球形障碍屏障**：h(q) = ‖p_ee - p_center‖² - r²，将末端夹爪限制在球形区域之外。
