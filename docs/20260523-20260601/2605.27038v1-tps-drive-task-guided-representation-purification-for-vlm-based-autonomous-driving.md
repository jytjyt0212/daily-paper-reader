## 摘要
视觉-语言模型（VLM）为自动驾驶规划提供了有前景的基础，但弥合语义推理和精确3D空间预测之间的差距仍然是一个关键挑战。现有的表征策略通常遵循两条路径：文本对齐方法将连续空间状态压缩为符号，这损害了几何结构并导致“空间幻觉”；密集视觉方法保留空间拓扑但用冗余背景纹理淹没标准分词器，导致“表征干扰”。为解决这些限制，我们引入TPS-Drive，一个以任务引导的表征净化为核心的新框架，使VLM能够在净化空间中思考。其核心是一个以智能体为中心的分词器，利用由冻结的3D检测头监督的任务引导向量量化机制，将有限的码本容量从普遍的静态背景显式重新分配给关键的动态智能体，并有效隔离空间冗余。利用这种净化的空间词汇，TPS-Drive采用解耦推理流程，依次执行场景理解、未来预测和动作生成。该框架通过渐进式三阶段训练范式进行优化，最终通过奖励驱动的微调超越纯模仿学习。大量实验验证了我们的方法：TPS-Drive在开环nuScenes评估中实现了准确的智能体空间状态预测并降低了碰撞率，同时在严格的闭环NAVSIMv1和NAVSIMv2基准上建立了新的安全记录。

## Abstract
Vision-Language Models (VLMs) provide a promising foundation for autonomous driving planning, yet bridging semantic reasoning and precise 3D spatial forecasting remains a critical challenge. Existing representation strategies generally follow two paths: text-aligned methods flatten continuous spatial states into symbols, which compromises geometric structure and induces "spatial hallucinations"; dense visual methods preserve spatial topology but overwhelm standard tokenizers with redundant background textures, leading to "representation interference". To address these limitations, we introduce TPS-Drive, a novel framework centered on Task-Guided Representation Purification that empowers VLMs to Think in Purified Space. At its core, an Agent-Centric Tokenizer utilizes a task-guided vector quantization mechanism supervised by a frozen 3D detection head, which explicitly reallocates limited codebook capacity from pervasive static backgrounds to critical dynamic agents and effectively isolates spatial redundancy. Leveraging this purified spatial vocabulary, TPS-Drive employs a decoupled reasoning pipeline that sequentially performs scene understanding, future forecasting, and action generation. The framework is optimized via a progressive three-stage training paradigm, culminating in reward-driven refinement that surpasses pure imitation learning. Extensive experiments validate our approach: TPS-Drive achieves accurate agent spatial state forecasting and reduces collision rates in open-loop nuScenes evaluations, while establishing new safety records on the rigorous closed-loop NAVSIMv1 and NAVSIMv2 benchmarks.

- **整体含义**：需要一种新的表征方式，在保留关键动态智能体几何信息的同时，剔除静态背景冗余，使VLM能在“净化空间”中思考，从而有效结合语义推理与精确空间预测。

## 2. 方法论

### 2.1 核心思想：任务引导的表征净化

- 构建**Agent-Centric Tokenizer**（以智能体为中心的分词器），通过任务引导的向量量化（VQ）机制，将码本容量从静态背景和冗余纹理显式重新分配给关键动态智能体。
- 采用**解耦推理管线**：场景理解 → 未来预测 → 动作生成，分别处理语义、空间状态和控制。

### 2.2 关键技术细节

#### 2.2.1 Agent-Centric Tokenizer

- **任务引导主码本 V₁**：
  - 输入：BEV特征图 B（尺寸 D×H×W）。
  - 编码器 Eϕ 将BEV映射为低分辨率潜在网格 e ∈ R^(D′×H′×W′)，每个空间位置 eᵢⱼ ∈ R^D' 被量化到最近的码本条目 vₘ，得到离散令牌 zᵢⱼ ∈ V₁^N（N = H'×W'）。
  - 量化公式：zᵢⱼ = argminₘ ||eᵢⱼ - vₘ||，qᵢⱼ = v_{zᵢⱼ}。
  - 解码器 Dψ 从量化表示 q 重建净化特征图 B̂。
- **任务引导监督**：使用冻结的CenterPoint 3D检测头（基于点云），在训练中同时优化重建损失、检测损失（热图Lhm和3D边界框Lbox）以及标准VQ损失（Lvq、Lcommit）。目标函数：
  ```
  L_primary = λr L_rec(B̂, B) + λh Lhm + λb Lbox + Lvq + β Lcommit
  ```
  - 重建损失维持结构完整性，但权重λr较小避免过度保留背景；检测损失迫使码本集中编码动态智能体。
- **残差细化层**：引入 L-1 个附加码本 {Vℓ}ℓ=2..L，采用残差层次结构，每个码本量化前一层的残差。最终重建：B̃ = Dψ(∑ℓ q^(ℓ))。
  - 主令牌 z^(1) 输入VLM骨干作为自回归预测目标；残差令牌由轻量分类头并行预测，保持序列紧凑。

#### 2.2.2 解耦推理架构

- **阶段1 - 场景理解**：视觉-语言骨干从多视图图像、BEV、指令等提取结构化表示 s_t（包括场景描述和物理规则）。使用Qwen3.5-27B预标注训练数据，通过交叉熵损失 L_scene 监督。
- **阶段2 - 未来预测**：以 s_t 和当前观测为条件，自回归预测未来主令牌序列 z^(1)_{t+Δt}，同时并行预测残差令牌。损失函数：
  ```
  L_world = -∑ₙ log p(z^(1)_{t+Δt,n} | x_t, z^(1)_{t+Δt,<n}) + λ_res ∑_{ℓ=2} L_CE(gℓ(h_{t+Δt}), z^(ℓ)_{t+Δt})
  ```
- **阶段3 - 动作生成**：使用条件扩散模型（Denoising Transformer ϵθ），以未来令牌隐藏状态、结构化表示和动作起始提示为条件，预测连续轨迹 τ_{t+1:t+T_plan}。扩散损失：
  ```
  L_plan = E[||ϵ - ϵθ(τ_k, k, f_t)||²]
  ```

#### 2.2.3 三阶段训练范式

1. **阶段1 - Tokenizer预训练**：先训练主码本和残差码本（分两阶段，先主后残冻住主）。
2. **阶段2 - 监督微调（SFT）**：联合优化 L_scene + L_world + L_plan，高效微调视觉编码器和语言模型，全量更新专用头。
3. **阶段3 - 奖励驱动微调**：基于分组相对优化的策略（类似GRPO），采样多个随机 rollout，用离线奖励（几何误差、平滑度）打分，更新世界模型分支和扩散规划器。
