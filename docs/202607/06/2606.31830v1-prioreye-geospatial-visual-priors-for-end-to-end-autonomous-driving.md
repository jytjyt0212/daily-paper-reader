## 摘要
大多数端到端自动驾驶方法仅依赖瞬时传感器观测，限制了它们只能做出反应性行为，而无法像人类驾驶员通过先验经验那样具有预见性。我们引入了地理空间视觉先验——锚定于预期驾驶路线的街景视觉上下文，提供独立于实时传感器的视觉空间前瞻能力。我们提出了一个记忆增强模块，具有双记忆架构和自适应记忆门，可轻松集成到现有端到端方法中。该设计将用于检索先验的上下文记忆与持久回退记忆配对，并根据当前状态兼容性动态调节记忆的影响。在NAVSIM-v2基准上的评估表明，我们的方法在多种端到端基线上均能持续提升性能。此外，由于这些先验独立于车载传感器，我们的方法固有地增强了对传感器损坏的鲁棒性，而双记忆设计确保当检索到的先验本身变得不可靠时能够安全回退。我们的项目页面见https://ori-mrg.github.io/PriorEye。

## Abstract
Most end-to-end autonomous driving methods rely solely on instantaneous sensor observations, limiting them to reactive behavior without the anticipatory foresight human drivers employ through prior experience. We introduce geospatial visual priors, street-level visual context anchored to the intended driving route, providing visual-spatial foresight independent of real-time sensors. We propose a memory augmentation module featuring a dual-memory architecture and an adaptive memory gate, which can be easily integrated into existing end-to-end approaches. This design pairs a contextual memory for retrieved priors with a persistent fallback memory, and dynamically regulates the influence of memories based on current state compatibility. Evaluated on the NAVSIM-v2 benchmark, our approach consistently improves performance across diverse end-to-end baselines. Furthermore, because these priors are independent of onboard sensors, our method inherently improves robustness against sensor corruption, while the dual-memory design ensures safe fallback when the retrieved priors themselves become unreliable. Our project page is available at https://ori-mrg.github.io/PriorEye.

### 1. 论文的核心问题与整体含义（研究动机和背景）

- **核心问题**：现有的大多数端到端自动驾驶（E2E AD）系统仅依赖车辆的实时传感器数据（如摄像头图像、激光雷达点云）进行决策。这种“瞬时反应”模式存在根本性缺陷，即系统缺乏像人类驾驶员那样基于过往经验（先验知识）预测前方道路环境的能力，导致其行为往往是被动的，难以应对复杂或突发状况。
- **研究背景**：虽然已有工作利用记忆模块增强驾驶模型，但多局限于对过去几秒内的短时观测进行融合，未能提供超越当前视野范围的、与未来规划路线相关的“前瞻性”信息。
- **整体含义**：为了解决这一局限性，作者提出了**PriorEye**，旨在为E2E自动驾驶系统注入一种被称为“地理空间视觉先验”的预测性知识，使其能够“看到”尚未到达但即将行驶的路段，从而具备类似于人类驾驶员的预见能力，提升驾驶的安全性和鲁棒性。

### 2. 论文提出的方法论：核心思想、关键技术细节

- **核心思想**：设计一种独立于车载传感器、基于**驾驶路线**的视觉先验信息，并将其融合进现有的E2E模型中。这种先验信息来源于沿规划路线预先录制的街景图像，提供了关于未来道路布局、环境特征等关键视觉上下文。

- **关键技术细节**：
    1.  **地理空间视觉先验**：锚定于导航系统的**驾驶路线**，而非车辆当前位置。它通过查询一个地理参考的街景图库，检索沿规划路线的一系列预先采集的街景图像，以此提供视觉前馈（visual foresight）。这部分信息不依赖车载传感器，因此更稳定。
    2.  **双记忆架构**：提出了一个可轻量级集成到现有模型的记忆增强模块。该模块包含两个记忆单元：
        - **上下文记忆**：存储近期从地理参考图库中检索到的“地理空间视觉先验”。该记忆被实时更新，信息最新，但可能因图库过时或路线临时变更而变得不可靠。
        - **持久回退记忆**：存储一个稳定、通用的默认先验知识（例如，车道保持、停止线等基本场景模式）。在上下文记忆不可靠时，该记忆提供安全的回退策略。
    3.  **自适应记忆门**：一个可学习的门控机制，用于**动态调节**上下文记忆和持久回退记忆的融合权重。它根据当前驾驶状态与记忆内容的兼容性，智能地决定是更多地依赖最新的上下文先验，还是回退到通用的持久记忆。

- **算法流程**：
    1.  **路线锚定**：根据车辆当前规划的未来驾驶路线，确定一系列沿线的地理坐标点。
    2.  **先验检索**：利用这些坐标点，从一个预先构建好的大规模地理参考图像库（如Google Street View）中检索对应的街景图像。
    3.  **特征编码**：使用视觉编码器（如ResNet、ViT）将检索到的街景图像和当前车载传感器图像编码为特征向量。
    4.  **记忆融合**：将编码后的先验特征送入上下文记忆，同时将通用知识存入持久回退记忆。自适应记忆门根据当前车载观测的特征，评估上下文记忆的可靠性，并计算两者的融合权重。
    5.  **决策输出**：融合后的记忆特征与当前观测特征一同被送入原有的E2E驾驶决策网络，最终输出驾驶指令（如方向盘转角、油门/刹车）。

### 8. 不足与局限
