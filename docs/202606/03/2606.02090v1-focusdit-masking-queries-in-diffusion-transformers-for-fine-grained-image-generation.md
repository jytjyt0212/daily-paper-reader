## 摘要
扩散变换器（DiT）在生成扩散领域被广泛采用，通过注意力机制和前馈（\text{FFN}）层推进查询令牌的去噪过程。FFN实际上充当了解码视觉内容的键值词典，其中值嵌入了视觉语义知识。我们提出，关注对应于更复杂细节的关键查询令牌，并鼓励模型改进这些令牌，对于细粒度视觉生成至关重要。为此，我们提出了FocusDiT，它应用了一种掩码方案来聚焦于仅输入FFN的关键查询令牌。被掩码的查询可以从FFN词汇表中检索视觉令牌，并使用它们来解码其视觉细节。大量的文本到图像实验验证了令牌掩码在增强生成性能方面的有效性。

## Abstract
Diffusion transformer (DiT) has been widely adopted in the generative diffusion field, advancing the denoising of query tokens through attention and Feed-Forward (\text{FFN}) layers. FFN actually acts as the key-value vocabulary for decoding visual contents where the value embeds the visual semantical knowledge. We present that focusing on critical query tokens corresponding to more complex details and encouraging the model to improve these tokens is essential for fine-grained visual generation. To this end, we propose FocusDiT, which applies a Masking scheme to focus on critical query tokens that are exclusively fed into FFN. The masked queries can retrieve visual tokens from the FFN vocabularies, and use them to decode their visual details. Extensive text-to-image experiments validate the effectiveness of token masking in enhancing generative performance.

# FocusDiT：扩散变换器中的查询掩码用于细粒度图像生成

## 1. 核心问题与整体含义（研究动机和背景）
- **背景**：扩散变换器（DiT）已成为视觉生成的主流架构，其中的前馈层（FFN）被揭示为一种键值记忆词汇表，用于存储训练数据中学到的视觉语义知识。查询令牌通过FFN检索这些视觉令牌以解码视觉内容。
- **核心问题**：现有DiT对所有查询令牌一视同仁，导致那些对应复杂细节（如人脸、纹理、建筑结构等）的关键令牌被大量对应于背景或低频区域的非关键令牌所淹没，无法充分利用FFN词汇表来解码精细细节。同时，FFN词汇表在不同层中存在利用率不足的问题，某些词汇条目很少被查询令牌激活。
- **研究意义**：提出一种有选择性地聚焦关键查询令牌的策略，使其能够更充分地利用FFN词汇表，从而在不增加总参数量的前提下提升细粒度图像生成质量。

## 2. 方法论

### 核心思想
- 设计一个**查询令牌掩码**，动态区分关键令牌（对应复杂细节）和非关键令牌，仅让关键令牌的更新通过FFN进行，而非关键令牌的FFN更新被抑制。
- 同时提出**词汇重分配（Vocabulary Redistribution, VR）**，根据不同层对词汇表的需求差异，重新分配各层FFN的内部维度（词汇表大小），形成“纺锤形”分布：浅层和深层分配较小的词汇表，中层分配更大的词汇表，总参数量保持不变。

### 关键技术细节
- **查询掩码生成网络（Q-MaskGen）**：以当前块的输入特征、上一块的掩码以及扩散时间步为输入，通过多层感知机（MLP）预测每个查询令牌的掩码值（0~1）。时间步信息通过AdaLN-single编码，使掩码在去噪前期（噪声水平高）趋于均匀，后期（噪声水平低）聚焦于关键令牌。
- **掩码应用**：将掩码乘到FFN的输出更新量上，公式为  
  \( Z_t^{out} = Z_t^{in} + M_Q \cdot \text{FFN}(Z_t^{in}) \)  
  反向传播时，掩码也作用于梯度，使非关键令牌的FFN参数更新被抑制，从而鼓励FFN编码更多与复杂细节相关的视觉知识。
- **词汇重分配**：设总块数为L，基线内部维度为\(4M\)（M为模型宽度）。设置第一块内部维度\(P = 3M\)，每相邻块变化量\(\Delta = \lfloor 2/(L/2-1) \rfloor\)，使得浅层（第1块到第L/2块）内部维度线性增加，深层（第L/2+1块到第L块）对称减小。总参数量与基线一致。

## 3. 实验设计

### 数据集
- **真实图像**：Coyo-HD-11M、LAION-Aesthetics-V1-120M、LAION-Art-8M（均选自高质量美学图像）。
- **合成图像**：Midjourney-Niji-1M（由Midjourney-V6生成）。
- **内部数据**：自收集的50万对文本-图像。
- **训练规模**：先在256×256分辨率下训练（batch size 2048），再在512×512分辨率下微调（batch size 1280），总训练步数约60k。

### 评估指标
- **FID**：衡量生成图像与真实图像的分布相似度。
- **CLIPScore**：评估图像与文本的语义对齐。
- **GenEval**：评估组合质量（对象共现、空间布局、计数、颜色）。
- **ImageReward**：基于人类偏好的感知质量。
- **SCTF（结构清晰度和纹理保真度）**：使用VLM（Qwen2.5-VL、InternVL-2.5）对生成图像的结构与纹理打分（0-10），并报告均值和标准误（SEM）。

### 对比方法
- PixArt-α、SD3、OpenSoraPlan（均为DiT变体）。
- 消融实验中还对比了不同层数的MLP、Dropout、前一层掩码、VR等变体。

## 6. 主要结论与发现
- 查询令牌掩码可以有效提升关键令牌对FFN词汇表的利用，从而在生成长发纹理、建筑细节、抽象概念等复杂场景时获得更精细的结构和更少的伪影。
- 词汇重分配使词汇表利用率显著提升（浅层和深层利用率提高，中层更充分利用），在不增加参数量的情况下改善生成质量。
- 基于掩码均值的FFN跳过策略可无损加速推理（阈值0.15时加速约14%），且参数剪枝（去除8个不重要FFN层）可减少12%参数而不显著降质。
- 用户研究表明FocusDiT在人类偏好上优于PixArt-α和SD3。

- **方法创新**：首次从FFN词汇表利用角度对DiT进行优化，提出有针对性的查询掩码和词汇重分配，思路新颖且数学表述清晰。
- **高效性**：训练算力仅为PixArt-α的约20%，却取得可比甚至更优的细粒度生成效果；推理阶段可灵活加速。

## 8. 不足与局限
- **数据限制**：主要使用开源数据集，规模和质量不及SD3等商业模型使用的内部数据，导致在FID和CLIPScore上未能超越SD3。作者也指出若使用更大且更多样化的数据集，性能可进一步提升。

- **应用限制**：方法主要针对图像生成，对其他模态（如视频、3D）的泛化性未讨论；推理加速基于固定阈值，需要手动调参。
