## 摘要
多任务学习旨在通过跨域共享共同表示来构建多个任务的联合模型。为实现这一目标，现有的优化中心方法要么平衡任务梯度，要么修改共享架构。然而，由于这些方法对共享表示的内容保持不可知，它们无法将任务相关结构与虚假上下文分离，导致负迁移和泛化能力差。为克服这一局限，我们提出了用于多任务学习的因果正交表示（CORE-MTL），这是一个因果驱动的表示中心框架，鼓励共享表示的结构化语义-残差分解，将任务相关结构集中在语义流中，同时将干扰变化归入残差流。我们通过利用结构化场景的物理先验和属性的统计约束，在视觉领域实例化了该框架。理论上，我们的方法比优化中心方法具有更紧的分布外泛化界，并在无需显式梯度投影或重新加权的情况下减少了任务梯度干扰。实验上，CORE-MTL在视觉多任务基准的分布内和分布外设置中均一致优于现有方法。代码公开于https://github.com/Hope-Rita/CORE-MTL。

## Abstract
Multi-task learning (MTL) aims to construct a joint model for multiple tasks by sharing a common representation across domains. To achieve this goal, existing optimization-centric methods either balance task gradients or modify the shared architecture. However, as these approaches remain agnostic to the content of the shared representation, they fail to disentangle task-relevant structure from spurious context, leading to negative transfer and poor generalization. To overcome this limitation, we propose Causal Orthogonal Representations for Multi-Task Learning (CORE-MTL), a causally motivated representation-centric framework that encourages a structured semantic-residual factorization of the shared representation, concentrating task-relevant structure in the semantic stream while relegating nuisance variation to the residual stream. We instantiate this framework in the visual domain by leveraging physical priors for structured scenes and statistical constraints for attributes. Theoretically, our method enjoys a tighter out-of-distribution generalization bound than optimization-centric methods and reduces task gradient interference without explicit gradient projection or reweighting. Empirically, CORE-MTL consistently outperforms existing methods on visual multi-task benchmarks in both in-distribution and out-of-distribution settings. Code is publicly available at https://github.com/Hope-Rita/CORE-MTL.

现有多任务学习方法主要分为优化中心和架构中心两类：优化中心方法（如GradNorm、PCGrad等）通过重新加权或投影梯度来平衡任务；架构中心方法（如MTAN）通过修改共享架构让每个任务关注特征的不同切片。然而，这些方法都忽略了共享表示的内部结构，未能将任务相关语义（invariant semantics）与虚假上下文（spurious context，如纹理、光照等干扰因素）解耦。这种纠缠导致负迁移（negative transfer）和分布外泛化（OOD generalization）能力差。论文从因果视角指出：梯度冲突往往是症状而非根本原因，根本原因在于共享表示中编码了任务间共享的干扰驱动捷径。因此，需要从表示层面进行结构化分离，而非仅进行后处理梯度手术。

## 2. 论文提出的方法论：核心思想、关键技术细节

### 核心思想
提出CORE-MTL，一个因果驱动的表示中心框架，将共享表示分解为**语义流（semantic stream）**和**残差流（residual stream）**。语义流捕获任务相关且跨任务稳定的结构，残差流吸收任务无关的干扰变化。任务预测仅依赖于语义流，从而从根源上消除干扰驱动的负迁移。

### 关键技术细节
- **双流编码器**：共享编码器Φθ输出 (Ẑs, Ẑr)，任务头仅使用Ẑs进行预测。
- **结构独立性约束**：使用线性中心核对齐（Linear CKA）作为正则项，最小化语义流和残差流之间的线性依赖性，对应理论中的泄漏系数λleak。
- **反事实特征增强（CFA）**：通过辅助解码器D从(Ẑs, Ẑr)重建输入x；训练时随机替换残差流形成反事实图像x̃，约束编码器从x̃中提取的语义表示仍能正确预测任务标签，从而鼓励语义对干扰的不变性。
- **接地机制（Grounding）**：
  - **硬接地（Hard Grounding）**：针对场景理解任务，使用基于物理的逆渲染解码器，将语义流映射为几何结构（如法线），残差流映射为光度因子（如反照率、光照），通过固定物理着色模型组合，强制角色分配。
  - **软接地（Soft Grounding）**：对一般任务使用通用的卷积解码器，通过重建损失和独立性约束推动功能分离。

## 6. 论文的主要结论与发现

1. **表示纠缠是负迁移的根本原因**：优化中心方法无法通过梯度操作消除由表示混合引起的OOD误差下界。
2. **CORE-MTL通过结构解耦实现鲁棒泛化**：在ID和OOD设置中均一致优于所有对比基线，尤其在OOD场景下优势显著（如GTA5→Cityscapes目标域mIoU最高、深度误差最低）。
3. **梯度正交性作为结构副产物**：解耦后任务梯度与残差梯度自然正交，无需后处理。
4. **可扩展性好**：训练时间不随任务数线性增长，优于PCGrad等梯度手术方法。
5. **接地机制有效**：硬接地（物理先验）比软接地略优，但软接地已足够有效；CKA和CFA共同作用最佳。

## 7. 优点

## 8. 不足与局限
