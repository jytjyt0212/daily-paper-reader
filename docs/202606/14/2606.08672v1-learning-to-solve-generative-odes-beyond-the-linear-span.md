## 摘要
扩散模型和流生成模型通过积分学习到的ODE进行采样，但高质量结果仍需要许多顺序模型评估。求解器学习通过调整标量系数、时间步长或两者来降低这一成本，同时保持骨干模型固定。在这项工作中，我们发现了这种更新族中的一个结构瓶颈：每一步仍然受限于生成范围。由于标量系数更新位于缓冲速度评估的生成范围内，它只能拟合范围内的分量，而任何范围外的残差仅靠标量重组无法达到。我们提出了SpanLift，一种轻量级神经求解器，用空间残差算子增强标量系数更新。SpanLift将固定的基础求解器作为范围内先验，并学习状态和速度缓冲区上的空间残差算子。该算子通过端点教师匹配进行训练，保留预训练的骨干，且不增加模型NFE。经验上，学习到的校正可跨基础求解器迁移，且主要位于范围外。在像素空间扩散、潜在流匹配和降水临近预报中，SpanLift实现了最先进的少步采样。仅用3 NFE，它将CIFAR-10的FID从8.16提升到5.69，ImageNet的FID从17.37提升到11.83。

## Abstract
Diffusion and flow generative models sample by integrating a learned ODE, but high quality still requires many sequential model evaluations. Solver learning reduces this cost by adapting scalar coefficients, timesteps, or both, while keeping the backbone model fixed. In this work, we identify a structural bottleneck in this update family: each step remains span-limited. Since the scalar-coefficient update lies in the span of buffered velocity evaluations, it can fit only the in-span component while leaving any out-of-span residual unreachable by scalar recombination alone. We propose SpanLift, a lightweight neural solver that augments scalar-coefficient updates with a spatial residual operator. SpanLift keeps a fixed base solver as an in-span prior and learns a spatial residual operator over the state and velocity buffer. The operator is trained by endpoint teacher matching, preserves the pretrained backbone, and adds no model NFEs. Empirically, the learned correction transfers across base solvers and is predominantly out-of-span. Across pixel-space diffusion, latent flow matching, and precipitation nowcasting, SpanLift achieves state-of-the-art few-step sampling. With only 3 NFE, it improves CIFAR-10 FID from 8.16 to 5.69 and ImageNet FID from 17.37 to 11.83.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **背景**：扩散模型和流生成模型通过求解生成式 ODE 进行采样，但高质量输出需要大量模型评估（NFE）。现有方法通过“求解器学习”（solver learning）减少 NFE，主要做法是学习标量系数、时间步或两者，但保持骨干模型固定。
- **问题**：作者发现这类更新族存在结构瓶颈——每一步更新都受限于“速度缓冲区的线性跨度”（span of buffered velocity evaluations）。标量系数更新只能拟合 **跨度内** 的分量，而 **跨度外** 的残差无法通过标量重组达到，导致在极少步数（如 3-5 NFE）时采样质量严重受限。
- **意义**：本文指出，少步采样不单是优化标量系数或评估点的问题，必须 **扩大可容许的更新类**，使其能够访问速度缓冲区之外的方向。这为提升生成式 ODE 的少步采样质量提供了新的理论视角和实用方案。

## 2. 论文提出的方法论

### 核心思想
提出 **SpanLift**，一种轻量级神经求解器，在固定基础求解器（base solver）上增加一个 **学习到的空间残差算子**。基础求解器提供可靠的“跨度内”更新，残差算子提供“跨度外”的校正方向。

### 关键技术细节
- **残差算子参数化**：
  - 设速度缓冲区 \(X_i = (u_i, u_{i-1}, \dots, u_{i-K+1})\)。
  - 基础更新 \(\Delta_i^{\text{base}} = \mathcal{A}_i^{\text{base}}(X_i)\)（如 iPNDM、DyWeight 等标量系数求解器）。
  - SpanLift 更新：\(\Delta_i^{\text{SL}} = \alpha_i \Delta_i^{\text{base}} + \beta_i \Delta_i^{\text{op}}\)，其中 \(\Delta_i^{\text{op}} = R_\phi(\tilde{X}_i; \xi_i)\)。
  - 输入 \(\tilde{X}_i = \text{Concat}(x_i, u_i, u_{i-1}, \dots, u_{i-K+1})\)，条件 \(\xi_i = [t_i, \lambda_i, h_i]\)（当前时间、logSNR、步长）。
  - 初始化为 \(\alpha_i=1, \beta_i = 0\)，保持基础求解器先验。
- **架构**：\(R_\phi\) 是一个浅层 FiLM 条件化 CNN，包括 1×1 卷积 stem、带 depthwise 空间卷积的 FiLM 残差块、最终卷积头。默认隐藏维度 d=64，2 个残差块，参数极少。
- **训练目标**：端点教师匹配（endpoint teacher matching），仅监督最终输出：
  \[
  S^\dagger = \arg\min_{S} \mathbb{E}_{x_0 \sim p_0} [\ell(\Phi^S(x_0), \Phi^\star(x_0))]
  \]
  - 对于像素空间扩散模型，使用 Inception loss；对于潜在流匹配模型，使用 MSE + DINOv2 感知损失。
- **关键特点**：不增加模型 NFE（轻量 CNN 额外计算，不调用生成模型），冻结骨干模型。
