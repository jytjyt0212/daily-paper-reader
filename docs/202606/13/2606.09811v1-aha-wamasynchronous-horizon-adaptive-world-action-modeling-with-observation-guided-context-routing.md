## 摘要
世界-动作模型已成为机器人操作的一种有前景的范式，它联合建模视觉场景动态和动作，将物理先验注入策略学习。然而，现有的世界-动作模型以相同的时间分辨率耦合世界预测和动作执行，迫使世界分支建模近期的帧变化，这些变化是冗余且信息量弱的。我们认为，将世界预测和动作执行严格绑定在同一时间节奏可能未能充分利用视频分支在具身控制中的潜力。因此，我们提出AHA-WAM，一种基于双扩散变换器（DiT）架构构建的异步自适应时域世界-动作模型，围绕这种时间不对称性重新组织世界-动作建模。AHA-WAM将视频DiT实例化为低频世界规划器，它维护过去观测的滚动键值记忆，并暴露可重用的逐层潜在上下文编码长视界场景演化，而高频动作DiT通过逐层联合注意力查询此上下文，以闭环方式执行短动作块。为了支持异步执行，我们引入了自适应时域偏移训练和观测引导的视频上下文路由（OVCR），两者共同使动作专家能够利用长视界世界上下文，同时保持对实时执行状态的响应，无需重新运行视频DiT。在RoboTwin和真实世界操作任务上的实验表明，AHA-WAM在没有任何机器人数据预训练的情况下达到了最先进的性能，在RoboTwin上平均成功率为92.80%，在4个真实世界任务上成功率为78.3%，同时实现了24.17 Hz的闭环控制，比Fast-WAM加速4.59倍。

## Abstract
World-action models have emerged as a promising paradigm for robot manipulation, jointly modeling visual scene dynamics and actions to inject physical priors into policy learning. However, existing world-action models couple world prediction and action execution at the same temporal resolution, forcing the world branch to model near-term frame variations that are redundant and weakly informative. We posit that strictly binding world prediction and action execution to the same temporal rhythm may underutilize the potential of the video branch for embodied control. Therefore, we propose AHA-WAM, an Asynchronous Horizon-Adaptive World-Action Model built on a dual Diffusion Transformer (DiT) architecture that reorganizes world-action modeling around this temporal asymmetry. AHA-WAM instantiates the video DiT as a low-frequency world planner that maintains rolling key-value memory over past observations and exposes reusable layerwise latent context encoding long-horizon scene evolution, while a high-frequency action DiT executes short action chunks in closed loop by querying this context through layerwise joint attention. To support asynchronous execution, we introduce horizon-adaptive offset training and Observation-Guided Video-Context Routing (OVCR), which together let the action expert exploit long-horizon world context while remaining responsive to real-time execution state without rerunning the video DiT. Experiments on RoboTwin and real-world manipulation tasks show that AHA-WAM achieves state-of-the-art performance without any robot-data pretraining, attaining 92.80% average success on RoboTwin and 78.3% success across 4 real-world tasks, while reaching 24.17 Hz closed-loop control with a 4.59x speedup over Fast-WAM.

# AHA-WAM：基于观测引导上下文路由的异步自适应时域世界-动作模型

## 1. 核心问题与整体含义（研究动机和背景）

- **问题背景**：现有世界-动作模型（World-Action Models, WAMs）将世界预测（视频场景动态）与动作执行绑定在相同的时间分辨率上，迫使视频分支建模密集的相邻帧变化，这些帧变化高度相关且对控制信息量弱，导致计算浪费，未能充分发挥视频分支在具身控制中的潜力。
- **核心动机**：作者认为视频世界模型应形成**时间上延展的潜在规划**（long-horizon latent plan），而动作模型应紧密耦合实时控制环，及时发出闭环修正。因此需要解耦两者的时间节奏，实现“慢世界规划 + 快动作执行”的异步架构。
- **整体意义**：AHA-WAM 是首个将双扩散 Transformer（DiT）异步解耦为低频世界规划器与高频动作执行器的模型，在不牺牲性能的前提下大幅提升闭环控制频率，为未来可部署的世界-动作模型开辟新方向。

## 2. 方法论：核心思想、关键技术细节

### 核心思想
- 将视频 DiT 实例化为**低频世界规划器**（low-frequency world planner），以较长时域（hv=64）建模场景演化，并维护可重用的逐层潜在上下文（planner video context）。
- 将动作 DiT 实例化为**高频动作执行器**（high-frequency action executor），以较短时域（ha=16）预测动作块，通过逐层联合注意力（layerwise joint attention）查询规划器上下文，实现闭环控制。
- 规划器上下文被多个动作更新阶段重用，避免每次动作都重新运行视频 DiT。

### 关键技术细节

1. **双 DiT 架构与逐层耦合**
   - 视频 DiT：接收视觉潜在令牌，在因果掩码下预测未来视频潜在（训练时），输出规划器上下文 `Cpτ = {(Kp,ℓ, Vp,ℓ)}`（每层 KV 对）。
   - 动作 DiT：接收噪声动作令牌和本体感觉令牌，通过联合注意力融合规划器上下文，去噪输出动作块。
   - 训练联合流匹配损失（flow matching）：`L = L_action + λ L_video`。

2. **观测引导视频上下文路由（OVCR）**
   - 为解决规划器上下文随执行推进而变陈旧的“上下文对齐”问题，OVCR 利用当前观测构建**分块特定的潜在查询**（chunk-specific latent queries）。
   - 通过注意力池化从当前视觉令牌中提取紧凑查询，再读取规划器 KV 并预测残差更新（ΔK，ΔV），通过门控残差更新得到适应后的上下文 `Ĉpt`。
   - 确保每个动作块都能获得与最新视觉证据对齐的规划器上下文，同时不将密集视觉令牌注入高频动作分支。

3. **自适应时域偏移训练（Horizon-Adaptive Offset Training）**
   - 在训练中随机偏移动作块起始位置（δ ~ U[0, ha)），使动作执行器学会在不同相位偏移下消耗规划器上下文，适应异步推理时规划器-执行器之间的任意相位关系。

4. **滚动规划器记忆（Rolling Planner Memory）**
   - 视频规划器内部维护一个 FIFO 滚动 KV 记忆（最多 6 帧），存储历史规划器刷新时的状态，扩展规划器的时域感受野，用于长时操作场景。

5. **推理优化**
   - 去除视频 DiT 的显式未来帧解码，仅保留上下文生成路径。
   - 使用 TensorRT、CUDA Graph 编译动作推理路径（10步 → 41.37 ms）。
   - 通过 ODE 蒸馏将动作采样步数从 10 压缩到 2 步（AHA-WAM-Flash → 17.56 ms, 56.95 Hz）。

- **性能**：在 RoboTwin 2.0 上，AHA-WAM 平均成功率 **92.80%**，超过所有基线（包括有预训练的 LingBot-VA 92.20%，Fast-WAM 91.83%），且 **无需任何机器人数据预训练**。
