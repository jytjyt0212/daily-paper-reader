## 摘要
离散视觉-语言-动作（VLA）模型通常将动作生成公式化为在离散动作空间上的下一个令牌预测，每个令牌以自回归方式依赖于先前上下文。虽然有效，但这种范式会带来高推理延迟，并且很大程度上忽略了动作轨迹中固有的时间结构。最近的工作引入并行解码以提高效率，实现更快的推理，但缺乏明确的令牌依赖关系建模机制。我们提出了TBD-VLA，一种基于离散令牌的VLA框架，它结合了块扩散以实现时序动作生成。我们将动作序列划分为时间块，并在每个块内执行掩码离散扩散，同时在块之间保持自回归生成。这种设计统一了时序自回归与并行动作解码，实现了强时序一致性和更快的推理速度。此外，显式的时序建模使得通过时序修复实现动作块（例如实时分块）的异步执行成为可能。TBD-VLA在仿真和真实世界的操作任务中显著优于先前的VLA方法，为构建快速、具有时序感知能力的离散VLA模型提供了一条可扩展的路径。项目网页：https://tbd-vla.github.io/

## Abstract
Discrete Vision-Language-Action (VLA) models typically formulate action generation as next-token prediction over discretized action spaces, conditioning each token autoregressively on prior context. While effective, this paradigm incurs high inference latency and largely ignores the temporal structure inherent in action trajectories. Recent efforts introduce parallel decoding to improve efficiency, enabling faster inference, but lack explicit mechanisms for modeling token dependencies. We introduce TBD-VLA, a discrete token-based VLA framework that incorporates block diffusion to enable temporal action generation. We partition action sequences into temporal blocks and perform masked discrete diffusion within each block, while maintaining autoregressive generation across blocks. This design unifies temporal autoregression and parallel action decoding, achieving both strong temporal coherence and improved inference speed. In addition, the explicit temporal modeling enables asynchronous execution of action chunks (e.g., Real-Time Chunking) via temporal in-painting. TBD-VLA significantly outperforms prior VLA approaches in both simulation and real-world manipulation tasks, offering a scalable path toward fast, temporally aware, discrete VLA models. ## 1. 核心问题与研究动机
**问题**：离散视觉-语言-动作（VLA）模型通常将动作生成视为离散动作空间上的自回归下一个token预测。这种范式虽然有效，但有两个主要缺陷：
- **高推理延迟**：自回归逐个生成动作token，在需要高频闭环控制的机器人场景中速度过慢。
- **忽略时间结构**：每个token独立依赖于先前上下文，缺乏对动作轨迹中固有时间依赖关系的显式建模。

**动机**：现有改进方向包括并行解码（如OpenVLA-OFT）以加速推理，但缺少对token间依赖关系的建模；或使用压缩动作表示减少token数量，但弱化了单个token与时间步的对应关系。TBD-VLA旨在结合并行解码的效率和显式时间依赖建模，提供一种快速、时间感知的离散VLA模型。

## 2. 方法论：核心思想与关键技术
**核心思想**：将动作序列划分为**时间块（temporal blocks）**，在每个块内进行**掩码离散扩散**（迭代预测被掩码的token），同时在块之间保持**自回归生成**。这种结构统一了时间级别的自回归与块内的并行解码，实现强时间一致性和更快推理。

**基本公式**：
- 动作序列概率分解为块自回归乘积：  
  p(a_{1:H_p} | o, g) = ∏_{k=0}^{K-1} p_θ(a_{km+1:(k+1)m} | o, g, a_{1:km})，其中m为块大小，K=H_p/m为块数。

**关键技术细节**：
- **模型骨干**：使用Qwen3-VL 2B，兼容任意VLM。添加掩码token、占位token、动作token。
- **动作离散化**：每个动作维度量化为N_b个bin，形成词汇表V。
- **训练过程**：
  - **时序级token shift**：当前块的目标被训练预测下一个块，对齐自回归目标。
  - **离散块扩散**：为每个块采样掩码概率t_{k,i}~U(0,1)，独立掩码每个token；反向过程预测干净token，损失为掩码位置的平均交叉熵。
  - **块级注意力掩码**：采用“加倍布局”技巧，将干净动作序列x^0和噪声序列x^t拼接，共享RoPE位置，自定义注意力掩码实现在单次前向中并行学习多个块。
- **推理过程**：
  - **按需解码**：只解码执行所需的动作块（K_exec = ⌈H_a/m⌉块）。
  - **前缀KV缓存**：缓存视觉、提示和已生成块的KV状态，避免重复计算。
  - **期望采样解码**：利用完整输出分布加权求和，而非取最大logit的离散token。
  - **实时分块（RTC）**：通过硬修复（hard in-painting）冻结先前生成的与推理延迟窗口对应的尾部动作，实现异步执行。

**损失函数**：掩码位置平均交叉熵，训练与修复任务一致。

## 7. 优点
1. **方法创新**：将离散块扩散引入VLA，首次在显式时间依赖建模与并行解码之间取得平衡。
2. **训练技巧高效**：时序级token shift和加倍布局注意力掩码使得单次前向传播可学习多个块，加速训练。
3. **推理优化全面**：结合按需解码、KV缓存、期望采样和RTC，实现低延迟（0.086~0.117秒）。
4. **实验广泛**：覆盖多个仿真和真实环境，包含多种扰动，验证了泛化性和鲁棒性。
5. **可扩展性**：方法不依赖特定VLM骨干，适用于任何VLM，为更大模型和更多数据留下空间。

## 8. 不足与局限
1. **对比不足**：真实世界仅与π0.5对比，缺乏与其他离散VLA（如Disc Diff VLA, UD-VLA）的直接比较。
