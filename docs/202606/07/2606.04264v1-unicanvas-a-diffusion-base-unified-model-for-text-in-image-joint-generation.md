## 摘要
近年来，统一视觉-语言模型在单一架构内同时处理多模态理解与生成方面取得了显著进展。尽管自回归视觉语言模型能够跨模态推理，但无法生成高质量图像。相比之下，扩散模型能生成逼真的视觉效果，但难以生成连贯的文本，这使得开发能够无缝处理视觉和文本生成的单一统一模型充满挑战。最近的研究表明，语言可以有效地嵌入到视觉表示中，使模型能够直接从图像中推理文本语义。为此，我们提出UniCanvas，这是首次尝试通过图像内文本生成来统一扩散模型以生成交错的多模态内容。扩散模型自然地捕捉共享像素画布上的变换，这可以视为视觉变化的世界模型。该模型不生成离散的文本标记，而是利用其固有的多模态嵌入空间，学习将语言表示为图像内部的视觉模式。这种设计使模型在图像合成过程中能够在单一像素画布内自然地“绘制”文本，实现无缝的多模态生成。实验表明，UniCanvas在性能上优于之前的统一模型，将基于扩散模型的图像内文本生成定位为一种有前途的统一多模态生成范式。

## Abstract
Recent years have seen remarkable progress in unified vision-language models handling both multimodal understanding and generation within a single architecture. While autoregressive VLMs can reason across modalities, they fail to generate high-quality images. In contrast, diffusion models produce photorealistic visuals yet struggle to generate coherent text, making it challenging to develop a single unified model that can seamlessly handle both visual and text generation. Recent advances suggest that language can be effectively embedded within visual representations, allowing models to reason about textual semantics directly from images. To this end, we propose UniCanvas, a first attempt that unifies diffusion models to generate interleaved multimodal contents through text-in-image generation. Diffusion models naturally capture transformations on a shared pixel canvas, which can be viewed as world models of visual change. Instead of producing discrete text tokens, the model learns to represent language as visual patterns inside images, leveraging its inherent multimodal embedding space. This design allows the model to "draw" text naturally within a single pixel canvas during image synthesis, achieving seamless multimodal generation. Experiments demonstrate that UniCanvas improves performance over previous unified models, positioning text-in-image generation with diffusion models as a promising unified multimodal generation paradigm.

## 1. 核心问题与整体含义

- **研究动机**：现有统一视觉语言模型（VLM）存在根本性矛盾——自回归VLM擅长跨模态推理，但生成图像质量低；扩散模型能生成逼真图像，却难以生成连贯文本。当前统一模型仍将文本和图像生成视为分离任务，导致目标差距、表示差距和推理差距。
- **核心问题**：如何在单一架构中无缝整合文本与图像的生成，使两者在同一过程中相互影响、协同进化。
- **整体含义**：提出一种全新的范式——**文本-图像联合生成**，将语言视为像素空间中的视觉图案，在同一画布上同时“写”和“画”，有望统一多模态生成。

## 2. 方法论

### 2.1 核心思想
- 采用**共享像素画布**：文本和图像共享同一潜在空间，扩散模型在像素画布上逐步优化，语言被表示为光学文字图案，而非离散标记。
- 将扩散模型视为**视觉变化的世界模型**：通过条件变换更新画布状态，实现多步推理。

### 2.2 关键技术细节

#### (1) 文本-图像生成（Text-in-Image Generation）
- 基于**流匹配（Flow Matching）**：对输入图像x和目标文本嵌入图像x^{text}_0，采样t~U[0,1]构造线性插值x_t=(1-t)x+t x_1，训练速度网络v_θ预测真实速度v_t=x_1-x_0。
- 损失函数：L^{text}_{FM} = E[||v_θ(x_t, t, c_{reason}) - (x^{text}_0 - x)||²]

#### (2) 两阶段生成（Two-Stage Generation）
- **阶段1（视觉推理）**：在画布上“书写”语义文本，使用推理提示c_{reason}，生成带光学文字注释的中间画布ŷ^{text}。
- **阶段2（视觉合成）**：将中间画布变换为下一状态图像，使用执行提示c_{exec}。
- 多步任务：将前一阶段的输出ŷ^{state}反馈为新的输入，重复两阶段过程。

#### (3) CLIP对齐正则化
- 使用冻结的CLIP模型，对中间画布ŷ^{text}的视觉编码与文本提示c_{reason}的文本编码施加对比损失，增强文本可读性和语义一致性。
- 总损失：L_{total} = L^{text}_{FM} + L^{state}_{FM} + λ_{CLIP} L_{CLIP}

#### (4) 预训练
- 在LLaVA-Instruct-150K和OmniEdit数据上混合训练，添加**感知损失（LPIPS）** 稳定文字渲染，使模型具备基础文字绘制能力。

- **通用推理任务**：CocoQA（开放问答）和Visual7W（多项选择），各200样本。

## 6. 主要结论与发现

- UniCanvas在VSP上平均成功率0.77，显著优于所有统一模型基线（最高仅0.24），甚至超越Qwen2.5-VL-3B（0.72）和GPT-4o零样本（0.46）。
- 两阶段生成显著优于单阶段（消融验证），CLIP对齐损失和预训练均带来明显提升。
- 在视觉质量上，UniCanvas保持高水平DINO和CLIP相似度（Recipe: 56.01 DINO, 79.95 CLIP；RLBench: 80.72 DINO, 89.79 CLIP）。
- 代理实验（使用真实状态）表明，若消除视觉误差累积，UniCanvas可达与Qwen2.5-VL-7B竞争的性能（0.84 vs 0.89），说明文本-图像范式本身具有较强推理潜力。
- 案例揭示模型具备自我修正能力，能够从错误像素状态中恢复并最终完成目标。
- 在多步长滚动中，误差累积仍是主要限制，尤其在大网格（6×6）上性能下降明显（0.57）。

## 7. 优点

- **范式创新**：首次提出纯扩散模型实现文本-图像联合生成，消除模态鸿沟，无需外部VLM或离散文本解码器。
- **架构优雅**：单一扩散骨干同时承担推理与生成，共享像素画布自然支持多步任务。
- **设计合理**：两阶段解耦（先写后画）降低学习难度，CLIP对齐和预训练有效提升文本渲染质量。
- **实验扎实**：涵盖多领域（导航、烹饪、机器人）、多难度、定量+定性分析，消融清晰。
- **分析深入**：不仅报告平均性能，还分析了误差累积、自我修正、真实状态上限等，揭示模型特性。
- **泛化潜力**：在通用推理任务上初见成效（CocoQA 0.58，Visual7W 0.78），说明范式可延伸至更广范围。

## 8. 不足与局限

- **长程推理能力不足**：多步滚动中误差累积严重，尤其是6×6网格，状态预测一旦偏离即导致轨迹崩溃。
- **文本生成质量有限**：长句或多句子答案易出现文字混乱、字符幻觉、复制问题等（如图10所示）。
- **推理速度较慢**：每步两阶段扩散（共80步），推理时间约为VLM的4.6倍（VMoT为5.1倍），但优于其他扩散序列模型。
- **预训练数据规模受限**：仅混合LLaVA-150K和OmniEdit，未使用更大规模的文本-图像合成数据，可能导致文字渲染多样性和鲁棒性不足。
- **通用任务评估样本少**：仅200个样本，统计显著性可能不够。
- **未与其他扩散统一模型全面对比**：未与JanusFlow、Transfusion等同类架构直接比较。
- **应用限制**：实际部署中，长时间稳定生成仍需改进状态更新模块；固定画布区域设计可能无法适应高度动态场景。
