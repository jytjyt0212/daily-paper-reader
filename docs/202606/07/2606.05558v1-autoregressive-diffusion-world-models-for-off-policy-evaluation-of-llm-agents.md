## 摘要
在多轮交互环境中评估大型语言模型（LLM）智能体成本高昂且具有风险，因为这需要在线环境交互。我们提出ADWM（自回归扩散世界模型），这是一个评估框架，仅从预先收集的轨迹中估计新LLM智能体策略的性能。核心思想是学习一个潜在扩散世界模型，模拟环境如何响应评估策略，而无需在真实环境中执行该策略。现有的基于扩散的OPE方法通过联合扩散状态和动作一次性指导完整轨迹，这一假设对于LLM智能体而言不成立，因为其动作是离散文本，必须在观察环境后从策略中采样。与遭受复合误差的自回归世界模型不同，ADWM将每个转移建模为独立的去噪过程，实现可靠的逐步 rollout，其中世界模型和智能体以因果顺序交替。关键是，被评估的LLM智能体通过策略条件得分函数直接引导每一步的扩散生成，确保模拟轨迹准确反映其决策模式。实验表明，ADWM在多样化的多轮智能体任务中实现了准确的价值估计和评估可靠性，展示了其作为离线LLM智能体评估实用框架的潜力。

## Abstract
Evaluating large language model (LLM) agents in multi-turn interactive environments is expensive and risky, as it requires online environment interaction. We propose ADWM (Autoregressive Diffusion World Model), an evaluation framework that estimates the performance of a new LLM agent policy purely from pre-collected trajectories. The core idea is to learn a latent diffusion world model that simulates how the environment responds to the evaluation policy, without ever executing it in the real environment. Existing diffusion-based OPE methods guide full trajectories in a single pass by jointly diffusing states and actions, an assumption that breaks down for LLM agents whose actions are discrete text that must be sampled from the policy after observing the environment. Unlike autoregressive world models that suffer from compounding errors, ADWM models each transition as an independent denoising process, enabling reliable step-by-step rollouts where the world model and agent alternate in causal order. Crucially, the LLM agent under evaluation directly guides the diffusion generation at each step via a policy-conditioned score function, ensuring that simulated trajectories accurately reflect its decision-making patterns. Empirically, ADWM achieves accurate value estimates and evaluation reliability across diverse multi-turn agent tasks, demonstrating its promise as a practical framework for offline LLM agent evaluation.

## 1. 核心问题与整体含义（研究动机与背景）

**问题：** 在线评估LLM智能体（多轮交互环境）成本高昂、风险大，需要实际执行策略，消耗API预算且可能产生不可逆副作用。离线策略评估（OPE）旨在仅从预先收集的轨迹中估计新策略的价值，但现有方法存在根本性挑战：

- 重要性采样（IS）方法中，似然比随轨迹长度指数增长，在LLM的高维离散动作空间中不实用。
- 基于价值的方法（如FQE）在评估策略与行为策略差异大时遭受复合偏差。
- 现有扩散OPE方法（如Policy-Guided Diffusion）假设动作是连续实数向量，可联合扩散状态和动作；但LLM智能体的动作是离散文本，必须在观察到环境后才能由策略采样，导致循环依赖，无法直接应用。
- 自回归世界模型（如Transformer）逐token生成观察，误差在单步内累积并跨步复合，不利于长周期任务。

**整体含义：** 作者提出ADWM（Autoregressive Diffusion World Model），利用扩散模型将每个环境转移建模为独立去噪过程，避免复合误差，并通过策略条件得分函数让评估策略在每一步引导生成，实现可靠的自回归模拟，从而从纯离线数据中准确估计新策略的价值。

## 2. 方法论：核心思想、关键技术细节与公式流程

### 核心思想
- 将策略引导的轨迹分布精确分解为一系列单步条件分布的乘积（Theorem 1），每个单步条件由三个因子组成：先验、动作后验、策略延续因子。
- 该分解对应一个导向扩散过程，评估策略通过其对数似然梯度影响每一步去噪，无需重新训练世界模型。
- 由于每个转移是独立的去噪过程，误差不会跨步累积。

### 关键技术细节

1. **策略引导的轨迹定律**（公式2）：

2. **定理1：融合的单步条件**（公式5）：

   \]
   - 先验：将生成锚定到离线数据支持域。
   - 动作后验：注入当前步动作信息，通过无分类器指导（CFG）实现，\(\omega = 1 + \lambda\)。
   - 策略延续：通过期望
     \[
     C_\alpha(o_{t+1}; h_t, a_t, \pi_e) = \mathbb{E}_{\tau_{t+1:T} \sim p_\theta(\cdot | h_t, a_t, o_{t+1})} \left[ \exp\left( \alpha \sum_{u=t+1}^T \log \pi_e(a_u | h_u) \right) \right]

3. **导向得分函数**（公式9）：

   - 前两项通过无分类器指导实现（公式8）。

   - 编码器\(E\)将观察映射为潜在\(z_t \in \mathbb{R}^d\)，与扩散世界模型端到端联合训练。

## 6. 主要结论与发现

1. **ADWM在所有测试配置中一致为正的Spearman秩相关系数**（平均+0.82，最小+0.67），而每个经典基线在至少三个配置中失败（出现负相关或零相关）。
2. **ADWM优于次优基线（FQE）平均+0.34**，且不需要重要性权重或线性归纳偏差。
3. **三个核心组件（局部CFG、延续指导、\(\psi\)-适配器）均至关重要**：每个组件在不同奖励机制中占主导，移除任意一个都会导致至少一个环境性能严重下降。
4. **训练收敛稳定**：所有损失分量在50轮内稳定收敛。
5. **行为数据多样性和潜在容量是关键前提**：在WebShop上，降低行为池多样性或减半潜在维度会导致排序完全反转。

## 7. 优点

- **理论严谨**：从重要性采样自然推广到未知行为策略，通过定理1给出精确的单步条件分解，并映射到可实现的导向扩散过程。
- **解决核心难题**：1）避免复合误差（独立去噪）；2）处理离散文本动作（因果自回归生成）；3）利用评估策略引导去噪而不需要重新训练。
- **实用性强**：训练一次世界模型后，可评估任意新策略（\(\psi\)-适配器需对跨家族评估重新训练，但单家族内零成本）。
- **可解释性**：三个因子（先验、动作后验、延续）有直观含义。
- **实验设计扎实**：覆盖多种奖励结构、多种后训练方法，与多个基线公平对比，消融充分，提供开箱即用的实现和附录详细信息。

## 8. 不足与局限

### 论文明确指出的局限（Appendix A）
1. **受限于地面真实质量**：例如在WebShop上，成功率的二项标准误差（~7%）与相邻LEAP迭代间的差距（3-19%）相当，导致更精细的跨迭代区分需要更多地面真实episode。
2. **\(\psi\)-适配器与评估LLM嵌入空间绑定**：若要评估跨家族模型（如Llama训练的世界模型评测Qwen），需要一次性的适配器重训练。

### 其他潜在局限
- **行为多样性假设**：实验表明，若行为池缺乏多样性（单模型），ADWM会完全失效（ρ降至-1.0）。实际中可能需要足够多的异构行为数据。
- **仅测试了\(\varepsilon\)-greedy退化族**：未验证在完全不同的策略（如完全不同架构、任务）下的排序能力，现实场景中策略差异可能更大。
- **计算开销**：虽然世界模型训练轻量，但推理时每一步都需要多步扩散去噪（50步），且需要调用LLM获取动作和对数似然梯度，导致总耗时可能较长（每配置15-45分钟）。
- **依赖LLM的概率接口**：延续指导需要\(\pi_e\)返回精确的对数似然，但许多商用LLM API不提供此信息，限制了实用性。
- **经验评估未覆盖随机性影响**：5种子下的Spearman方差在某些稀疏奖励环境下较大（如ALFWorld-iter3标准差0.64），说明不稳定。
