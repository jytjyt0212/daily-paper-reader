## 摘要
导航与操作是具身智能的基础能力，使机器人能够理解自然语言指令并与周围环境进行物理交互。然而，当前的视觉-语言-动作（VLA）模型仍然受限于任务特定的架构，专门处理导航或操作，这阻碍了通用机器人智能体的发展。为弥补这一差距，我们提出OneVLA，一种统一架构，将这些不同的任务整合到一个内聚的框架中。具体而言，我们设计了一个统一动作头，能够生成导航和操作动作，无需任务特定变体。此外，我们提出了一种多阶段渐进训练策略——结合精心构建的数据集和思维链（CoT）微调——促进了两个领域之间的强正迁移和相互增强。在模拟和真实环境中的大量实验表明，OneVLA达到了最先进的性能，显著优于专门的单任务模型和现有的跨任务模型。通过统一这些核心能力，OneVLA为真正的通用机器人系统铺平了道路。模型和源代码将公开发布。

## Abstract
Navigation and manipulation are fundamental capabilities of embodied intelligence, enabling robots to interpret natural language commands and interact physically with their surroundings. However, current Vision-Language-Action (VLA) models remain constrained by task-specific architectures, specializing in either navigation or manipulation, which hinders the development of general-purpose robotic agents. To bridge this gap, we introduce OneVLA, a unified architecture that integrates these distinct tasks into a single, cohesive framework. Specifically, we design a unified action head capable of generating both navigation and manipulation actions without requiring task-specific variants. Furthermore, we propose a multi stage progressive training strategy-incorporating curated data construction and Chain-of-Thought (CoT) fine-tuning that facilitates strong positive transfer and mutual reinforcement between the two domains. Extensive experiments in both simulated and real-world environments demonstrate that OneVLA achieves state-of-the-art performance, significantly outperforming both specialized single-task and existing cross-task models. By unifying these core capabilities, OneVLA paves the way for truly general-purpose robotic systems. The model and source code will be publicly released.

## 2. 方法论：核心思想、关键技术细节

### 2.1 核心思想
- **统一架构**：OneVLA是一个统一的VLA框架，在同一模型内既能生成导航动作（离散命令），也能生成操作动作（连续7自由度末端执行器控制），无需切换或特定模型变体。
- **核心创新**：设计了**统一动作头（Unified Action Head）**，将导航和操作的动作维度拼接成11维统一动作空间（4维导航 + 7维操作），并通过任务特定权重掩码在训练时独立计算损失。
- **多阶段渐进训练策略**：分三阶段逐步引入任务复杂度和跨任务知识迁移，最终实现相互增强。

### 2.2 关键技术细节

#### 统一动作头
- 动作空间：`a_unified = [a_navi | a_mani] ∈ ℝ¹¹`，其中：
  - 导航动作：`a_navi ∈ ℝ⁴`，离散命令的概率分布 `[p_forward, p_turn_left, p_turn_right, p_stop]`
  - 操作动作：`a_mani ∈ ℝ⁷`，连续7自由度末端执行器控制 `[Δx, Δy, Δz, Δroll, Δpitch, Δyaw, g]`
- 采用**流匹配扩散过程**（Flow-Matching）预测未来动作序列：从噪声采样，通过插值构造噪声轨迹，模型预测速度场`v_θ = a_gt - ε`，优化流匹配目标。推理时使用欧拉积分逐步去噪。
- 任务特定权重掩码：对每个样本计算动作损失时，使用`w_τi`（导航或操作掩码）对相关维度赋予高权重，对填充维度赋予近零权重，实现联合训练。

#### 输入输出
- 每个时间步`t`，输入：多视角RGB图像`o_t`、自然语言指令`l_t`、可选机器人状态`r_t`。
- 输出：文本响应`y_t`（解释理解）和未来动作序列`a_{t:t+T}`。使用特殊标记`<text>...</text><action>...</action>`在单次前向中区分语言生成和动作生成阶段。

#### 多阶段训练
- **第一阶段（建立操作能力）**：仅使用操作数据集和通用视觉问答（VQA）数据集，损失函数为`λ_vlm L_vlm + λ_action L_mani_action`。
- **第二阶段（发展导航能力）**：引入导航数据，与操作和VQA数据联合训练，损失函数为`λ_vlm L_vlm + λ_action (L_navi_action + L_mani_action)`。
- **第三阶段（增强跨任务性能）**：加入思维链（CoT）数据，监督文本生成，损失函数为`λ_vlm L_vlm + λ_text L_text + λ_action (L_navi_action + L_mani_action)`。

#### 损失函数
总损失：`L_total = λ_vlm L_vlm + λ_text L_text + λ_action L_action`
- `L_vlm`：通用VLM交叉熵损失，保持视觉语言对齐。
- `L_text`：具身任务样本的语言推理下一个词预测损失。
- `L_action`：流匹配损失，使用任务特定权重掩码。

#### 视觉语言编码器
- 视觉编码器：32层Vision Transformer，隐藏维度1280，空间合并（merge size=2），提取分层视觉特征。
- 语言模型：36层Transformer，16个注意力头、2个KV头（GQA），隐藏维度2048。
- 总体：Qwen2.5-VL-3B-Instruct作为统一视觉语言骨干。

#### 其他细节
- 动作预测时的动作视野（Action Horizon）默认=5（经消融实验确定最优）。
- 训练时任务采样比例：导航:操作 = 6:4。
- 损失权重：`λ_action=1, λ_text=λ_vlm=0.1`。
- 优化器：AdamW，学习率：基础模型4e-5，视觉语言接口1e-5，动作模型1e-4。

## 3. 实验设计

### 3.1 模拟环境 Benchmark

- **导航任务**：VLN-CE基准，使用R2R和RxR数据集，在Habitat模拟器中连续动作空间，评估val unseen集，主要指标：oracle成功率（OSR）。
- **操作任务**：SimplerEnv-Bridge基准，使用WidowX机械臂，四个代表性任务：“Put Spoon on Towel”、“Put Carrot on Plate”、“Stack Green Block on Yellow Block”、“Place Eggplant in Yellow Basket”。每个任务运行24次独立试验，报告成功率及平均成功率。
- **真实世界实验**：操作任务用Franka Research 3机械臂（4个任务×20次），导航任务用移动机器人平台（4个场景×10次）。报告平均成功率。

### 3.2 对比方法

## 6. 主要结论与发现

1. **统一架构有效**：OneVLA在同一模型内（无需任务特定变体）同时在导航和操作任务上达到SOTA性能，证明了统一架构的可行性。
2. **显著优于现有方法**：对比UniVLA（7B，跨任务基线），OneVLA（3B）在VLN-CE R2R上提升21.5%（68.6% vs 47.1%），在RxR上提升31.9%（58.2% vs 26.3%），在SimplerEnv上提升29.1%（64.5% vs 35.4%）。对比单任务SOTA，也分别有4.6%（导航）和16.2%（操作）的改进。
3. **跨任务联合训练相互促进**：消融实验显示，联合训练比单独训练各任务提升显著：R2R +7.3%，RxR +9.3%，SimplerEnv +5.5%。证实导航与操作可以互相受益。
4. **多阶段渐进训练优于单阶段**：三阶段策略比一次性训练提升12.5%（R2R）、15.3%（RxR）、18.3%（SimplerEnv）。
5. **动作视野最优值为5**：过长（6-8）或过短（2-4）均导致性能下降。
6. **真实世界泛化强**：在真实机器人实验中，操作成功率78.8%（超UniVLA 16.3%），导航成功率77.5%（超UniVLA 35.0%）。

## 7. 优点

- **架构创新**：统一动作头设计简洁有效，无需任务特定变体即可处理离散和连续混合动作空间，是核心亮点。
