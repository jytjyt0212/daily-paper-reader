## 摘要
流模型和扩散模型能在多种模态下生成高质量样本；然而，由于需要对底层微分方程进行数值积分，推理过程中需要大量网络评估。流映射通过直接学习微分方程的解映射来缓解这一问题，从而实现少步采样。然而，当前方法仅限于逼近常微分方程的解映射。这些方法可用于学习随机微分方程的转移核，从而得到一个恢复过程边缘分布（弱收敛）而非解路径（强收敛）的解映射。我们提出强随机流映射（SSFMs）作为学习加性噪声随机微分方程强解映射的新框架，直接将确定性流映射推广到随机设置。此外，我们引入了布朗运动的多项式近似，并证明其路径收敛。这些结果为扩散模型的解映射提供了一种无模拟的训练目标。我们证明SSFMs在图像生成上优于先前的随机流映射方法，并实现了分子系统的少步采样。

## Abstract
Flow and diffusion models generate high-quality samples in many modalities; however, many network evaluations are required during inference due to numerical integration of an underlying differential equation. Flow maps alleviate this problem by learning the solution map of the differential equation directly, enabling few-step sampling. Yet, current methods are restricted to approximating the solution map of ODEs. These methods can be used to learn the transition kernel of an SDE, thereby obtaining a solution map that recovers the marginal distributions of the process (weak convergence) rather than the solution path (strong convergence). We propose Strong Stochastic Flow Maps (SSFMs) as a novel framework for learning the strong solution map of additive-noise SDEs, directly generalizing deterministic flow maps to the stochastic setting. Further, a polynomial approximation to Brownian motion is introduced and shown to converge pathwise. These results enable a simulation-free training objective for the solution map of diffusion models. We demonstrate that SSFMs outperform previous stochastic flow map methods on image generation and enable few-step sampling of molecular systems.

## 1. 核心问题与整体含义（研究动机和背景）

- **问题背景**：扩散模型和流匹配模型在多种模态生成中表现优异，但推理时需要对底层微分方程进行数百次数值积分（每次积分需一次网络评估，即NFE），导致计算开销大。近期提出的**流映射（Flow Maps）** 通过学习微分方程的**解映射**（solution map）实现少步采样（如2-4步），但这些方法仅限于常微分方程（ODE），无法直接处理随机微分方程（SDE）。

- **现有方法的局限**：可近似SDE转移核的弱随机流映射（如Diamond Map、GLASS）只恢复边缘分布（弱收敛），不提供路径解（强收敛），因此无法用于路径依赖的可观测量的估计，也与底层SDE解路径脱钩。

- **本文贡献**：提出**强随机流映射（Strong Stochastic Flow Maps, SSFMs）**，首次将确定性流映射推广到加性噪声SDE，学习其**强解映射（Itô映射）**，实现**路径一致**的少步采样；同时引入布朗运动的**多项式逼近**并证明其路径收敛，从而获得扩散模型的**无模拟训练**目标。

## 2. 提出的方法论

### 核心思想
- 定义加性噪声SDE: dXt = f(t,Xt) dt + g(t) dWt。其Itô映射 Ψs,t : (Xs, W[s,t]) → Xt 既依赖于初始状态，也依赖于完整的布朗路径实现。SSFMs用神经网络参数化该映射。

### 关键技术细节
1. **参数化形式**（欧拉-丸山步结构）：
   Ψθs,t(Xs, I(N)s,t) = Xs + fθs,t(Xs,I(N)s,t)(t-s) + gθs,t(I(N)s,t)(Wt-Ws)
   其中 I(N)s,t 是布朗路径的多项式系数，Wt-Ws = I(0)s,t。

2. **布朗运动的多项式逼近**：
   - 基于移位勒让德多项式展开，系数独立正态分布：I(n)s,t ~ N(0, (t-s)/(2n+1) I)。
   - 证明在α-赫尔德距离下路径收敛（α∈[0,1/2)），且具有闭式Chen关系，用于半群条件中系数合并。

3. **训练目标**（Theorem 3.5）：
   - 包含两部分：**匹配损失** Lf,g 强制对角系数等于真实SDE的漂移和扩散；**蒸馏损失** LD 强制半群一致性，即单步预测等于两步组合预测。
   - 实际训练中（Algorithm 1）：采样s~U[0,1]，用小步长欧拉-丸山匹配漂移和扩散，再用大步长蒸馏强化半群性质。使用指数移动平均（EMA）更新目标网络。

## 6. 主要结论与发现

- SSFMs在图像生成上**优于所有弱随机流映射**，与最优确定性流映射相当或更好（如CIFAR-10 8步FID 3.29 vs LSD的3.33）。
- 在分子系统中，SSFMs仅需**1-2步**即可获得准确样本，而扩散基线需要1000步才能达到可比性能；在100步时SSFMs即匹配基线1000步。
- 验证了**强收敛性质**：固定初始状态和布朗路径，不同步数下输出一致；改变路径则输出不同，保持随机性。
- 多项式逼近随着阶数增加强收敛误差降低，N=4时仍未饱和。

## 7. 优点

- **理论创新**：首次将流映射从ODE推广到SDE的强解，数学严谨（基于粗糙路径理论）。
- **实用高效**：训练无模拟（simulation-free），推理可少至1-2步；多项式近似使输入维度低且具有闭式Chen关系，便于实现半群蒸馏。
- **性能优越**：在图像和分子任务上均优于或持平最先进的少步方法。

## 8. 不足与局限

- **适用范围**：当前框架仅针对**加性噪声SDE**，扩展到状态相关扩散（乘性噪声）的理论已提出但未实验验证。
- **参数调节**：多项式阶数N需作为超参数调优；实验中N=3或4，但未见对高维或长时步的敏感性分析。
- **图像分辨率**：仅实验在CIFAR-10/32×32和CelebA-64/64×64，未验证更高分辨率，可能无法直接推广。
- **与弱流映射的对比**：弱流映射方法主要面向扩散模型SDE，SSFMs是更通用的框架，但分子任务中未与弱流映射直接对比（因为后者未在分子上报告）。
- **理论复杂性**：部分证明（如粗糙路径收敛）较为数学化，可能增加复现门槛。
