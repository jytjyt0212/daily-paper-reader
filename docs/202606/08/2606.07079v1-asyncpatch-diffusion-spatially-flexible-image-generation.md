## 摘要
标准扩散模型以单一共享噪声水平破坏整个样本，强制所有空间区域遵循相同的去噪轨迹。我们引入异步斑块扩散（AsyncPatch Diffusion），这是一种联合扩散框架，为不同的输入维度（如图像像素或潜在令牌）分配不同的噪声水平。我们展示了这种异步破坏如何定义有效的生成过程，同时支持更丰富的空间异质去噪轨迹族，并证明了该过程的第一个有效ELBO。我们证明，单个预训练模型可以执行空间自适应生成，其中不同区域按不同调度进行去噪。一个关键挑战是训练：朴素的独立噪声水平采样过度强调高度异质的配置，而低估了同质噪声水平，而后者在采样过程中至关重要。我们通过一个受控噪声水平采样器来解决这个问题，该采样器调节平均破坏水平及其空间变异性。AsyncPatch在ImageNet 256和LSUN上实现了与常规扩散相当的生成质量，同时天然适用于修复任务而无需任务特定的微调。我们进一步引入了输入引导，利用干净或部分损坏的区域来指导未知区域的生成，改善局部一致性和纹理匹配。最后，我们展示了自适应生成策略，包括不确定性引导的加速和自回归采样。

## Abstract
Standard diffusion models corrupt an entire sample with a single shared noise level, forcing all spatial regions to follow the same denoising trajectory. We introduce AsyncPatch Diffusion, a joint-diffusion framework that assigns distinct noise levels to different input dimensions, such as image pixels, or latent tokens. We show how this asynchronous corruption defines a valid generative process while supporting a richer family of spatially heterogeneous denoising trajectories, and prove the first valid ELBO for this process. We show that a single pretrained model can perform spatially adaptive generation, where different regions are denoised on different schedules. A key challenge is training: naive independent noise-level sampling overemphasizes highly heterogeneous configurations and underrepresents homogeneous noise levels, that are crucial during sampling. We address this with a controlled noise-level sampler that regulates both the average corruption level and its spatial variability. AsyncPatch achieves generation quality comparable to conventional diffusion on ImageNet 256 and LSUN, while being natively suited for inpainting without task-specific fine-tuning. We further introduce input guidance, which uses clean or partially corrupted regions to guide the generation of unknown regions, improving local consistency and texture matching. Finally, we demonstrate adaptive generation strategies including uncertainty-guided acceleration and autoregressive sampling.

## 1. 核心问题与整体含义（研究动机和背景）

标准扩散模型对所有像素（或潜在 token）使用**同一全局噪声水平**，导致所有空间区域被迫遵循完全相同的去噪轨迹。这种同步约束限制了模型在空间上的灵活性，无法对不同区域按需调整生成过程（例如在图像修复中只对缺失区域去噪，或让不同区域以不同速度生成）。

本文提出 **AsyncPatch Diffusion**，一种**空间灵活的联合扩散框架**，允许为输入的不同维度（像素级或潜在 token 级）分配**独立且不同的噪声水平**，从而支持更丰富的空间异质去噪路径。该工作旨在统一标准生成、图像修复、自适应采样等任务，无需针对特定任务进行模型微调或架构修改。

## 2. 方法论：核心思想、关键技术细节

### 2.1 联合扩散框架
- 将数据分解为 N 个 token（如像素），每个 token 对应一个独立的时间变量 \( t_i \in [0,1] \)。
- 前向过程：对每个 token 按各自时间 \( t_i \) 添加独立高斯噪声，即 \( q(z_t|x) = \prod_i \mathcal{N}(\alpha_{t_i} x_i, \sigma^2_{t_i} I) \)。
- 反向过程：由一个共享的神经网络 \( s_\theta(z_t; t) \) 联合预测所有 token 的分数，训练目标为 Fisher 散度。

### 2.2 理论贡献
- **Lemma 1**：证明任何全局最小化器都能恢复正确的联合分数 \( \nabla_{z_{i,t_i}} \log p(z_t, t) \)，从而生成目标分布。
- **Theorem 1**：首次为联合扩散推导出有效的**证据下界（ELBO）**，通过单调随机行走和随机环境平均得到显式权重 \( \lambda_i(t) \)。

### 2.3 训练时的噪声水平采样
- **问题**：独立均匀采样会导致训练分布与推理分布严重不匹配——模型过多看到平均噪声约 0.5 的局部异质状态，而极少见到全局干净/全局噪声/清晰-噪声分块结构。
- **解决方案**：设计**受控噪声水平采样器（AsyncPatch sampling）**，明确控制两个关键因素：
  - 全局平均噪声水平 \( \bar{t} \)（控制整体信息量）
  - 空间变异程度 \( \Delta \)（控制同步 vs 异步程度）
- 具体流程：采样 \( \bar{t} \sim U(t_{\min}, t_{\max}) \)，确定最大对称区间 \( [\bar{t}-\delta, \bar{t}+\delta] \)，再将图像分块，每块独立从该区间采样。同时对比了 Perlin 采样（类似 RAD）和 Patchwise 采样（各块独立均匀采样）。

### 2.4 推理时的空间噪声调度
- 定义空间噪声调度 \( \tau(u) = \{\tau_1(u),..., \tau_N(u)\} \)，每个 token 随时间 \( u \) 单调递减。
- **标准生成**：所有 token 共享同一调度。
- **图像修复**：已知区域保持 \( \tau_i=0 \)，未知区域从 1 到 0 去噪。
- **自回归生成**：将 token 分组，逐组生成（先产生的组保持干净，后产生的组保持噪声）。

### 2.5 输入引导（Input Guidance）
- 利用干净或部分损坏区域的信息，引导未知区域的生成。
- 比较同一 token 在两个不同噪声水平（较干净 vs 较噪声）下的分数估计，通过推离噪声预测来增强局部一致性。
- 可与分类器无关引导（CFG）组合使用。

## 6. 主要结论与发现

1. **异步扩散有效**：AsyncPatch 框架可训练出既能保持标准生成质量（FID 与基线相当或略优），又能零样本执行图像修复（性能优于或持平 RePaint 等零样本方法）的模型。
2. **时间步采样至关重要**：AsyncPatch 采样策略（控制平均噪声和变异程度）显著优于独立均匀采样和单纯 Patchwise 采样，在生成与修复之间取得良好平衡。
3. **输入引导改善局部一致性**：输入引导能有效推动模型匹配已知区域的纹理和细节，在纹理合成任务中比同类扩散方法更忠实于示例纹理。
4. **自适应采样潜力**：不确定性引导加速和自回归生成展示了空间灵活调度带来的额外能力，尽管生成质量有损但无结构性伪影。

## 7. 优点

1. **理论创新**：首次为联合扩散推导出有效 ELBO（Theorem 1），为异步噪声水平提供了严格的变分基础。
2. **统一框架**：同一模型无需微调即可支持标准生成、图像修复、外推、自回归生成等多种任务，简化了部署。
3. **实用采样方法**：AsyncPatch 采样器有效解决了训练-推理分布不匹配问题，是工程上的关键贡献。
4. **输入引导新颖**：类比 classifier-free guidance，但利用输入自身不同噪声水平的分数差异来增强条件性，对纹理保持特别有效。
5. **实验翔实**：在多个主流数据集上与多种基线对比，消融充分，并对隐空间与像素空间的差异性进行了说明。

## 8. 不足与局限

1. **架构局限**：所有实验使用 UNet，未在 Transformer 扩散架构（如 DiT）上验证，异步调度与注意力机制的结合效果未知。

4. **缺少文本条件实验**：未在文本引导生成/修复场景中验证，而当前主流应用多依赖文本条件。
