## 摘要
世界动作模型（WAMs）通过联合建模视觉状态转换和机器人动作，为机器人操作提供了一种有前景的范式。然而，现有的WAMs受限于有限的时间上下文、粗粒度的片段级语言监督以及主要以文本为条件的设置，这阻碍了任务进度追踪和细粒度语言-视频-动作对齐，同时限制了视觉上下文推理和跨实体迁移。本文提出了WorldScape Policy 2.0，一种具有推理增强长短时记忆的可控WAM。其因果短时视觉记忆提供最近的观测作为DiT前缀输入，以保留局部交互动态；而其长短时事件记忆将历史VLM输出组织为全局历史、局部活跃和事件边界表示，用于进度感知的检索。检索到的历史信息增强了感知和自回归生成的规划令牌，为自主规划提供了隐式的子目标条件；语义强制进一步将事件级指令语义注入这一潜在规划路径。为了建立细粒度的多模态可控性，我们构建了Event-5M，一个基于事件的具身预训练数据集，包含近500万个事件片段，配准的动作轨迹、片段级任务指令、片段级子任务描述、目标图像和视频演示。这些设计为从高级指令进行自主规划以及从细粒度文本、目标图像或视频上下文提示进行可控执行提供了统一接口。在仿真和真实世界平台上的实验展示了其在长程自主规划、细粒度指令遵循和上下文适应方面的优越能力。

## Abstract
World Action Models (WAMs) offer a promising paradigm for robotic manipulation by jointly modeling visual state transitions and robot actions. However, existing WAMs are constrained by limited temporal context, coarse episode-level language supervision, and predominantly text-only conditioning, which hinder task-progress tracking and fine-grained language-video-action grounding while limiting visual-context reasoning and cross-embodiment transfer. In this paper, we introduce WorldScape Policy 2.0, a controllable WAM with reasoning-augmented long short-term memory. Its causal short-term visual memory supplies recent observations as DiT prefill to preserve local interaction dynamics, while its long short-term event memory organizes historical VLM outputs into global-history, local-active, and event-boundary representations for progress-aware retrieval. The retrieved history augments perception and autoregressively generated planning tokens, yielding an implicit subgoal condition for autonomous planning; semantic forcing further transfers event-level instruction semantics into this latent planning pathway. To establish fine-grained multimodal controllability, we construct ManipEvent-5M, an event-grounded embodied pretraining dataset containing nearly 5 million event segments with aligned action trajectories, episode-level task instructions, segment-level subtask captions, goal images, and video demonstrations. These designs provide a unified interface for autonomous planning from high-level instructions and controllable execution from fine-grained text, goal-image, or video-context prompts. Experiments in both simulation and real-world platforms demonstrate superior capabilities in long-horizon autonomous planning, fine-grained instruction following and in-context adaptation.

- **背景**：世界动作模型（World Action Models, WAMs）通过联合建模视觉状态转换和机器人动作，为机器人操作提供了有别于传统VLA（视觉-语言-动作）模型的范式。然而，现有WAMs存在三个关键局限：
  - **有限的进度感知记忆**：大多数方法仅依赖当前观测或短历史窗口，无法感知任务全局进度，导致相似视觉状态下动作决策模糊。
  - **粗粒度的语言-视频-动作对齐**：许多数据集不同片段共享同一任务级指令，对原子动作的监督弱，模型易依赖视觉捷径，对细粒度指令不敏感。
  - **受限的交互接口**：主要依赖文本控制，缺乏对目标图像、演示视频等视觉提示的原生支持，限制了视觉推理和跨实体迁移能力。

- **整体含义**：为了解决上述问题，本文提出WorldScape Policy 2.0，通过**推理增强的长短时记忆**，将长期事件语义记忆与短期视觉动态记忆相结合，并构建大规模事件级多模态数据集ManipEvent-5M，实现了从高级指令到细粒度多模态提示的统一可控世界动作建模。

## 2. 方法论

### 2.1 核心思想
- 采用**因果短期视觉记忆**（Causal Short-Term Visual Memory）保留最近观测的VAE潜在编码作为DiT前缀（prefill），维持局部交互动态。
- 引入**长短时事件记忆**（Long Short-Term Event Memory），由VLM分支将历史块输出组织为三种互补视图：**全局历史**（Global-History）、**局部活跃**（Local-Active）和**事件边界**（Event-Boundary），并通过检索和门控融合（Gated Fusion）增强当前推理令牌。
- **隐式子目标规划**（Implicit Subgoal Planning）：通过语义强制（Semantic Forcing）将事件级细粒度描述语义对齐到自主规划路径，使模型在仅有高级指令时能自主推断下一个子目标。
- **统一接口**：支持三种交互模式——自主规划（高级指令）、细粒度指令跟随（子任务描述）、上下文适应（目标图像/视频演示）。

### 2.2 关键技术细节
1. **统一动作表示**：动作表示为相对于动作块首帧的位移（位置Δp、旋转6D表示ΔR、绝对夹爪命令g），双机械臂拼接为20维向量。
2. **动作编码/解码器**：每个实体有专用编码器\(E_a^{(e)}\)和解码器\(D_a^{(e)}\)，将原始动作映射到共享DiT令牌空间，并恢复速度场用于流匹配。
3. **多模态提示编码**：
   - 细粒度指令由T5编码为嵌入直接注入DiT的交叉注意力。
   - 高级指令由VLM（Qwen3-VL-4B）与当前观测联合解释，经事件记忆增强后作为规划条件。
   - 目标图像和视频演示由VAE编码为持久视觉前缀。
4. **记忆构建与检索**：
   - 事件记忆队列维护历史VLM输出令牌，通过注意力池化压缩感知令牌为gist令牌，保留规划令牌。
   - 三种记忆视图经投影后与压缩全历史拼接，当前推理令牌作为查询进行交叉注意力，再由门控（sigmoid）控制注入量。
   - 事件边界通过相邻块平均表示的余弦距离变化检测，满足最小时间间隔。
5. **语义强制**：
   - 将VLM推理令牌的池化表示与T5池化表示进行余弦相似度最大化，T5编码器固定并停止梯度，避免坍塌。
6. **三阶段训练课程**：
   - **阶段1**：事件级多模态WAM预训练，使用ManipEvent-5M，激活短期视觉记忆，目标为动作流匹配和视频流匹配损失。
   - **阶段2**：记忆感知中间训练，引入VLM规划分支和长短期事件记忆，加入语义强制损失。
   - **阶段3**：下游交互后训练，根据任务需求激活不同交互模式。

## 3. 实验设计

- **仿真基准**：RoboTwin 2.0（50个双机械臂任务，干净/随机化设置，每任务100次评估）。
- **真实世界平台**：双机械臂PiPER平台，包括长程自主规划（折叠衣服、盒子）、内存依赖视觉推理（shell game）、跨实体技能迁移（堆叠积木，使用目标图像或视频演示）、时序细粒度控制（清理桌子，6条子任务指令）。

### 3.2 对比方法
- **VLA模型**：π0、π0.5、X-VLA、Abot-M0、LingBot-VLA、HoloBrain-0-QW。
- **WAM模型**：Motus、GigaWorld-Policy、LingBot-VA、Fast-WAM、Abot-M0.5、LingBot-VA 2.0、DreamZero。
- **消融变体**：记忆组件（STM、LTM、LSR）逐项添加、训练阶段（无Stage-1/2/语义强制）比较。

### 3.3 评估指标

## 6. 主要结论与发现

1. **整体性能优势**：WorldScape Policy 2.0在RoboTwin 2.0上平均成功率94.3%，超过所有对比方法（π0.5为79.8%，Fast-WAM为91.9%，LingBot-VA 2.0为93.6%），且在干净和随机化设置下表现均衡（差距仅0.1%）。

3. **真实世界能力**：
   - 长程自主规划（折叠衣服75%，折叠盒子75%）优于π0.5（60%/65%）和DreamZero（45%/55%）。

5. **核心贡献**：事件级多模态预训练和推理增强长短时记忆是实现可控、长程、自主操作的关键。
