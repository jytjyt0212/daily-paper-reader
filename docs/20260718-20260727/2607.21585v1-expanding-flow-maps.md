## 摘要
基于流的生成模型在连续和离散状态空间上实现了快速可控生成方面的显著进展，但现有参数化受限于固定维度或固定序列长度。本文引入扩展生成流（EFlows），它沿着一种扩展插值器定义维度递增的分布之间的流，该插值器通过添加条件噪声来增长状态。在此基础上，我们提出扩展流映射（EFMs），这是一种新的流映射类别，将扩展插值器蒸馏为高效的少步生成模型。每个EFM将任意两个时间步之间的映射分解为两个可学习操作：扩展算子，它根据当前状态用新坐标或标记扩充状态空间；以及传输映射，它沿着插值器将扩展状态向前推进。组合这些算子产生一个联合扩展和去噪状态的单映射，将现有的固定画布流和流映射作为扩展算子为恒等映射的特殊情况。我们进一步将框架扩展到离散单纯形，实现可变大小图生成和可变长度序列生成。在连续和离散模态中，我们将EFlows和EFMs确立为输出大小本身是学习到的可控自由度的场景的 principled 框架。

## Abstract
Flow-based generative models have enabled remarkable progress in fast and controllable generation across continuous and discrete state spaces, yet existing parameterizations are constrained to fixed dimensions or fixed sequence lengths. Here, we introduce Expanding Generative Flows (EFlows), which define flows between distributions of increasing dimensionality along an expanding interpolant that grows the state by augmenting it with conditional noise. Building on this construction, we propose Expanding Flow Maps (EFMs), a new class of flow maps that distill the expanding interpolant into efficient few-step generative models. Each EFM factors the map between any two timesteps into two learnable operations: an expand operator, which augments the state space with new coordinates or tokens conditioned on the current state, and a transport map, which pushes the expanded state forward along the interpolant. Composing these operators yields a single map that jointly expands and denoises the state, recovering existing fixed-canvas flows and flow maps as the special case in which the expand operator is the identity. We further extend the framework to the discrete simplex, enabling variable-size graph generation and variable-length sequence generation. Across both continuous and discrete modalities, we establish EFlows and EFMs as a principled framework for settings in which output size is itself a learned, controllable degree of freedom.

#### 1. 论文的核心问题与整体含义

**研究动机与背景**：
- **核心问题**：现有的基于流的生成模型（Flow-based Models）和流映射（Flow Maps）都受限于一个“固定画布”（fixed canvas）。无论是连续空间（固定维度d）还是离散空间（固定序列长度L），生成模型的输出大小必须在生成前就确定好，无法动态调整。
- **研究背景**：许多现实世界的生成任务天然要求输出可变大小，例如：可变分辨率的图像和3D形状、任意时长的音频和视频、长度不固定的文本序列、以及交错不同模态的多模态数据。
- **整体含义**：本文的目标是打破这一限制，构建一个统一的生成框架，使得模型在推理过程中，其状态空间的维度（或序列长度）可以**自适应地增长**，从而实现对可变大小输出的少步（few-step）生成。

#### 2. 论文提出的方法论：核心思想与技术细节

**核心思想**：构建一个“扩展插值器”（Expanding Interpolant），该插值器连接两个不同维度的分布。在从噪声分布到数据分布的演化过程中，通过添加条件噪声来逐步“扩展”状态空间。关键是将这个插值过程分解为两个可学习的操作，并蒸馏成高效的**扩展流映射（EFM）**。

**关键技术细节**：
- **扩展生成流（EFlows）**：
    1.  **扩展插值器（Expanding Interpolant）**：定义了一个非递减的维度调度函数 `d(t)`，使得状态 `x_t` 的维度随时间 `t` 增加。这克服了标准插值器维度固定的限制。
    2.  **扩展算子（Expand Operator， `Es,t`）**：负责在时间 `s` 到 `t` 的跳转中，将低维状态 `x_s` 从 `R^d(s)` 提升到高维空间 `R^d(t)`。具体做法是**向当前状态中插入（条件）噪声变量** `ϵ`。插入方式可以是简单的拼接（应对序列生成）、位置插入（应对插值任务）或子节点扩展（应对粗到细生成）。
    3.  **局部时间坐标（Local Time Coordinate）**：新插入的坐标具有自己的“局部时间”，这样在全局时间 `t`，不同时间点插入的坐标有不同的去噪进度，这被统一映射到 `[0, 1]` 区间内进行管理。
    4.  **分段确定性马尔可夫过程（PDMP）**：论文将整个扩展流框架统一定义为一个PDMP，其生成器（Generator）由两部分组成：**传输项**（连续去噪的ODE流）和**跳跃核**（维度扩展的跳变过程）。这为框架提供了坚实的理论基础。

- **扩展流映射（EFMs）**：
    1.  **定义**：`EFM` 是 `EFlow` 的蒸馏版本，旨在通过少步（如1-4步）即可生成样本。它被定义为**扩展算子** `Es,t` 与**传输映射** `Xs,t` 的组合：`Φs,t = Xs,t ∘ Es,t`。
    2.  **训练目标**：EFM的训练结合了**对角损失**和**一致性损失**。
        - **对角损失**：训练网络学习在时间 `s=t` 时的瞬时速度 `vs,s`（或瞬时去噪器 `ψs,s`），这是标准流匹配（CFM）的损失。
        - **一致性损失**：通过**拉格朗日条件**、**欧拉条件**和**半群条件**这三个一致性方程来约束 `Φs,t`，确保从任意 `s` 到 `t` 的映射是自洽的，类似于一致性模型（Consistency Models）的思想。
    3.  **离散扩展流映射**：将上述框架扩展到离散状态空间（如离散序列和分子图）。关键是将扩展算子具体化为“**令牌插入**”（Token Insertion），将传输映射具体化为“**令牌去噪**”（Token Denoising）。为此，设计了一个**插入头**（Insertion Head）来预测在每两个已存在令牌之间应该插入多少个新令牌，并采用二项分布或泊松分布进行采样。

#### 8. 不足与局限
