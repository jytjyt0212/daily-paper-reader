## 摘要
模仿学习能够利用专家演示在具有潜在奖励信号的未知环境中学习策略，但当模仿者和专家的观察不匹配且专家演示中存在未观察到的混杂因素时，模仿学习会陷入困境。通过顺序π-后门准则识别适当的调整集，因果模仿学习（CIL）提供了一个从混杂数据近似专家策略的框架。然而，现有的CIL方法——因果行为克隆（Causal BC）和因果生成对抗模仿学习（Causal GAIL）——是为短视界、低维设置设计的。当应用于具有长视界和高维状态-动作空间的连续控制任务时，这些方法表现出较差的性能：Causal BC遭受复合误差，Causal GAIL不稳定且样本效率低，顺序π-后门调整变得不切实际。我们引入了因果软Q模仿学习（Causal SQIL）和因果逆软Q学习（Causal IQ-Learn），这是两种离策略因果模仿学习算法，将因果调整框架与最先进的逆强化学习目标相结合。两种算法均基于由高效近似顺序π-后门准则产生的因果调整状态表示，利用连续控制环境的因果结构将全视界调整简化为固定大小的滑动窗口。我们在一个混杂环境套件中评估所有方法，发现Causal SQIL和Causal IQ-Learn在长视界任务上显著优于先前的CIL算法，有时甚至超越专家，而所有非因果模仿方法均未能学习到有意义的行为。

## Abstract
Imitation learning enables learning a policy in an unknown environment with a latent reward signal using expert demonstrations, but it struggles when the imitator's and expert's observations are mismatched and unobserved confounders are present in expert demonstrations. By identifying appropriate adjustment sets via the sequential $π$-backdoor criterion, causal imitation learning (CIL) provides a framework for approximating the expert's policy from confounded data. However, existing CIL methods, Causal Behavioral Cloning (Causal BC) and Causal Generative Adversarial Imitation Learning (Causal GAIL), are designed for short-horizon, low-dimensional settings. When applied to continuous control tasks with long horizons and high-dimensional state-action spaces, these methods exhibit poor performance: Causal BC suffers from compounding errors, Causal GAIL is unstable and sample-inefficient, and sequential $π$-backdoor adjustment becomes impractical. We introduce Causal Soft Q Imitation Learning (SQIL) and Causal Inverse soft-Q Learning (IQ-Learn), two off-policy causal imitation learning algorithms that combine the causal adjustment framework with state-of-the-art inverse reinforcement learning objectives. Both algorithms operate on causally-adjusted state representations produced by an efficient approximation of the sequential $π$-backdoor criterion, exploiting the causal structure of continuous control environments to reduce the full-horizon adjustment to a fixed-size sliding window. We evaluate all methods in a suite of confounded environments and find that Causal SQIL and Causal IQ-Learn substantially outperform prior CIL algorithms on long-horizon tasks, sometimes surpassing the expert, whereas all causally unaware imitation methods fail to learn meaningful behavior.

## 2. 论文提出的方法论
### 核心思想
- 将因果调整（顺序π-后门准则）与离策略逆强化学习目标（SQIL、IQ-Learn）结合，在因果调整后的状态表示上学习策略。
- 提出**窗口化顺序π-后门调整**（Algorithm 1），利用环境的时间有界性和时间同质性，将全视界调整集计算简化为固定大小滑动窗口，从而在长视界中可行。

### 关键技术细节
1. **因果调整**：基于已知因果图，通过顺序π-后门准则确定每步应条件化的观测变量子集 \(Z_t\)，排除与结果无因果关系的变量（如混杂代理变量）。
2. **窗口化调整（Algorithm 1）**：
   - 假设k-有界时间影响（任何混杂的影响在k步内）和内生时间同质性。
   - 构建短视界代理图 \(G_k\)（视界 \(k+1\)），在该代理图上运行 FIND OX 算法得到调整集，然后通过时间同质性推广到全视界。
   - 输出每步的滑动窗口规范，将 \(Z_t\) 限制为最近k步内的变量，维度固定为 \(O(k)\) 而非 \(O(H)\)。
3. **Causal SQIL**：将专家 transition 标记奖励 \(r=1\)，策略 transition 标记 \(r=0\)，用 SAC 在因果调整后状态上训练，critic 最小化软贝尔曼残差（公式1），actor 最大化熵正则化目标（公式2）。
4. **Causal IQ-Learn**：学习 Q 函数，其隐式奖励与专家行为一致，通过卡方散度损失（公式3-4）训练 critic，actor 目标与 Causal SQIL 相同。两种算法共享相同的因果编码层和 SAC 风格更新。

### 算法流程
- **输入**：专家演示、因果图、窗口大小k、视界H等。
- **步骤**：
  1. 调用 Algorithm 1 计算窗口化调整集 \(\{Z_t^H\}\) 和规范 S。
  2. 构建编码器 ENCODE，将每步原始观测转换为 \(z_t\)（拼接 k 步内调整集变量的值）。
  3. 初始化策略网络、Q网络等。
  4. 循环：在环境中执行策略，收集轨迹并编码；从专家缓冲区和策略缓冲区采样，更新 critic 和 actor（SQIL用软贝尔曼残差，IQ-Learn用卡方损失）；软目标更新、熵调优。
- **输出**：最终策略 \(\pi_\phi\)。

## 6. 论文的主要结论与发现
1. **非因果方法全部失败**：所有条件于全部观测的方法在混杂环境下几乎零成功率，证实混杂导致不可忽略的偏误。
2. **因果调整是必要条件，但不足以保证可扩展性**：Causal BC 和 Causal GAIL 在长视界任务中性能严重下降；Causal SQIL 和 Causal IQ-Learn 则保持高性能。
3. **离策略Q学习是关键技术**：通过时间差分学习传播专家信号，解决复合误差和信度分配问题。
4. **窗口化调整有效**：k 在 1-10 范围内性能最佳，过大（100）反而因维度爆炸导致 Q 学习不稳定；窗口化调整使长视界因果调整可行。
5. **混杂无法通过训练分布内诊断**：训练时非因果方法回报与因果方法相近，仅在部署时失效。
6. **Causal SQIL 和 Causal IQ-Learn 有时超越专家**：因为离策略 Q 学习隐式平均了混杂分布，比专家微调策略更鲁棒。

## 7. 优点
- **方法创新**：首次将因果调整与离策略软 Q 学习（SQIL、IQ-Learn）结合，实现可扩展 CIL。
- **高效近似**：提出窗口化顺序π-后门调整，理论保证（Theorem 1）下将计算复杂度从 \(O(H)\) 降至 \(O(k)\)，使长视界（H=1000-2000）可行。

- **理论支撑**：提供窗口化调整的正确性证明，并论证了有界时间混杂假设在物理模拟中的合理性。
- **实验严谨**：包含多维度消融（窗口大小、混杂强度、视界长度）、训练/部署对比、运行时分析，统计可靠（标准误差）。

## 8. 不足与局限
- **依赖已知因果图**：方法需预先指定因果结构，实践应用中可能缺失或需因果发现，未处理图误设情况。
- **窗口假设局限**：假设混杂影响在 k 步内衰减，若存在长期潜伏依赖（如缓慢漂移、持久隐藏目标），近似失效。
