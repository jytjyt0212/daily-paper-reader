## 摘要
扩散Transformer在图像生成方面表现强劲，但大多数在压缩潜空间中运行。像素空间扩散避免了这种信息损失，然而现有方法将每个原始图像补丁映射为单一令牌，迫使一个表示同时处理全局通信和细粒度细节。我们通过提出一种新架构DuSPiT（双分支子补丁像素Transformer）来解决此问题。该模型将全局结构推理与局部外观建模分离。DuSPiT使用紧凑的基础分支进行高效全局推理，以及并行的、高容量的像素分支（组织成子补丁组）以保留细节外观，两个分支通过交叉注意力交互。我们的结果表明，DuSPiT生成的图像具有更丰富的细节和更强的细粒度结构，同时相比先前的像素空间扩散Transformer实现了更好的质量-效率权衡。

## Abstract
Diffusion Transformers achieve strong image generation performance, but most operate in compressed latent spaces. Pixel-space diffusion avoids this information loss, yet existing approaches map each raw image patch to a single token, forcing one representation to handle both global communication and fine-grained details. We address this issue by proposing a new architecture, \textbf{DuSPiT}, a \textbf{Du}al-branch \textbf{S}ub\textbf{P}atch \textbf{Pi}xel \textbf{T}ransformer. This model separates global structural reasoning from local appearance modeling. DuSPiT uses a compact base branch for efficient global reasoning and a parallel, high-capacity pixel branch, organized into subpatch groups, to preserve detailed appearance, with the two branches interacting through cross-attention. Our results show that DuSPiT generates images with richer details and stronger fine-grained structures, while also achieving a better quality--efficiency trade-off than prior pixel-space diffusion transformers.

## 2. 论文提出的方法论：核心思想、关键技术细节

### 核心思想
- **双分支解耦**：一个紧凑的**基分支（base branch）**负责高效的全局结构推理（类似标准DiT）；一个高容量的**像素分支（pixel branch）**通过**子补丁组（subpatch groups）**保留细粒度外观。
- **交叉注意力交互**：基分支为像素分支提供全局上下文的键值（key/value），像素分支仅用查询（query）从同一patch的基分支token获取信息，实现非对称的信息流动。
- **输出生成**：仅从像素分支直接预测干净图像（x₀预测），基分支不参与最终输出，作为内部结构瓶颈。

### 关键技术细节
1. **双分支表示**：
   - 基分支：`z_i = E_patch(x_t^(i))`，维度`d_p`较小（如32维）。
   - 像素分支：`a_i = E_pixel(x_t^(i))`，维度`d_a`较大（≥3072），分为`n²`个子补丁组（如8×8=64组，每组48维）。
2. **层次化位置编码**：
   - 基分支使用标准2D RoPE编码patch级坐标`(u,v)`。
   - 像素分支中，每个子补丁组根据其在patch内的相对偏移`(Δx, Δy)`，通过RoPE得到子补丁级位置`p_sub(u,v,s,t) = RoPE(u+Δx, v+Δy)`。
   - 在交叉注意力中，查询（子补丁）使用子补丁位置，键值（基分支）使用patch位置。
3. **交叉注意力机制**：
   - 每个子补丁组`a_i^(r)`通过共享MLP映射为查询`q_i^(r)`。
   - 基分支token`z'_i`被拆分为H个注意力头，经线性投影得到键`k_i^(h)`和值`v_i^(h)`。
   - 每个子补丁查询仅与本patch的基分支token进行交叉注意力（一对一patch内），输出聚合后与原始像素表示相加并经过独立的子补丁MLP_r。
   - 公式：`ˆa_i^(r) = Σ_h α_(i)^(r,h) v_i^(h)`，其中`α`为softmax归一化后的注意力权重。
4. **输出头**：经过L层后，像素分支token通过轻量线性层`W_out`直接投影为clean patch像素值，再重组为完整图像。

### 算法流程简述
- 输入：噪声图像`x_t` → 双分支token化 → 经过L个交替的DiT block（基分支自注意力+MLP）和CrossDiTBlock（基分支→像素分支交叉注意力+像素分支SwiGLU FFN） → 最终像素分支线性投影 → 输出干净图像`̂x₀`。
