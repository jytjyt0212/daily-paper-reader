## 摘要
现代视觉-语言-动作（VLA）模型通常难以泛化到新设置，例如改变相机视角或机器人形态，因为它们通常仅以当前观察和语言指令为条件。通过忽略作为变量的底层系统配置，这些模型隐含地假设了训练中遇到的固定执行上下文，从而需要对任何新环境进行数据密集型微调。在这项工作中，我们引入了上下文世界建模（ICWM），这是一种将系统识别视为上下文适应问题的框架。ICWM使机器人策略能够从短期的自生成、任务无关交互历史中自主推断关键系统变量。与传统的使用演示来指定执行什么任务的上下文学习不同，ICWM利用上下文窗口来理解系统如何运行。通过在任务执行前处理这些交互，模型隐式地捕获当前系统的世界动态，从而无需参数更新即可适应新配置。在仿真和真实机器人平台上的大量实验表明，ICWM在新型相机视角下显著优于标准VLA基线。

## Abstract
Modern Vision-Language-Action (VLA) models often fail to generalize to novel setups, such as altered camera viewpoints or robot morphologies, because they are typically conditioned only on current observations and language instructions. By ignoring the underlying system configuration as a variable, these models implicitly assume a fixed execution context encountered during training, necessitating data-intensive fine-tuning for any new environment. In this work, we introduce In-Context World Modeling (ICWM), a framework that treats system identification as an in-context adaptation problem. ICWM enables robot policies to autonomously infer essential system variables from a short history of self-generated, task-agnostic interactions. Unlike traditional In-Context Learning that uses demonstrations to specify what task to perform, ICWM leverages the context window to understand how the system operates. By processing these interactions before task execution, the model implicitly captures the world dynamics of the current system, enabling adaptation to novel configurations without parameter updates. Extensive experiments in simulation and on real-world robot platforms demonstrate that ICWM significantly outperforms standard VLA baselines on novel camera viewpoints.

- **研究动机**：作者类比人类操控器的行为：当面对不熟悉的控制映射时，人类首先会进行短暂的随机探索（随机操作摇杆，观察响应），从而建立起系统动力学的内部模型，随后才能进行目标导向的控制。这一校准过程完全自主生成，无需任务特定演示或外部指导。作者由此认为，VLA模型的失败本质上是系统识别问题：策略在测试时缺乏对系统配置ψ的了解。因此，需要一种方法，在不更新参数、不依赖任务特定演示的情况下，让模型自主推断当前系统配置。

- **整体含义**：本文提出In-Context World Modeling（ICWM），通过重新利用上下文窗口进行系统识别，而非行为规范。通过在任务执行前插入一段自生成的、任务无关的交互历史（随机探索片段），模型隐式地捕获了当前系统的世界动力学（如控制映射、相机几何），从而实现对用户视角等新配置的零样本适应。

## 2. 论文提出的方法论

### 核心思想
ICWM的核心是将系统识别问题转化为上下文适应问题。模型不是直接学习从观测到动作的静态映射，而是学会从一段短的自生成交互历史（T）中推断当前环境/系统的潜在配置ψ，并据此调整动作预测。形式上，策略从πθ(at | ot, l)变为πθ(at | Ψ(T), ot, l)，其中Ψ(T)是通过Transformer隐式学习到的系统配置表示。

### 关键技术细节
- **交互上下文定义**：T = {(o_si, a_i, o_ei)}，其中N个任务无关的随机运动片段。每个片段包含开始观测、执行的动作、结束观测。
- **训练阶段**：模型在多种系统配置（不同视角、形态）的数据上训练，对每个训练样本预置N个随机采样的交互片段作为上下文。这些片段来自于同一系统配置下的轨迹，使得模型必须学会从上下文中提取系统动力学信息，以准确预测任务动作。损失函数为标准的动作预测负对数似然：L = -log πθ(at | Ψ(T), ot, l)。
- **推理阶段**：
    1. **主动探测阶段（Active Probing）**：机器人执行N个任务无关的随机探索动作（在安全工作空间内随机采样目标位姿并执行），记录每个片段的观测-动作-观测三元组。
    2. **上下文执行阶段（In-Context Execution）**：将收集到的T与当前观测ot、语言指令l一起输入模型，模型通过Transformer自注意力机制，先处理上下文建立配置感知的隐藏状态，再处理任务查询输出动作。整个过程无需梯度更新。
- **参数共享**：Ψ与VLA骨干网络共享参数，无需引入额外参数。这得益于动作预测和配置推断都具有理解观测-动作对应关系的结构相似性。

### 公式 / 算法流程（文字说明）
1. 训练数据：从不同系统配置下收集的任务轨迹中，随机抽取N个任务无关的交互片段作为前缀。
2. 训练：模型以前缀+当前观测+语言指令为输入，输出动作，通过反向传播优化。
3. 测试：
   - 第一步：机器人在当前配置下执行N个随机探索动作，记录观测和动作。
   - 第二步：将记录的前缀与当前任务查询一起输入训练好的模型，生成动作。
   - 重复第二步直到任务完成。

## 6. 论文的主要结论与发现
1. **视角泛化是根本性挑战**：所有基线在OOD视角下性能急剧下降，ICWM则显著缓解，平均OOD成功率比MV高13.0%。
2. **隐式识别优于显式指定**：ICWM（使用交互上下文）比EXplicit（使用真实角度）高出9.5%，表明纯几何信息不足，而交互上下文提供了更丰富的系统动力学信息。
3. **长序列任务增益最大**：在LIBERO-Long上，ICWM相比MV在未见视角下提升26.3%，因为长任务放大视角偏移带来的累积误差，而ICWM通过连续的动作-观测对齐抵消该效应。
4. **交互上下文成分缺一不可**：缺少图像或动作都显著降级，但错误上下文比无上下文更差，证明模型积极利用上下文进行推断。
5. **ICWM能泛化到语义和形态变化**：在干扰物、新纹理、机械臂爪变形上保持优势；对连杆长度变化，ICWM的退化更平缓，相对优势随不确定性增大。
6. **计算开销可接受**：每步仅增加约0.07秒（N=5），且可通过KV缓存优化。

## 7. 优点
- **方法简洁但高效**：仅利用随机探索的交互历史，无需额外训练、无需任务演示、无需微调参数。该思想直接且可落地。
- **理论动机充分**：作者从POMDP视角证明交互上下文比单帧观测包含更多系统配置信息（命题1），为方法提供理论支撑。
- **实验设计系统且严谨**：覆盖仿真和真实、多种干扰因素、充分的消融和对比，尤其是有“错误上下文”的阴性对照，增强了结论可信度。
- **实际部署友好**：探测动作任务无关且安全（避免触碰物体），探测时间短（5-6秒），可复用KV缓存，微创地集成到现有VLA流程中。
- **跨任务和跨配置泛化**：同一训练好的模型可直接用于不同摄像头角度、语义变化和形态变化，无需针对性微调，潜力巨大。

## 8. 不足与局限
- **实验覆盖仍有局限**：仅测试了相机视角、语义变化（干扰物、纹理）、形态变化（刚性垫片、连杆缩短）。未测试其他系统配置如：
  - 不同的机器人构型（例如从UR5e换为Franka Panda或人形机器人）。
  - 传感器异构（例如不同分辨率、噪声模型、深度缺失）。
  - 动力学参数变化（如负载、摩擦力）。
- **仅依赖视觉观测**：ICWM当前只使用RGB图像，未纳入其他模态（深度、触觉、IMU），对视觉遮挡或光线剧烈变化可能脆弱。
- **探测策略影响有限**：不同探测策略对性能略有影响但无普适最优，随机探测已足够好，但理论上可能存在更高效的探测策略未被探索。
- **需要一定计算资源**：虽然推理时可优化，但训练（8 A100）仍需要一定成本。且上下文长度增加会线性增长推理时间。
- **隐式表示的可解释性不足**：虽然t-SNE显示很好的聚类，但Ψ(T)的具体含义难以解释，可能限制在安全关键系统中的应用。
- **所提框架对系统配置变化敏感程度未量化**：例如，需要多少上下文片段（N）才能达到稳定鲁棒性？作者主要在N=5下实验，未系统改变N。
- **未与其他无参数适应方法对比**：例如基于视觉流的自校准方法或增量式SlAM内参校正。仅与标准训练方法对比。
